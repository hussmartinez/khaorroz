# Yakhnet Khudra / يخنة الخضار

> ⬅ [الرئيسية](README.md) · [فلسطين](provincial_palestine.md) · [الأردن](provincial_jordan.md) · [لبنان](provincial_lebanon.md) · [سوريا](provincial_syria.md)

> ⚠️ **ملاحظة حول موثوقية المصادر:** يخنة منزلية عامة موثّقة في مواقع الوصفات العربية؛ وارتباطها الإقليمي بفلسطين والأردن مصدره تلك المواقع، لا المصادر التاريخية.

## 1. الملامح الجغرافية والقوام
*   **Primary Geographic Zone:** المطبخ المنزلي الشامي؛ وتصف المصادر العربية يخنة اللحم والخضار بأنها "مشهورة في فلسطين والأردن".
*   **Dish Type & Texture:** تُؤكل مع الأرز: خضار مشكّلة (بطاطا، جزر، كوسا، بازلاء، بندورة) مع اللحم أو الدجاج في مرق بندورة خفيف، تُقدَّم مع الأرز بالشعيرية.
*   **Traditional Cooking Vessel & Fuel:** قِدر يخنة كبيرة؛ وقِدر أرز بغطاء.

## 2. السياق التاريخي والثقافي
حين يكون في المطبخ قليل من كلّ شيء، تُعدّ الطاهية الشامية **يخنة الخضار**: تُضاف الخضار "بحسب مدّة طهيها، بدءاً بالبطاطا، ثم الجزر، والكوسا والبندورة في الآخر"، وتُغطّى بالماء أو مرق الدجاج، وتُطهى على نار هادئة نحو نصف ساعة. وتُقدَّم مع الأرز بالشعيرية. وتصف مواقع الوصفات العربية يخنة اللحم والخضار بأنها "مشهورة في فلسطين والأردن وتُقدَّم مع الأرز". وصيغة اللحم المفروم مع البطاطا والجزر والبازلاء والفطر تستغرق نحو 40 دقيقة لأربعة أشخاص.

وهي العضو الجامع في عائلة *رز ويخنة*؛ انظر [يخنة البطاطا](recipe_yakhnet_batata.md).

## 3. الاختلافات المحلية من بلدة إلى بلدة (أساسي)
*   **فلسطين / الأردن (لحم خروف أو بقر):** مكعّبات لحم، والغلبة للجزر والبطاطا، مع البندورة؛ والأرز الأبيض.
*   **صيغة الدجاج:** أساسها مرق الدجاج؛ مع الأرز بالشعيرية.
*   **صيغة اللحم المفروم:** أسرع، مع البازلاء والفطر.
*   **لحم الخروف مع الخضار (رمضان):** صيغة أدسم بقطع لحم الخروف لمائدة الإفطار.

## 4. الوصفة الأساسية (مخطط لأربعة أشخاص)
*الصيغة المعتمدة: يخنة الخضار الفلسطينية الأردنية بلحم الخروف مع الأرز بالشعيرية.*

### قاعدة النكهة (El Fondo)
| المكوّن | الكمية |
|---|---|
| لحم خروف أو بقر، مكعّبات | 500 غ |
| بطاطا، مكعّبات | 300 غ |
| جزر، شرائح | 200 غ |
| كوسا، مكعّبات | 200 غ |
| بازلاء | 150 غ |
| بصلة + ثوم | 1 + 3 فصوص |
| رُبّ البندورة + بندورة مهروسة | 2 ملعقة كبيرة + 300 غ |
| ورق غار، هيل، سبع بهارات | 2، 3 حبّات، 1 ملعقة صغيرة |
| زيت زيتون | 40 مل |
| ماء أو مرق | 1 ل |

### نسب التجميع
| العنصر | الكمية |
|---|---|
| أرز (متوسط الحبّة) | 300 غ |
| شعيرية | 50 غ |
| ماء للأرز | 450 مل |
| زبدة | 30 غ |

### خطوات الطهي بالتفصيل
1. **اللحم:** حمّر اللحم مع البصل؛ وأضف الماء والغار والهيل والملح؛ واتركه على نار هادئة **60 دقيقة**.
2. **الخضار بالترتيب:** أضف البطاطا، ثم الجزر بعد 5 دقائق، ثم رُبّ البندورة والبندورة؛ وبعد 15 دقيقة أضف الكوسا والبازلاء.
3. **اليخنة:** اتركها على نار هادئة **15 دقيقة** أخرى حتى يطرى كلّ شيء.
4. **الأرز:** حمّص الشعيرية في الزبدة، وأضف الأرز والماء المغلي المملّح، واطهه مغطّى 15 دقيقة، واتركه يرتاح 10 دقائق.
5. **التقديم:** اليخنة فوق الأرز.
