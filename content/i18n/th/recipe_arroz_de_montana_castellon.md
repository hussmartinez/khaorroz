# Arroz de Montaña de Castellón / Arròs de Muntanya (amb Conill, Caragols i Bolets)

> ⬅ [หน้าหลัก](README.md) · [จังหวัด Castelló](provincial_castellon.md)

> ⚠️ **หมายเหตุระดับความน่าเชื่อถือของแหล่งข้อมูล:** ข้าวภูเขาที่ใส่กระต่าย หอยทาก และเห็ดป่า เป็นอาหารที่ทำกันทั่วไปใน comarca (เขตปกครอง) ด้านในของจังหวัด Castellón (Alt Millars/Alto Mijares, L'Alcalatén, Els Ports, Alt Maestrat) แต่**ผู้เขียนไม่พบสูตรมาตรฐานที่มีการบันทึกไว้อย่างเป็นทางการแม้แต่สูตรเดียว** ข้อมูลการท่องเที่ยวของเมืองอย่าง Montanejos ส่วนใหญ่อ้างถึงเพียง "paella valenciana" และข้าวกระต่าย หน้านี้จึงสร้างโครงสร้างร่วมขึ้นใหม่จากแนวปฏิบัติของพื้นที่ด้านในบาเลนเซีย และระบุไว้ในจุดที่ทำเช่นนั้น โปรดตรวจสอบกับร้านอาหารหรือตำราอาหารท้องถิ่น

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** พื้นที่ด้านในของ Castellón ได้แก่ L'Alt Millars / Alto Mijares (Montanejos), L'Alcalatén (Llucena, L'Alcora), Els Ports (Morella) และ L'Alt Maestrat
*   **Liquid & Texture Profile:** **Seco** (ข้าวแห้ง) เมื่อทำในกระทะ paella ส่วนบนที่สูงอากาศหนาวของ Els Ports มักทำแบบ **caldoso** (ข้าวน้ำซุป) แทน
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** กระทะ paella เหล็กบนไฟฟืนไม้**สน**หรือไม้**โอ๊กโฮล์ม** ส่วนใน masía (มาซีอา บ้านไร่) ใช้หม้อดิน cassola ตั้งบนเตาผิง

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
พื้นที่ด้านในของ Castellón เป็นดินแดนสูง หนาว และมีประชากรเบาบาง เต็มไปด้วยบ้านไร่ masía ปศุสัตว์ และการล่าสัตว์ ข้าวของที่นี่รวบรวมสิ่งที่ภูเขามอบให้ ได้แก่ **กระต่าย** (ป่าหรือเลี้ยง) **หอยทาก** (*vaquetes*, *caragols serrans* หอยทากภูเขา) **เห็ดป่า**ในฤดูใบไม้ร่วง (*rovellons* / níscalos เห็ดน้ำนมสีส้ม, *pebrassos* เห็ดน้ำนมรสเผ็ด) **เนื้อหมูจากเทศกาลฆ่าหมู matança** และสมุนไพร (ไธม์ โรสแมรี่) ข้าวต้องลงไปซื้อจากชายฝั่ง จึงเป็นวัตถุดิบสำหรับวันเทศกาลบนนี้ ขณะที่โปรตีนหาได้ในท้องถิ่น ข้าวนี้คือคู่แฝดฝั่งเหนือของข้าว [conejo y caracoles](recipe_arroz_conejo_y_caracoles.md) (กระต่ายกับหอยทาก) ของ Alicante เพียงแต่เปลี่ยนแหล่งความร้อน (ไม้สนหรือโอ๊กแทน sarmiento กิ่งองุ่น) และเพิ่มเห็ดตามฤดูกาล

**วิทยาศาสตร์การทำอาหาร:** เห็ดป่าคายน้ำและกลูตาเมตออกมามาก การผัดเห็ดแยกต่างหากจนน้ำระเหยและเห็ดเป็นสีน้ำตาล แล้วค่อยใส่กลับลงไปตอนท้ายของ fondo (ฟอนโด ฐานน้ำซุป) จะให้รสอูมามิโดยที่น้ำซุปไม่จาง ไม้สนเผาไหม้ได้ร้อนและมีควันกลิ่นยางสน ซึ่งแต่งกลิ่นข้าวอย่างแผ่วเบา

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ — สร้างขึ้นใหม่ โปรดตรวจสอบในท้องถิ่น)

*   **สไตล์ Alto Mijares (Montanejos):** กระต่าย + ไก่ + **หอยทาก** + ถั่วแขก ใกล้เคียงกับ paella valenciana ที่ใส่สมุนไพรภูเขา
*   **สไตล์ L'Alcalatén:** กระต่าย + ซี่โครงหมู + **rovellons** ในฤดูใบไม้ร่วง แบบ seco
*   **สไตล์ Els Ports (Morella):** อากาศหนาวกว่า จึงมักทำแบบ **caldoso** ใส่**เนื้อแกะ**หรือ**หมู**และ**มันฝรั่ง** บางครั้งใส่ *cecina* (เซซีนา เนื้อตากแห้ง) หรือ *jamón* (แฮมสเปน) ของท้องถิ่น
*   **สไตล์ Alt Maestrat:** กระต่าย + หอยทาก + **ไธม์** ชั้นข้าวบางมากและแห้ง เป็นญาติฝั่งภูเขาของข้าวแบบ Pinoso

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **Seco ฤดูใบไม้ร่วงแบบ L'Alcalatén / Alto Mijares** (กระต่าย + หอยทาก + rovellons)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| กระต่าย แยกชิ้น | 1 ตัว (≈ 1.1 kg) |
| ซี่โครงหมู หั่นท่อนสั้น | 250 g |
| หอยทาก (vaquetes) ล้างพิษและลวกแล้ว | 24 ตัว |
| Rovellons / níscalos (หรือเห็ดป่ารวม) ทำความสะอาด ฉีกเป็นชิ้น | 300 g |
| น้ำมันมะกอก | 100 ml |
| กระเทียม | 4 กลีบ |
| มะเขือเทศสุก ขูด | 150 g |
| Pimentón dulce (ปาปริกาหวาน) | 3 g |
| ไธม์ / โรสแมรี่ | อย่างละ 1 กิ่ง |
| น้ำ | 1.6 L |
| หญ้าฝรั่น | 0.3 g |

**การสกัดรส:** ผัดเห็ดในน้ำมัน 20 ml จากที่เตรียมไว้ จนเป็นสีน้ำตาลและแห้ง (**6–8 นาที**) แล้วพักไว้ ผัดกระต่ายและซี่โครงหมูช้าๆ จนเหลือง (**20 นาที**) ใส่กระเทียม pimentón (5 วินาที) และมะเขือเทศ (5 นาที) เติมน้ำ หอยทาก สมุนไพร และหญ้าฝรั่น เคี่ยว **25 นาที** จนงวดเหลือ ≈ 1.2 L ใส่เห็ดกลับลงไปใน 5 นาทีสุดท้าย

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น | 380 g |
| น้ำซุป | ≈ 1.15–1.2 L |
| กระต่าย + ซี่โครงหมู | ≈ 1.35 kg |
| เห็ด | 300 g |

### ขั้นตอนการทำทีละขั้น
1. **การเตรียม:** ล้างพิษหอยทาก (3–5 วัน) และทำความสะอาดเห็ดด้วยแปรง ไม่ใช่ล้างน้ำ
2. **Fondo:** ทำตามข้างต้น
3. **ข้าว:** โรยข้าวแล้วเกลี่ยให้เรียบ หยิบกิ่งสมุนไพรออก
4. **ไฟ (ไม้สน/โอ๊ก):** ไฟแรง 8 นาที → ถ่านแดง 8–9 นาที → เร่งไฟสั้นๆ เพื่อทำ socarrat (ข้าวตังก้นกระทะ)
5. **จบงาน/การพัก:** พัก 5 นาที
