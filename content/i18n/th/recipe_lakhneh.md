# Lakhneh (Nablus Stuffed Leaves) / اللخنة

> ⬅ [หน้าหลัก](README.md) · [ปาเลสไตน์](provincial_palestine.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** เป็น**อาหารที่กำลังจะสูญหาย** Mirna Bamieh (เมียร์นา บามีห์) ศิลปินและนักวิจัย ผู้ก่อตั้ง "Palestine Hosting Society" ซึ่งค้นคว้าอาหารปาเลสไตน์ที่ถูกลืม ให้สัมภาษณ์กับ *Asharq Al-Awsat* ว่า *lakhneh* (ลัคเนห์) ยังทำกัน**เฉพาะในเมืองนาบลัสและหมู่บ้านรอบๆ เท่านั้น** ประกอบด้วยใบของพืชที่เรียกว่า *dhakar al-qarnabit* (ษะกัร อัล-ก็อรนะบีฏ "กะหล่ำดอกตัวผู้") ห่อเนื้อสับ ข้าว และเครื่องเทศ โดยมี**ยี่หร่า**เป็นเครื่องปรุงหลัก ไม่มีบันทึกว่าใบนี้คือพืชชนิดใดทางพฤกษศาสตร์ ไม่มีบันทึกของเหลวที่ใช้ปรุงและปริมาณ พิมพ์เขียวด้านล่างจึงเป็นการประมาณขึ้นใหม่โดยอิงเทคนิคการทำใบผักยัดไส้แบบนาบลัส

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** เมืองนาบลัสและหมู่บ้านในเขต Jabal Nablus (ญะบัล นาบลุส)
*   **Dish Type & Texture:** ใบผักยัดไส้ (*mahashi* มะฮาชี) ใบผักป่าหรือผักไร่ที่อ่อนนุ่มม้วนห่อข้าวและเนื้อหอมยี่หร่า เคี่ยวจนนุ่ม
*   **Traditional Cooking Vessel & Fuel:** หม้อบนเตาแก๊สหรือเตาฟืน วางจานทับม้วนผักไว้

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
นาบลัสมีชื่อเสียงด้านอาหาร *madani* (มะดะนี อาหารชาวเมือง) ที่ประณีต เช่น knafeh (คนาเฟห์) maqluba (มักลูบา) ใส่กะหล่ำดอก และ *'akkoub* (อักกูบ พืชหนามป่าตามฤดูกาล) ส่วนหมู่บ้านรอบๆ ยังรักษาอาหารที่ทำจากพืชที่เก็บจากป่าและไร่นาไว้ *Lakhneh* อยู่ในโลกที่สองนี้ Bamieh บรรยายว่าจานนี้ยังคงอยู่เฉพาะในเขตนาบลัส ขณะที่ "ชาวปาเลสไตน์คนอื่นๆ ส่วนใหญ่เลิกทำไปแล้ว" โต๊ะอาหารชุมชนยาวเหยียดของเธอ ซึ่งครั้งแรกจัดร่วมกับมูลนิธิ A. M. Qattan และห้าครอบครัว เป็นความพยายามบันทึกอาหารเหล่านี้ไว้ก่อนที่จะสูญหาย นอกจาก *lakhneh* แล้ว เธอยังระบุอาหารอื่นๆ ที่ใกล้สูญหาย ได้แก่ *musluʿa* (มุสลูอะห์ ถั่วเลนทิลกับข้าว ดู [musluʿa](recipe_musluaa.md)) ของนาบลัส *rummaniyyeh* (รุมมานียะห์) ของจาฟฟา และแตงกวายัดไส้กับมะขามของเยรูซาเล็ม

ชื่อใบ *dhakar al-qarnabit* ("กะหล่ำดอกตัวผู้") ชวนให้คิดว่าเป็นใบด้านนอกของกะหล่ำดอกที่ไม่ห่อดอกหรือแทงช่อดอกแล้ว หรือพืชตระกูลกะหล่ำชนิดอื่น ⚠️ ซึ่งจะทำให้ *lakhneh* เป็นญาติแบบประหยัดของ [malfuf mahshi](recipe_malfouf_mehshi.md) (มัลฟูฟ มะห์ชี กะหล่ำปลีม้วนยัดไส้)

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **เมืองนาบลัสและหมู่บ้านรอบๆ (มีบันทึก):** ใบ *dhakar al-qarnabit* เนื้อสับ ข้าว และเครื่องเทศ โดยมียี่หร่าเป็นรสเด่น
*   **ส่วนอื่นของปาเลสไตน์:** กล่าวกันว่าไม่มีใครทำแล้ว กะหล่ำปลีม้วนและใบองุ่นม้วนเข้ามาแทนที่

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*ฉบับที่ใช้: lakhneh แบบนาบลัส ประมาณขึ้นใหม่*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| ใบพืชตระกูลกะหล่ำขนาดใหญ่ที่อ่อนนุ่ม (ใบนอกของกะหล่ำดอก / ใบแบบคะน้าฝรั่ง) | 30–35 ใบ |
| เนื้อแกะหรือเนื้อวัวสับ | 250 g |
| ข้าวเมล็ดสั้น ซาวแล้ว | 200 g |
| ยี่หร่าป่น | 2 ช้อนชา |
| ออลสไปซ์ เกลือ พริกไทยดำ | ½ ช้อนชา / 1 ช้อนชา / ½ ช้อนชา |
| น้ำมันมะกอก | 3 ช้อนโต๊ะ |
| กระเทียมทั้งกลีบ | 6 กลีบ |
| น้ำมะนาว | 3 ช้อนโต๊ะ |
| น้ำ | ≈ 800 ml |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ไส้ต่อใบ | 1 ช้อนชาพูน |
| เวลาเคี่ยว | 40–50 นาที |

### ขั้นตอนการทำทีละขั้น
1. **ใบ:** ลวกใบในน้ำเดือดผสมเกลือ 1–2 นาทีจนใบอ่อนตัว แล้วตัดก้านกลางที่แข็งออก
2. **ไส้:** ผสมข้าว เนื้อ ยี่หร่า ออลสไปซ์ เกลือ พริกไทย และน้ำมัน
3. **ม้วน:** วางไส้เป็นแนวยาวบนใบ แล้วม้วนให้แน่นเป็นรูปซิการ์
4. **เรียงและปรุง:** เรียงม้วนผักแน่นๆ ในหม้อพร้อมกระเทียม เติมน้ำและน้ำมะนาวให้พอท่วม วางจานทับ ปิดฝาเคี่ยวด้วยไฟอ่อน 40–50 นาที
5. **เสิร์ฟ:** พักไว้ 5 นาที แล้วเสิร์ฟกับโยเกิร์ตและมะนาว
