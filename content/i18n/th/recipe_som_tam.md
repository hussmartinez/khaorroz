# Som Tam / ส้มตำ (Tam Mak Hung / ตำหมากหุ่ง)

> ⬅ [หน้าหลัก](README.md) · [อีสาน (ภาคตะวันออกเฉียงเหนือ)](provincial_isan.md)

> ⚠️ **หมายเหตุความน่าเชื่อถือของแหล่งข้อมูล:** ต้นกำเนิดจากลาวเป็นที่กล่าวซ้ำกันอย่างกว้างขวางแต่ยังพิสูจน์ไม่ได้แน่ชัด และช่วงเวลาที่ส้มตำเข้ามาถึงกรุงเทพฯ (กลางศตวรรษที่ 20) เป็นเพียงการประมาณ

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** อีสานและลาว แรงงานอีสานที่ย้ายถิ่นนำไปสู่กรุงเทพฯ และทั่วประเทศ
*   **Dish Type & Texture:** กับข้าวกินกับข้าว: มะละกอดิบสับเส้นตำในครกกับพริก กระเทียม มะนาว น้ำปลาหรือปลาร้า รสเปรี้ยว-เผ็ด-เค็ม และกรอบ สามประสานคลาสสิกคือ ส้มตำ ไก่ย่าง และข้าวเหนียว
*   **Traditional Cooking Vessel & Fuel:** ครกดินเผาทรงสูง (*ครกดิน*) กับสากไม้ ตัวสลัดไม่ใช้ไฟ ข้าวเหนียวนึ่งใน *หวด* เสิร์ฟใน *กระติ๊บ*

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ในภาษาลาวและอีสาน อาหารจานนี้คือ *ตำหมากหุ่ง* "มะละกอตำ" หรือ *ตำส้ม* "ตำเปรี้ยว" *ส้ม* แปลว่าเปรี้ยว และ *ตำ* แปลว่าโขลก ([Wikipedia – Green papaya salad](https://en.wikipedia.org/wiki/Green_papaya_salad); [Wikiwand – Tam mak hung](https://www.wikiwand.com/en/articles/Tam_mak_hung)) งานอ้างอิงเสนอว่าสลัดตำรสเปรี้ยวมีมาก่อนมะละกอ ซึ่งเป็นผลไม้จากโลกใหม่ที่มาถึงชาวลาวผ่านชาวขแมร์เลอ (Khmer Loeu) ทางตะวันออกเฉียงใต้ของลาว และส้มตำแพร่เข้าสู่กรุงเทพฯ พร้อมกับแรงงานอพยพชาวอีสานในช่วงกลางศตวรรษที่ 20 ⚠️ ([Wikipedia – Green papaya salad](https://en.wikipedia.org/wiki/Green_papaya_salad)) มิชลินบรรยายว่าส้มตำเป็นมื้ออาหารที่สมบูรณ์เมื่อกินกับข้าวเหนียวและเนื้อย่าง ([มิชลินไกด์ – ถอดรหัสส้มตำ](https://guide.michelin.com/en/article/features/decoding-the-delicious-som-tam))

**วิทยาศาสตร์การครัว:** การตำทำให้เส้นมะละกอช้ำพอจะซึมซับน้ำปรุงโดยไม่เละ ปลาร้าเพิ่มกลูตาเมตและความลึกของกลิ่นหมักที่สมดุลกับความเปรี้ยวของมะนาว

## 3. ความแตกต่างของแต่ละท้องถิ่น (สำคัญ)
*   **ตำลาว / ตำปลาร้า:** แบบอีสาน-ลาว ใส่ *ปลาร้า* ไม่ใส่น้ำตาลหรือถั่วลิสง เผ็ดมาก ([มิชลิน](https://guide.michelin.com/en/article/features/decoding-the-delicious-som-tam))
*   **ตำไทย:** แบบกรุงเทพฯ หวานกว่า ใส่น้ำตาลปี๊บ กุ้งแห้ง และถั่วลิสง
*   **ตำปู:** ใส่ปูนาดอง
*   **ตำแบบอื่น ๆ:** ใช้แตงกวา ถั่วฝักยาว ข้าวโพด หรือผลไม้แทนมะละกอ

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: ตำปลาร้าแบบอีสาน-ลาว เสิร์ฟกับข้าวเหนียว*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| มะละกอดิบ สับเส้น | 400 ก. |
| พริกขี้หนู | 4–8 เม็ด |
| กระเทียม | 3 กลีบ |
| น้ำปลาร้า ต้มสุก | 3 ช้อนโต๊ะ |
| น้ำปลา | 1 ช้อนโต๊ะ |
| น้ำมะนาว | 3 ช้อนโต๊ะ |
| มะเขือเทศเชอร์รี่ ผ่าครึ่ง / ถั่วฝักยาว | 8 ลูก / 2 ฝัก |
| ข้าวเหนียว แช่น้ำ 6–8 ชม. | 300 ก. |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเหนียว | ข้าวสาร 300 ก. |
| มะละกอต่อครกหนึ่งรอบ | ≈ 100 ก. (ตำ 4 รอบ) |

### ขั้นตอนการทำทีละขั้น
1. **ข้าว:** แช่ข้าวเหนียว 6–8 ชม. สะเด็ดน้ำ แล้วนึ่งใน *หวด* ไม้ไผ่สานบนหม้อน้ำเดือด 20–25 นาที กลับก้อนข้าวหนึ่งครั้งตอนครึ่งทาง เก็บให้อุ่นใน *กระติ๊บ* ที่มีฝาปิด
2. **เครื่องตำ:** ตำกระเทียมกับพริกในครกดินพอหยาบ
3. **ตำ:** ใส่ถั่วฝักยาวและมะเขือเทศ แล้วใส่มะละกอหนึ่งในสี่ส่วน ตำเบา ๆ พร้อมใช้ช้อนพลิกไปมา เติมน้ำปลาร้า น้ำปลา และมะนาว
4. **เสิร์ฟ:** ชิมรส ทำซ้ำจนครบทุกรอบ แล้วเสิร์ฟกับข้าวเหนียว ไก่ย่าง และผักสด
