# Southern Thailand / ภาคใต้

> ⬅ [หน้าหลัก](README.md)

## 1. ภาพรวม
ภาคใต้ของไทยทอดยาวลงไปตามคอคอดกระระหว่างทะเลสองฝั่ง คือชายฝั่ง **อ่าวไทย** (ชุมพร สุราษฎร์ธานี นครศรีธรรมราช สงขลา ปัตตานี นราธิวาส) และชายฝั่ง **อันดามัน** (ระนอง พังงา ภูเก็ต กระบี่ ตรัง สตูล) วัฒนธรรมสองสายใช้ข้าวร่วมกัน:
- **ภาคใต้ไทยพุทธ (นครศรีธรรมราช สุราษฎร์ธานี พัทลุง สงขลา)** ที่นี่ข้าวผูกพันกับปฏิทินการทำบุญ ได้แก่ขนมห้าอย่างใน **สารทเดือนสิบ** (เทศกาลเดือนสิบเพื่อบรรพบุรุษ) **ขนมต้ม** ห่อใบที่โยนให้เรือพระในงาน **ชักพระ** และ **ข้าวยาคู** (*ข้าวมธุปายาส*) รสหวานน้ำผึ้งที่กวนกันที่พระบรมธาตุเมืองนคร
- **ภาคใต้ตอนล่างมลายูมุสลิม (ปัตตานี ยะลา นราธิวาส บางส่วนของสงขลาและสตูล)** ดินแดนนี้เคยเป็นรัฐสุลต่านปัตตานี ซึ่งมีครัวร่วมกับรัฐกลันตันและตรังกานูในปัจจุบัน ข้าวที่นี่คือ **นาซิดาแก** (ข้าวกะทิกับลูกซัด กินกับแกงปลาทูน่า) และ **ข้าวยำ** ราด **บูดู** ซอสปลากะตักหมักที่ทำในหมู่บ้านมุสลิมชายฝั่ง
- **ภูเก็ตและฝั่งอันดามัน** อาหารเปอรานากัน (บาบ๋า) แบบฮกเกี้ยน-มลายู รวมถึงข้าวยำผักดองกับ *น้ำเคย* (น้ำจากการหมักกะปิ) ในพังงา ระนอง และชุมพร

อาหารใต้เผ็ดที่สุดและเหลืองขมิ้นที่สุดในประเทศไทย ข้าว ไม่ว่าจะเป็นข้าวหอมมะลิสวยหรือข้าวเหนียวสำหรับทำขนม คือสิ่งที่อยู่เคียงข้างแกง *บูดู* และผักสด (*ผักเหนาะ*) เสมอ

## 2. อนุภูมิภาคทางวัฒนธรรม
| อนุภูมิภาค | บุคลิกของข้าว | เมืองสำคัญ |
|---|---|---|
| **นครศรีธรรมราช** | ข้าวยำน้ำบูดูผสมเครื่องแกงขมิ้น ขนมสารทเดือนสิบ (ขนมลาจากปากพนัง) ข้าวยาคูที่พระบรมธาตุ | นครศรีธรรมราช ปากพนัง หัวไทร |
| **สุราษฎร์ธานีและพัทลุง** | ประเพณีชักพระและขนมต้มห่อใบกะพ้อ | สุราษฎร์ธานี พัทลุง |
| **สงขลา / หาดใหญ่** | ข้าวยำในตลาด สารทเดือนสิบ ผสมผสานไทย-จีน-มลายู | สงขลา หาดใหญ่ |
| **ปัตตานี ยะลา นราธิวาส** (มลายูมุสลิม) | นาซิดาแก ข้าวยำบูดู (นาซิเกอราบู) ข้าวใบยอ | ปัตตานี ยะลา นราธิวาส |
| **ภูเก็ตและพังงา** (เปอรานากัน) | อาหารบาบ๋าฮกเกี้ยน-มลายู ข้าวยำกับผักดองและ *น้ำเคย* | เมืองภูเก็ต พังงา ตะกั่วป่า |
| **ตรัง กระบี่ สตูล** (อันดามัน) | ข้าวยำไม่ใส่บูดู (สตูล) | ตรัง กระบี่ สตูล |
| **ชุมพรและระนอง** | ประตูสู่ภาคใต้ ข้าวยำผักดอง | ชุมพร ระนอง |

## 3. สูตรอาหารในภูมิภาคนี้
| สูตร | ประเภทอาหาร | พื้นที่ |
|---|---|---|
| [ข้าวยำ](recipe_khao_yam.md) | ข้าวยำกับบูดูและผักสมุนไพร | ทั่วภาคใต้ มีแบบปัตตานี นคร และอันดามัน |
| [นาซิดาแก](recipe_nasi_dagae.md) ⚠️ | ข้าวกะทิกับแกงปลาทูน่า | ปัตตานี ยะลา นราธิวาส |
| [ขนมต้ม / ข้าวต้มลูกโยน](recipe_khao_tom_luk_yon.md) | ข้าวเหนียวห่อใบสำหรับออกพรรษา / ชักพระ | สุราษฎร์ธานี พัทลุง นคร; ภาคกลาง |
| [ขนมลา](recipe_khanom_la.md) ⚠️ | แป้งข้าวโรยเป็นเส้นตาข่ายสำหรับสารทเดือนสิบ | นครศรีธรรมราช (ปากพนัง) |
| [ข้าวมธุปายาส / ข้าวยาคู](recipe_khao_mathu_payat.md) ⚠️ | ข้าวทำบุญรสหวานน้ำผึ้ง | นครศรีธรรมราช; ทั่วประเทศ |

ขนมจากข้าวที่พบทั่วประเทศในแผนที่นี้ (หลายอย่างมีแบบฉบับภาคใต้): [ข้าวเหนียวมะม่วง](recipe_khao_niao_mamuang.md), [ข้าวต้มมัด](recipe_khao_tom_mat.md), [ข้าวเหนียวสังขยา](recipe_khao_niao_sangkhaya.md), [ข้าวหมาก](recipe_khao_mak.md), [บัวลอย](recipe_bua_loy.md), [ขนมครก](recipe_khanom_krok.md), [ขนมชั้น](recipe_khanom_chan.md) ส่วน [ข้าวประดับดิน](recipe_khao_pradap_din.md) พิธีกรรมของอีสาน เป็นคู่เทียบฝั่งตะวันออกเฉียงเหนือของสารทเดือนสิบ

⚠️ = แหล่งข้อมูลน้อยหรือเป็นการสร้างสูตรขึ้นใหม่ ดูหมายเหตุความน่าเชื่อถือในแต่ละไฟล์
