# Khao Man Som Tam / ข้าวมันส้มตำ

> ⬅ [หน้าหลัก](README.md) · [ภาคกลาง](provincial_central_thailand.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** กรุงเทพฯ และที่ราบภาคกลาง (ร้านส้มตำแบบภาคกลาง)
*   **Dish Type & Texture:** สำรับข้าว: ข้าวมันกะทิ (*ข้าวมัน*) กับส้มตำมะละกอรสเปรี้ยวหวาน (*ส้มตำไทย*) แกงเผ็ดไก่ และเนื้อฝอยรสหวาน กินด้วยกัน อย่างละหนึ่งช้อน
*   **Traditional Cooking Vessel & Fuel:** หม้อหรือลังถึงสำหรับข้าวมันกะทิ (*หม้อหุงข้าว*) ครกดิน (*ครกดิน*) กับสากไม้สำหรับตำส้มตำ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ศิลปวัฒนธรรมบรรยายถึง*สำรับ*แบบภาคกลางที่ประกอบด้วย*ข้าวมัน* *ส้มตำ* แกงเผ็ดไก่ และเนื้อฝอยทอดหวาน บางครั้งมีน้ำพริกมะขามด้วย และระบุว่าสำรับนี้คล้ายกับสำรับ *nasi lemak* (นาซิเลอมัก) ของมลายูอย่างชัดเจน ([ศิลปวัฒนธรรม](https://www.silpa-mag.com/?p=184)) ส่วนส้มตำเองโดยทั่วไปเชื่อกันว่ามาจากอีสาน (*ตำหมากหุ่ง*) และถูกดัดแปลงในกรุงเทพฯ ให้หวานขึ้น ใส่ถั่วลิสงและกุ้งแห้ง ([ศิลปวัฒนธรรม – เมื่อส้มตำเข้ากรุงเทพฯ](https://www.silpa-mag.com/?p=5140); [มิชลินไกด์ประเทศไทย](https://guide.michelin.com/th/th/article/features/decoding-the-delicious-som-tam)) ⚠️ ไม่มีแหล่งข้อมูลใดระบุช่วงเวลาที่เกิดการจับคู่นี้

**วิทยาศาสตร์การทำอาหาร:** เกลือและน้ำตาลเล็กน้อยในหัวกะทิทำให้ข้าวมันและหวานนิด ๆ เป็นเบาะนุ่มรองรับความเปรี้ยวของมะนาวและความเผ็ดของพริกในส้มตำ

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **สำรับแบบกรุงเทพฯ:** ข้าวมัน + ส้มตำไทย + แกงเผ็ดไก่ + เนื้อฝอย (เนื้อฝอยรสหวาน) ([ศิลปวัฒนธรรม](https://www.silpa-mag.com/?p=184))
*   **ใส่น้ำพริกมะขาม (*น้ำพริกส้มมะขาม*):** เป็นของเสริมในสำรับเดียวกันบางครั้ง ([ศิลปวัฒนธรรม](https://www.silpa-mag.com/?p=184))
*   **คู่เทียบของอีสาน:** ข้าวเหนียวกับ *ตำหมากหุ่ง* ดู[ข้าวเหนียวนึ่ง](recipe_khao_niao_nueng.md)

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: **สำรับแบบกรุงเทพฯ***

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| หัวกะทิ (สำหรับข้าว) | 250 ml |
| เกลือ / น้ำตาล (สำหรับข้าว) | 1 ช้อนชา / 1 ช้อนโต๊ะ |
| มะละกอดิบ ขูดเป็นเส้น | 400 g |
| กระเทียม พริกขี้หนู กุ้งแห้ง ถั่วลิสงคั่ว | 3 กลีบ, 3 เม็ด, 2 ช้อนโต๊ะ, 3 ช้อนโต๊ะ |
| น้ำมะนาว / น้ำปลา / น้ำตาลมะพร้าว | 3 ช้อนโต๊ะ / 2 ช้อนโต๊ะ / 2 ช้อนโต๊ะ |
| มะเขือเทศสีดา ถั่วฝักยาว | 8 ลูก, 4 ฝัก |
| แกงเผ็ดไก่ เนื้อฝอยรสหวาน | สำหรับเสิร์ฟ (≈ 400 ml, 120 g) |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวหอมมะลิ | ข้าวสาร 400 g |
| หัวกะทิ : น้ำ สำหรับหุงข้าว | 250 ml : 300 ml |
| ส้มตำต่อจาน | ≈ 100 g |

### ขั้นตอนการทำทีละขั้น
1. **ข้าวมันกะทิ:** หุงข้าวหอมมะลิที่ซาวแล้ว 400 g กับน้ำ 300 ml เมื่อน้ำซึมหมดแล้ว คลุกหัวกะทิที่อุ่นกับเกลือและน้ำตาลลงไป ปิดฝาระอุ 10 นาที
2. **น้ำปรุง:** ในครกดิน ตำกระเทียมและพริก ใส่น้ำตาลมะพร้าว น้ำปลา และมะนาว คนให้ละลาย
3. **ส้มตำ:** ใส่ถั่วฝักยาวและมะเขือเทศ ตำเบา ๆ พอช้ำ แล้วใส่มะละกอ กุ้งแห้ง และถั่วลิสง ใช้สากและช้อนเคล้าให้เข้ากัน
4. **จัดสำรับ:** เสิร์ฟแต่ละจานพร้อมข้าวมันกะทิ ส้มตำ แกงเผ็ดหนึ่งถ้วย และเนื้อฝอยหวานเล็กน้อย
