# Ruz bi-Djaj ma'a Hashweh / رز بالدجاج مع الحشوة

> ⬅ [หน้าหลัก](README.md) · [ปาเลสไตน์](provincial_palestine.md) · [จอร์แดน](provincial_jordan.md) · [ซีเรีย](provincial_syria.md)

> ⚠️ **หมายเหตุความน่าเชื่อถือของแหล่งข้อมูล:** *hashweh* (ฮัชเวห์ ข้าวปรุงเครื่องเทศกับเนื้อสับและถั่ว) และถาดไก่กับข้าวสำหรับงานเลี้ยงมีหลักฐานบันทึกไว้อย่างดีทั่วปาเลสไตน์ จอร์แดน และซีเรีย อย่างไรก็ตาม ผม**ไม่พบแหล่งข้อมูลใดที่บันทึกความแตกต่างระหว่างเมือง** รูปแบบต่างๆ ใน §3 จึงสร้างขึ้นใหม่จากแนวปฏิบัติทั่วไปของแถบเลแวนต์และมีเครื่องหมายกำกับไว้ ปริมาณในสูตรเป็นแบบแผนสำหรับครัวเรือน

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** เขตเมืองของปาเลสไตน์ (เยรูซาเล็ม นาบลุส รามัลลาห์ เบธเลเฮม) และมีร่วมกันในจอร์แดนและซีเรีย
*   **Dish Type & Texture:** ข้าวสำหรับงานเลี้ยงราดหน้าเนื้อ (*hashweh*) เม็ดข้าวร่วนฟูไม่ติดกันแบบ *mfalfal* (มฟัลฟัล แปลว่า "แบบพริกไทย" หมายถึงเม็ดร่วน) ผัดกับเนื้อสับจนเป็นสีน้ำตาล แล้ววางไก่และถั่วไว้ด้านบน
*   **Traditional Cooking Vessel & Fuel:** หม้อหนัก (*tanjara* ทันจะระห์) บนเตาสำหรับหุงข้าว ไก่นำไปต้มก่อนแล้วจึงอบหรือนำไปทอดในกระทะจนเป็นสีน้ำตาล เสิร์ฟบนถาดใหญ่

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Hashweh* แปลว่า "ไส้" เป็นข้าวที่หุงกับ**เนื้อแกะหรือเนื้อวัวสับ** เครื่องเทศกลิ่นอุ่น และ**เมล็ดสนกับอัลมอนด์คั่ว** ใช้ยัดไส้ไก่ แกะ ผัก และ *kibbeh* (กิบเบห์ ลูกบัลกูร์สอดไส้เนื้อ) และในวันเทศกาลจะเสิร์ฟเป็นอาหารจานหนึ่งในตัวเอง โดยกองบนถาดใต้ไก่ที่ต้มแล้วนำไปอบ ตามธรรมเนียมทำด้วยเนื้อแกะและใช้ยัดไส้สัตว์ทั้งตัว เป็นอาหารที่นิยมในเทศกาลอีสเตอร์และเดือนรอมฎอน และมักทำครั้งละมากๆ เพื่อเลี้ยงคนจำนวนมาก เครื่องเทศหลักคือ "เครื่องเทศเจ็ด/เก้าชนิด" ของแถบเลแวนต์ (*baharat* บะฮารัต: ออลสไปซ์ อบเชย กระวาน กานพลู ลูกจันทน์เทศ พริกไทยดำ ยี่หร่า…) Reem Kassis กล่าวว่าเครื่องเทศผสมเก้าชนิดคือสิ่งที่ทำให้อาหารมีสัมผัส "แบบปาเลสไตน์อย่างชัดเจน"

**วิทยาศาสตร์การทำอาหาร:** เนื้อสัมผัส "เม็ดร่วน" (*mfalfal*) มาจากการล้างแป้งที่ผิวข้าวออก ผัดข้าวในไขมันจนเม็ดขุ่น แล้วหุงในน้ำซุปที่ตวงไว้อย่างแม่นยำโดยไม่คน ผัดเนื้อสับให้เป็นสีน้ำตาลเข้มก่อน เพื่อให้รสจากปฏิกิริยาเมลลาร์ดเคลือบเม็ดข้าว ส่วนถั่วทอดแยกต่างหากแล้วใส่ตอนท้ายเพื่อให้ยังกรอบ ญาติใกล้ชิดของจานนี้คือ *ouzi* (อูซี ข้าวกับเนื้อห่อด้วยแป้งพาย) ของซีเรีย ซึ่งบันทึกไว้ในหน้า [ซีเรีย](provincial_syria.md)

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบเมืองของปาเลสไตน์ (เยรูซาเล็ม นาบลุส):** ไก่บน hashweh กับ**เมล็ดสนและอัลมอนด์** ปรุงรสด้วยออลสไปซ์และอบเชย ⚠️ สร้างขึ้นใหม่
*   **แบบไก่ยัดไส้สำหรับงานเลี้ยง (*djaj mahshi* ดะจาจ มะห์ชี):** หุง hashweh ให้สุกครึ่งหนึ่ง ยัดใส่ในตัวไก่ แล้วนำไก่ไปต้มก่อนอบ เว็บไซต์สูตรอาหารภาษาอาหรับบันทึกไก่ "แบบปาเลสไตน์" ที่ยัดไส้ด้วยข้าว หอมใหญ่ พริกหวาน และไทม์
*   **สำรับแบบจอร์แดน / ค่อนไปทางเบดูอิน:** hashweh เนื้อแกะ บางครั้งกินกับโยเกิร์ต hashweh มีความเกี่ยวข้องกับอาหารแบบเบดูอิน ⚠️ สร้างขึ้นใหม่
*   **สำรับอีสเตอร์และคริสต์มาสของชาวคริสต์:** hashweh รองใต้ไก่หรือไก่งวง (เทียบกับ [arroz con pava](recipe_arroz_con_pava.md) (อาร์โรซ คอน ปาบา ข้าวไก่งวง) สำหรับงานเลี้ยงของบาเลนเซีย) ⚠️ สร้างขึ้นใหม่
*   ***hashweh* คริสต์มาสของเบธเลเฮม (ครอบครัว Kattan):** ครอบครัวของเชฟ Fadi Kattan เสิร์ฟ *hashweh* (ข้าวกับเนื้อสับ) ในคืนก่อนวันคริสต์มาส และคุณยายของเขาใส่**เกาลัด**ลงไปด้วย ผู้ปรุงอาหารในเบธเลเฮมยังใช้ไส้แบบเดียวกันนี้ใน [djaj mahshi](recipe_djaj_mahshi.md) และในจานเอกซี่โครงแกะ [taj al-malek](recipe_taj_al_malek.md) (ทาจ อัล-มะลิก) ([Middle East Eye](https://www.middleeasteye.net/discover/christmas-dinner-palestine-bethlehem-dinner))

## 4. สูตรหลัก (สำหรับ 4 คน)
*ฉบับที่นำเสนอ: **ไก่บน hashweh กับเมล็ดสนและอัลมอนด์สำหรับงานเลี้ยง***

### ฐานรสชาติ (El Fondo) (น้ำซุปไก่ / *maraq* มะร็อก)
| ส่วนผสม | ปริมาณ |
|---|---|
| ไก่ทั้งตัวหรือผ่าครึ่ง | 1.4 kg |
| น้ำ | 1.8 L |
| หอมใหญ่ ใบกระวาน ลูกกระวาน อบเชยแท่ง พริกไทยเม็ด | 1 / 2 / 4 / 1 / 6 |
| เครื่องทาสำหรับอบ: ออลสไปซ์ อบเชย เกลือ น้ำมันมะกอก | 1 ช้อนชา / ½ ช้อนชา / — / 2 ช้อนโต๊ะ |

เคี่ยวไก่ **40 นาที** คอยช้อนฟองออก ยกไก่ขึ้น ทาด้วยเครื่องเทศและน้ำมัน แล้วอบที่ 220 °C **20–25 นาที** จนเป็นสีทอง กรองน้ำซุปแล้วเก็บไว้ **≈ 750 ml**

### อัตราส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าว (ข้าวเม็ดกลางของอียิปต์หรือบาสมาติ) ซาวแล้ว | 400 g |
| เนื้อแกะหรือเนื้อวัวสับ | 250 g |
| Samneh (ซัมเนห์ เนยใส) หรือเนย | 40 g |
| น้ำซุปไก่ | ≈ 700–750 ml (บาสมาติ ≈ 1.6 : 1 โดยปริมาตร; ข้าวอียิปต์ ≈ 1.8 : 1) |
| Baharat / เครื่องเทศเจ็ดชนิด | 2 ช้อนชา |
| อบเชย ออลสไปซ์ | อย่างละ ½ ช้อนชา |
| เมล็ดสน + อัลมอนด์ลอกเปลือก ทอดในเนยใสเล็กน้อย | 40 g + 60 g |
| สำหรับเสิร์ฟ: โยเกิร์ตรสธรรมชาติหรือสลัดโยเกิร์ตแตงกวา | — |

### ขั้นตอนการปรุงทีละขั้น
1. **การเตรียม:** ต้มและอบไก่ (ตามด้านบน) ทอดถั่วจนเป็นสีทองแล้ววางพักบนกระดาษ
2. **เนื้อ:** ในหม้อ ละลาย samneh แล้วผัดเนื้อสับกับ baharat เกลือ และพริกไทยจนเป็นสีน้ำตาลเข้ม (**8 นาที**) พร้อมยีให้แตกออก
3. **การคั่ว:** ใส่ข้าวที่สะเด็ดน้ำแล้ว ผัด **2–3 นาที** จนเม็ดข้าวขุ่นและเป็นเงา
4. **การเติมของเหลว:** เทน้ำซุปเดือดลงไปแล้วปรับเกลือ ต้มให้เดือดอีกครั้ง
5. **การควบคุมไฟ:** ปิดฝาแล้วหุงด้วยไฟอ่อนที่สุด **15–18 นาที** โดยไม่คน
6. **ขั้นตอนสุดท้าย/การพัก:** ยกลงจากเตา ปิดฝาพักไว้ **10 นาที** (ผ้าที่รองใต้ฝาจะช่วยซับไอน้ำ) ใช้ส้อมเขี่ยให้ร่วน กองบนถาด วางไก่ไว้ด้านบนแล้วโรยถั่วให้ทั่ว เสิร์ฟกับโยเกิร์ต
