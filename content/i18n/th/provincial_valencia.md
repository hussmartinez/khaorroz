# Província de València / Provincia de Valencia

> ⬅ [หน้าหลัก](README.md) · [Alacant](provincial_alicante.md) · [Castelló](provincial_castellon.md)

## 1. ภาพรวม
จังหวัดบาเลนเซีย (Valencia) คือหัวใจทางประวัติศาสตร์ของอาหารข้าวแบบบาเลนเซีย พื้นที่ชุ่มน้ำ **Albufera** (อัลบูเฟรา) และที่ราบลุ่ม **La Ribera** (ลา ริเบรา) เป็นที่ตั้งของนาข้าวส่วนใหญ่ภายใต้ **D.O. Arròs de València** (ตราแหล่งกำเนิดข้าวบาเลนเซีย; สายพันธุ์ Senia, Bahía, Albufera, Bomba, J. Sendra) การทำนาข้าวที่นี่ย้อนกลับไปถึงสมัยอันดาลุส (Al-Andalus) ซึ่งเป็นยุคที่วางเครือข่ายคลองชลประทาน (*séquies*) ที่ปัจจุบันยังอยู่ภายใต้การดูแลของ **Tribunal de les Aigües** (ศาลน้ำแห่งบาเลนเซีย มรดกทางวัฒนธรรมที่จับต้องไม่ได้ของยูเนสโก) การหุงข้าวแบบบาเลนเซียมีหัวใจอยู่ที่**ไฟฟืน** **กระทะ paella ที่กว้างและตื้น** และผลผลิตจาก *horta* (ออร์ตา สวนผักชานเมือง) ได้แก่ *bajoqueta* (บาโคเกตา ถั่วแขกฝักแบน) *garrofó* (การ์โรโฟ ถั่วลิมาเมล็ดใหญ่) มะเขือเทศ อาร์ติโชก และในอดีตยังมีกระต่าย ไก่ เป็ด และหอยทากด้วย

## 2. อนุภูมิภาคทางวัฒนธรรม
| อนุภูมิภาค (comarca) | เอกลักษณ์ของอาหารข้าว | เมืองสำคัญ |
|---|---|---|
| **L'Horta de València** (Nord, Sud, Oest) | Paella valenciana, arròs amb bledes, fesols i naps | València, Meliana, Alboraia, Torrent, Benissanó (ชายขอบ Camp de Túria) |
| **L'Albufera / La Ribera Baixa** | Paella ใส่เป็ด ถิ่นของ all i pebre ปาเอยาแบบชาวนาในทุ่งนา | Sueca, El Palmar, Cullera, Silla, Catarroja |
| **La Ribera Alta** | ปาเอยาที่ผัดเนื้อจนเหลืองนาน ข้าวแบบ caldoso ช่วงฤดูหนาว | Alzira, Algemesí, Carcaixent |
| **La Costera / La Vall d'Albaida** | ถิ่นกำเนิดของ **Arròs al forn** | Xàtiva, Ontinyent |
| **La Safor** | ข้าวอาหารทะเล ข้าวแบบ caldoso, arròs negre | Gandia, Oliva, Xeraco |
| **ชายฝั่งเมืองบาเลนเซีย** | Arròs negre, senyoret, a banda | El Cabanyal, El Grau, La Malva-rosa |
| **พื้นที่ด้านใน (Utiel-Requena, Serranos, Camp de Túria)** | ข้าวกระต่ายกับหอยทากที่หุงด้วยไฟกิ่งองุ่น (sarmiento) ข้าว caldoso เข้มข้นจากเทศกาลฆ่าหมู (matança) | Requena, Utiel, Llíria, Chelva |
