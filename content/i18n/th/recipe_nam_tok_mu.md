# Nam Tok Mu / น้ำตกหมู

> ⬅ [หน้าหลัก](README.md) · [อีสาน (ภาคตะวันออกเฉียงเหนือ)](provincial_isan.md)

> ⚠️ **หมายเหตุความน่าเชื่อถือของแหล่งข้อมูล:** ที่มาของชื่อ ("น้ำตก") มักอธิบายกันว่ามาจากน้ำในเนื้อที่หยดลงบนถ่าน แต่คำอธิบายนี้มาจากเว็บบอร์ด ไม่ใช่แหล่งข้อมูลที่น่าเชื่อถือ

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** อีสานและลาว ปัจจุบันเป็นเมนูมาตรฐานในร้านอาหารอีสานทั่วประเทศ
*   **Dish Type & Texture:** กับข้าวกินกับข้าว: หมูย่างหั่นชิ้น (มักเป็นคอหมู) ปรุงแบบลาบด้วยมะนาว น้ำปลา พริก หอมแดง สะระแหน่ และข้าวคั่ว เป็นชิ้นฉ่ำ ๆ ที่เกรียมไฟแทนที่จะเป็นเนื้อสับ กินกับข้าวเหนียว
*   **Traditional Cooking Vessel & Fuel:** เตาถ่าน (*เตาถ่าน*) ครกหินสำหรับตำข้าวคั่ว ข้าวเหนียวนึ่งใน *หวด* เสิร์ฟใน *กระติ๊บ*

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
น้ำตกคือญาติแบบย่างของลาบ คนครัวระบุว่าทั้งสองอย่าง "คล้ายกันมาก" ต่างกันที่การหั่น — เนื้อสับเป็นลาบ เนื้อหั่นชิ้นเป็นน้ำตก ([Pholfoodmafia – น้ำตกคอหมูย่าง](https://www.pholfoodmafia.com/?p=26087)) งานอ้างอิงภาษาอังกฤษจัด *น้ำตกหมู* เป็นอาหารอีสาน ([Wikipedia – Nam tok mu](https://en.wikipedia.org/wiki/Nam_tok_mu)) ชื่อนี้มักอธิบายว่ามาจากน้ำที่หยดจากเนื้อย่างลงบนถ่าน แต่เป็นคำอธิบายแบบชาวบ้าน ⚠️ ([เว็บบอร์ดเรือนไทย](https://www.tapatalk.com/groups/rueanthai2/-t4146435.html)) ข้าวคั่วเป็นสิ่งจำเป็น ประมาณ 1½ ช้อนโต๊ะต่อเนื้อ 300 ก. งาคั่วเป็นตัวแทนแบบสมัยใหม่ ([Pholfoodmafia](https://www.pholfoodmafia.com/?p=26087); [Wongnai](https://www.wongnai.com/recipes/ugc/a65a54ddef524dcbb926f51cd5d29127))

**วิทยาศาสตร์การครัว:** การย่างส่วนที่มีมันอย่างคอหมูทำให้มันละลายออกและผิวเกรียม การหั่นบาง ๆ และคลุกน้ำปรุงขณะยังอุ่นทำให้น้ำปรุงรสเปรี้ยวซึมเข้าเนื้อ

## 3. ความแตกต่างของแต่ละท้องถิ่น (สำคัญ)
*   **คอหมูย่าง:** ส่วนดั้งเดิมที่นิยมใช้ ([Pholfoodmafia](https://www.pholfoodmafia.com/?p=26087))
*   **แบบหมูทอด (คอหมูทอด):** แบบสมัยใหม่ ([Pholfoodmafia – น้ำตกหมูทอด](https://www.pholfoodmafia.com/?p=39935))
*   **น้ำตกเนื้อ (*น้ำตกเนื้อ*):** พบทั่วไปในอีสานและลาว

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: น้ำตกคอหมูย่าง*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| คอหมู | 500 ก. |
| น้ำปลา | 2½ ช้อนโต๊ะ |
| น้ำมะนาว | 3 ช้อนโต๊ะ |
| พริกป่น | 1–2 ช้อนชา |
| ข้าวคั่ว (ข้าวคั่วป่น) | 2 ช้อนโต๊ะ |
| หอมแดงซอย / สะระแหน่ / ต้นหอม / ผักชีฝรั่ง | 3 หัว / 1 กำมือ |
| ข้าวเหนียว แช่น้ำ 6–8 ชม. | 300 ก. |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเหนียว | ข้าวสาร 300 ก. |
| ข้าวคั่ว : เนื้อ | 1½ ช้อนโต๊ะ : 300 ก. |

### ขั้นตอนการทำทีละขั้น
1. **ข้าว:** แช่ข้าวเหนียว 6–8 ชม. สะเด็ดน้ำ แล้วนึ่งใน *หวด* ไม้ไผ่สานบนหม้อน้ำเดือด 20–25 นาที กลับก้อนข้าวหนึ่งครั้งตอนครึ่งทาง เก็บให้อุ่นใน *กระติ๊บ* ที่มีฝาปิด
2. **ย่าง:** โรยเกลือคอหมูบาง ๆ แล้วย่างบนถ่านไฟกลางจนผิวนอกเกรียมและข้างในพอสุก (12–15 นาที) พักไว้ 5 นาทีแล้วหั่นบาง ๆ
3. **ปรุง:** คลุกหมูที่ยังอุ่นกับน้ำปลา มะนาว และพริก แล้วใส่หอมแดงและผักสมุนไพร
4. **จบ:** ใส่ข้าวคั่วเป็นอย่างสุดท้าย เสิร์ฟกับข้าวเหนียวและผักสด
