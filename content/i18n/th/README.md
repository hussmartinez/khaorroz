# Arrossos d'Espanya: แผนที่ภาคสนามของอาหารข้าวสเปน

แผนที่อาหารข้าวฉบับละเอียดหลายภาษา (Castellano / Valencià / Català / อังกฤษ) ที่รวบรวมขนบการทำข้าวของสเปน โดยมีรากฐานอยู่ที่ **Comunitat Valenciana** (València, Alacant/Alicante, Castelló/Castellón) และขยายไปยังทุกภูมิภาคที่ทำอาหารข้าวในสเปน **108 สูตร**บันทึก**ความแตกต่างแบบเมืองต่อเมือง**ไว้ทุกที่ที่มีแหล่งข้อมูลรองรับ รวมถึงข้าวประจำหมู่บ้านที่ถูกลืมและใกล้สูญหาย หากต้องการอ่านเรื่องราวฉบับเต็ม ดู [ประวัติศาสตร์ข้าวในสเปน](history.md)

## 1. วิธีใช้แผนที่เล่มนี้
*   **หน้าภูมิภาค** อธิบายอนุภูมิภาคทางวัฒนธรรมและลิงก์ไปยังสูตรอาหารของแต่ละพื้นที่
*   **ไฟล์สูตรอาหาร** ใช้โครงสร้างตายตัว ได้แก่ ภูมิศาสตร์และเนื้อสัมผัส → บริบททางประวัติศาสตร์และวัฒนธรรม → ความแตกต่างแบบเมืองต่อเมือง → สูตรหลักสำหรับ 4 คน → ลิงก์แหล่งอ้างอิง → **อาหารที่เกี่ยวข้อง** (อาหารญาติในเมืองและภูมิภาคอื่น จัดกลุ่มตามตระกูลอาหาร)
*   **การตั้งชื่อ:** อาหารแต่ละจานมีทั้งชื่อภาษาสเปนและชื่อท้องถิ่น (*Arroz* / *Arròs* แปลว่าข้าว, *Paella*, *Caldero*)
*   **⚠️ เครื่องหมายระดับความเชื่อมั่น:** อาหารที่มีข้อมูลน้อยจะมีหมายเหตุระบุไว้ชัดเจน และความแตกต่างที่สร้างขึ้นใหม่จะถูกระบุว่าเป็นเช่นนั้น โปรดตรวจสอบในท้องถิ่นก่อนอ้างอิงว่าเป็นแบบฉบับมาตรฐาน
*   **ปริมาณ** คิดสำหรับ 4 คน สัดส่วนของเหลวขึ้นกับสายพันธุ์ข้าว โดยข้าว Bomba ดูดซับน้ำได้มากกว่า Senia/Bahía ประมาณ 15–20 %

## 4. ตระกูลอาหาร (ญาติข้ามภูมิภาค)

## 7. อภิธานศัพท์เทคนิคที่ใช้ร่วมกัน
| คำศัพท์ | ความหมาย |
|---|---|
| **Fondo** | ฐานรส ได้จากโปรตีนที่ผัดจนเหลือง + sofrito + น้ำซุปที่เคี่ยวจนงวด |
| **Sofregit / Sofrito** | กระเทียมและมะเขือเทศ (± ปาปริกา) ผัดจนข้นเหมือนแยม ข้าวแบบ seco ของบาเลนเซียส่วนใหญ่ไม่ใส่หัวหอม |
| **Salmorreta** | ซอสข้นแบบ Alicante ทำจาก ñora กระเทียม มะเขือเทศ และพาร์สลีย์ |
| **Ñora** | พริกหวานตากแห้งเม็ดกลมเล็ก (จากลุ่มน้ำ Segura) ทอดเพียงไม่กี่วินาทีเท่านั้น |
| **Picada** | เครื่องที่โขลกด้วยครก (กระเทียม ñora พาร์สลีย์ ขนมปังทอดหรืออัลมอนด์) แล้วคนลงในน้ำซุป |
| **Socarrat** | ข้าวตังก้นกระทะที่เกิดจากการเคี่ยวจนคาราเมล เกิดขึ้นในช่วง 1–2 นาทีสุดท้าย |
| **Sarmiento / Sarment** | กิ่งองุ่นที่ตัดแต่ง ให้ไฟแรงจัดและร้อนเร็ว |
| **Serranas / Vaquetes** | หอยทากภูเขา (*Sphincterochila* / *Iberus*) |
| **Morralla** | ปลาหินตัวเล็กหลายชนิดรวมกันสำหรับทำน้ำสต็อก |
| **Allioli** | ซอสอิมัลชันจากกระเทียม + น้ำมันมะกอก กินคู่กับข้าวอาหารทะเล |

## 8. ระเบียบวิธีและข้อจำกัด
*   การค้นคว้าทำเป็นภาษาสเปน ภาษาบาเลนเซีย/คาตาลัน และภาษาอังกฤษ โดยใช้คำเรียก "Paella", "Arroz…" และ "Arròs…" แหล่งข้อมูลจัดลำดับความสำคัญดังนี้ (1) เอกสารของ Generalitat (รัฐบาลแคว้น) หน่วยงานท่องเที่ยวระดับเทศบาล และศาลาว่าการเมือง (2) สื่อมวลชนระดับภูมิภาค (El Español Alicante/Valencia, AQUÍ Medios, Valencia Bonita, Alicante Plaza) (3) สื่อสูตรอาหารที่เป็นที่ยอมรับ (Directo al Paladar, 3Cat Cuines, Consum)
*   **ความแตกต่างแบบเมืองต่อเมือง** บันทึกจากแหล่งข้อมูลเหล่านี้เมื่อมีอยู่ ในกรณีที่ข้อมูลมีน้อย (มีเครื่องหมาย ⚠️) ความแตกต่างจะถูกสร้างขึ้นใหม่จากแนวปฏิบัติระดับ comarca (เขตปกครองย่อย) และระบุไว้อย่างชัดเจน โปรดตรวจสอบกับแม่ครัวพ่อครัวในท้องถิ่นก่อนอ้างอิงว่าเป็นแบบฉบับมาตรฐาน
