# Khao Phan Phak (Laplae Steamed Rice Sheets with Vegetables) / ข้าวพันผัก

> ⬅ [หน้าหลัก](README.md) · [ภาคเหนือ (ล้านนา)](provincial_lanna.md)

> ⚠️ **หมายเหตุระดับความเชื่อมั่นของแหล่งข้อมูล:** ที่มาและวิธีทำมีบันทึกในสื่อไทยและไทยพีบีเอส แต่ไม่มีแหล่งใดให้ปริมาณ สัดส่วนของแป้งจึงเป็นการสร้างขึ้นใหม่ แม้จะมีคำว่า "ข้าว" ในชื่อ แต่**ไม่มีเมล็ดข้าวเลย**: แผ่นทำจากแป้งข้าวเจ้าและน้ำ

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** อำเภอลับแล จังหวัดอุตรดิตถ์ (ภาคเหนือตอนล่าง) ปัจจุบันมีขายที่พิษณุโลกด้วย
*   **Dish Type & Texture:** แผ่นแป้งข้าวเจ้านึ่ง เกลี่ยแป้งข้าวเจ้าเหลวบาง ๆ บนผ้าที่ขึงไว้เหนือหม้อนึ่ง สุกในไม่กี่วินาที แล้วม้วนห่อผักผัด วุ้นเส้น หรือเนื้อสัตว์ ได้แผ่นที่นุ่ม ใส และยืดหยุ่นเล็กน้อย
*   **Traditional Cooking Vessel & Fuel:** หม้อดินใส่น้ำเดือดที่ขึงผ้าตึงไว้ที่ปากหม้อ (*ปากหม้อ*) ฝาครอบทรงโดม และไม้ไผ่สำหรับลอกแผ่นแป้ง บนเตาฟืน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*ข้าวพันผัก* ("ข้าวที่พันรอบผัก") เป็นอาหารพื้นถิ่นของ**ลับแล** ชาวบ้านที่นั่นทำ**ข้าวแคบ** แผ่นแป้งข้าวเจ้าตากแดดที่เก็บได้นานและพกไปสวนไปไร่ได้ แผ่นนึ่งสดที่ห่อผักจึงพัฒนามาจากขนบนี้ ([ไทยโพสต์](https://www.thaipost.net/main/detail/57089); [ไทยรัฐ](https://www.thairath.co.th/lifestyle/life/2866199)) ข้าวแคบแห้งยังใช้ม้วนเส้นหมี่ปรุงรสเป็น*หมี่พัน* ([MGR Online](https://mgronline.com/travel/detail/9580000111801)) วิธีทำคล้ายกับ*ข้าวเกรียบปากหม้อ*ของภาคกลาง ร้านสมัยใหม่เพิ่มไข่ เนื้อสัตว์ และเส้นชนิดอื่น ([ไทยพีบีเอส](https://www.thaipbs.or.th/program/KonSuRoak/watch/150079))

**วิทยาศาสตร์การทำอาหาร:** ชั้นแป้งข้าวเจ้าที่บางมากจะเกิดเจลาติไนเซชันแทบทันทีในไอน้ำที่ 100 °C และเซ็ตตัวเป็นแผ่นฟิล์มที่เกาะกัน การใช้แป้งข้าวเจ้าแทนแป้งสาลีทำให้แผ่นปราศจากกลูเตนและใสเล็กน้อย

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **ลับแลแบบดั้งเดิม:** แผ่นห่อผักใบเขียวผัด วุ้นเส้น แครอท และกะหล่ำปลี กินกับน้ำมันกระเทียมเจียวและน้ำส้มพริก ([ไทยรัฐ](https://www.thairath.co.th/lifestyle/life/2866199))
*   **ร้านสมัยใหม่ (พิษณุโลก, อุตรดิตถ์):** เพิ่มไข่ หมู หรือเส้นชนิดอื่น ([ไทยโพสต์](https://www.thaipost.net/main/detail/57089))
*   **ข้าวแคบ / หมี่พัน:** แผ่นตากแดดม้วนห่อเส้นหมี่ปรุงรส ([MGR Online](https://mgronline.com/travel/detail/9580000111801))

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่ใช้เป็นตัวแทน: ข้าวพันผักลับแลไส้ผัก (สัดส่วนแป้งสร้างขึ้นใหม่)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| แป้งข้าวเจ้า | 200 g |
| แป้งมันสำปะหลัง | 2 ช้อนโต๊ะ |
| น้ำ | 500 ml |
| เกลือ | ½ ช้อนชา |
| ผักรวม (กะหล่ำปลี แครอท ผักบุ้ง) หั่นฝอย | 400 g |
| วุ้นเส้น แช่น้ำแล้ว | 50 g |
| กระเทียมสับ + น้ำมัน | 4 กลีบ + 3 ช้อนโต๊ะ |
| ซีอิ๊ว / น้ำปลา | 1 ช้อนโต๊ะ / 1 ช้อนโต๊ะ |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| แป้งต่อแผ่น | ≈ 3 ช้อนโต๊ะ |
| จำนวนแผ่น | ≈ 16 แผ่น |
| เวลานึ่งต่อแผ่น | 30–60 วินาที |

### ขั้นตอนการทำทีละขั้น
1. **แป้ง:** ตีแป้งข้าวเจ้า แป้งมัน เกลือ และน้ำให้เนียน พักไว้ **30 นาที**
2. **ไส้:** เจียวกระเทียมในน้ำมัน แล้วผัดผักและวุ้นเส้นกับซีอิ๊วและน้ำปลาเร็ว ๆ ให้ผักยังกรอบ
3. **ขึงผ้า:** ขึงผ้าให้ตึงที่ปากหม้อน้ำเดือด แล้วทาน้ำมันบาง ๆ
4. **นึ่งแผ่น:** ตักแป้งหนึ่งกระบวยเกลี่ยเป็นวงกลมบาง ๆ ปิดฝา **30–60 วินาที** จนแผ่นใส แล้วตักไส้วางบนแผ่น
5. **ม้วนและเสิร์ฟ:** ใช้ไม้ไผ่ลอกแผ่นขึ้น พับห่อไส้ แล้วย้ายใส่จาน เสิร์ฟพร้อมน้ำมันกระเทียมเจียวและน้ำส้มพริก
