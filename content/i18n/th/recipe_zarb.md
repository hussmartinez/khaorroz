# Zarb / زرب

> ⬅ [หน้าหลัก](README.md) · [จอร์แดน](provincial_jordan.md)

> ⚠️ **หมายเหตุความน่าเชื่อถือของแหล่งข้อมูล:** zarb (ซัรบ์) ได้รับการบรรยายไว้อย่างกว้างขวาง แต่**ส่วนใหญ่มาจากนักเขียนท่องเที่ยวและแคมป์ใน Wadi Rum** ซึ่งเป็นแหล่งข้อมูลเชิงประชาสัมพันธ์ บวกกับสูตรในบ้านของนักแปลชาวจอร์แดนคนหนึ่ง ไม่มีแหล่งใดให้ปริมาณ และไม่มีแหล่งใดบันทึกความแตกต่างระหว่างชนเผ่าหรือเมือง วิธีการด้านล่างทำตามคำบรรยายเหล่านั้น: หลุมที่ปิดผนึก ชั้นวางหลายชั้น เนื้ออยู่ด้านบน ข้าวและผักอยู่ด้านล่าง ส่วนปริมาณเป็นการสร้างขึ้นใหม่

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ดินแดนเบดูอินทางตอนใต้ของจอร์แดน: Wadi Rum ทะเลทราย Hisma และพื้นที่ตอนในระหว่าง Ma'an–Aqaba ปัจจุบันทำเลี้ยงแขกในแคมป์ทะเลทรายทั่วภาคใต้
*   **Dish Type & Texture:** งานเลี้ยงเตาหลุมแบบเบดูอิน ข้าวปรุงเครื่องเทศนึ่งในถาดปิดฝาใต้เนื้อ รองรับน้ำจากเนื้อ ร่วนฟู ไม่แฉะเลย
*   **Traditional Cooking Vessel & Fuel:** **หลุมที่ขุดในทราย** (หรือถังโลหะที่ฝังดิน) ปูด้วย**ถ่านไม้**ที่ลุกแดง มีชั้นวางโลหะหลายชั้นอยู่ภายใน ปิดหลุมด้วยฝาหรือแผ่นสังกะสี ผ้าห่ม และทราย แล้วปล่อยให้อาหารสุกเป็นเวลาหลายชั่วโมง

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Zarb* คือเตาใต้ดินของชาวเบดูอินในจอร์แดนตอนใต้และคาบสมุทรไซนาย และเป็นชื่อของงานเลี้ยงที่ปรุงในเตานั้นด้วย เนื้อ ไก่ แกะ หรือแพะ วางอยู่บนชั้นบนสุดของชั้นวาง โดยมีถาด**ข้าว** มันฝรั่ง หอมใหญ่ มะเขือเทศ และแครอทอยู่ด้านล่าง หย่อนชั้นวางลงบนถ่านร้อนที่ก้นหลุมทราย แล้วปิดผนึกไม่ให้อะไรเล็ดลอดออกมา หลายชั่วโมงต่อมาจึงเปิดหลุมต่อหน้าแขก เป็นช่วงเวลาการแสดงแห่งการต้อนรับที่แคมป์ใน Wadi Rum ทำให้มีชื่อเสียงในหมู่นักท่องเที่ยว อาหารถูกคว่ำลงบนถาดใหญ่โดยมีข้าวเป็นฐานรอง เหมือนกับ mansaf (มันซัฟ) และกินกับขนมปังและสลัด

นี่คือทางออกของทะเลทรายในการปรุงอาหารโดยไม่มีเตาอบหรือเชื้อเพลิงมากนัก ไม้จำนวนเล็กน้อยที่เผาจนเป็นถ่านแล้วฝังไว้พร้อมอาหารก็เพียงพอจะปรุงอาหารเลี้ยงคนจำนวนมาก ทรายเป็นฉนวนกันความร้อน จึงไม่มีเปลวไฟให้ต้องคอยดูแลและไม่มีลม

**วิทยาศาสตร์การทำอาหาร:** หลุมที่ปิดผนึกทำงานเหมือนเตาอบอุณหภูมิต่ำความชื้นสูง ไอน้ำจากเนื้อและผักเล็ดลอดออกไปไม่ได้ เนื้อส่วนที่มีคอลลาเจนมากจึง**ตุ๋นในไอน้ำของตัวเอง**และนุ่มลงโดยไม่แห้ง ไขมันและน้ำจากเนื้อ**หยดจากชั้นบนลงบนข้าวด้านล่าง** ข้าวจึงได้รสจากเนื้อขณะนึ่ง แหล่งความร้อนค่อยๆ อ่อนลง การปรุงจึงเริ่มด้วยความร้อนสูงและจบอย่างนุ่มนวล ซึ่งเหมาะกับทั้งเนื้อและข้าว

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แคมป์ทะเลทราย Wadi Rum:** มาตรฐานสมัยใหม่ที่มีบันทึก: ไก่และ/หรือเนื้อแกะบนชั้นบนสุด ข้าว มันฝรั่ง หอมใหญ่ และมะเขือเทศอยู่ด้านล่าง เสิร์ฟบนถาดโดยมีข้าวรองใต้เนื้อ พร้อมขนมปังและสลัด
*   **zarb ในบ้าน (จอร์แดนในเมือง):** สูตรของนักแปลชาวจอร์แดนคนหนึ่งใช้**ถังที่ฝังดิน** หมักไก่ด้วย**โยเกิร์ต กระเทียม มะนาว และเครื่องเทศเจ็ดชนิด** ข้าวปรุงรสล่วงหน้าด้วยขมิ้น เทียนสัตตบุษย์ ยี่หร่า อบเชย ลูกกระวาน ใบกระวาน และ**มะนาวแห้ง** พร้อมแครอทและน้ำมะเขือเทศ วางบนชั้นล่างพร้อมมะเขือเทศและหอมใหญ่
*   **รูปแบบตามชนเผ่าหรือภูมิภาค:** ⚠️ ไม่มีบันทึก การใช้เนื้อแกะ แพะ หรือไก่ และเครื่องเทศผสม แตกต่างกันไปตามครอบครัวและแคมป์

## 4. สูตรหลัก (สำหรับ 4 คน)
*ฉบับที่นำเสนอ: **zarb แบบบ้าน / แคมป์** ใส่เนื้อแกะและไก่ ตามการเรียงชั้นที่มีบันทึก ปริมาณสร้างขึ้นใหม่*

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| เนื้อแกะ ชิ้นติดกระดูก (ไหล่) | 800 g |
| ไก่ ตัดสี่ส่วน | 800 g |
| เครื่องหมัก: โยเกิร์ตรสธรรมชาติ / กระเทียม / น้ำมะนาว / น้ำมันมะกอก | 150 g / 4 กลีบ / มะนาว 1 ลูก / 30 ml |
| เครื่องเทศเจ็ดชนิด (*baharat*) + ปาปริกา + เกลือ | 2 ช้อนชา + 1 ช้อนชา + 2 ช้อนชา |
| มันฝรั่ง หั่นแว่นหนา | 4 หัว (600 g) |
| หอมใหญ่ ผ่าสี่ / มะเขือเทศ ผ่าครึ่ง | 3 / 4 |
| แครอท ขูด (สำหรับข้าว) | 2 หัว |

### อัตราส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเม็ดยาว (บาสมาติ) ซาวแล้วแช่น้ำ 20 นาที | 400 g |
| น้ำ + น้ำมะเขือเทศสำหรับข้าว (≈ 1.25 : 1 โดยปริมาตร เพราะข้าวยังได้ไอน้ำด้วย) | 450 ml + 100 ml |
| น้ำมัน / samn (เนยใส) สำหรับข้าว | 40 ml |
| ขมิ้น / เมล็ดยี่หร่า / เมล็ดเทียนสัตตบุษย์ | ½ ช้อนชา / ½ ช้อนชา / ¼ ช้อนชา |
| อบเชยแท่ง / ลูกกระวาน / ใบกระวาน / มะนาวแห้ง (เจาะรู) | 1 / 4 / 2 / 1 |
| ถ่าน | ไฟในหลุมหรือในถังที่เผาจนเหลือถ่านแดงชั้นหนา (≈ 1 ชั่วโมง) |

### ขั้นตอนการปรุงทีละขั้น
1. **หมัก (4 ชั่วโมงหรือข้ามคืน):** คลุกเนื้อแกะและไก่กับเครื่องหมักโยเกิร์ตและเครื่องเทศ
2. **ไฟ:** จุดไฟฟืนในหลุมหรือในถังที่ฝังดิน แล้วเผา**ราว 1 ชั่วโมง** จนได้ถ่านลุกแดงชั้นหนา
3. **ถาดข้าว:** ผัดหอมใหญ่กับเครื่องเทศทั้งเม็ดและขมิ้นในน้ำมัน ใส่แครอท น้ำมะเขือเทศ เกลือ ใบกระวาน และมะนาวแห้ง แล้วใส่ข้าวที่สะเด็ดน้ำแล้วคนให้เข้ากัน เทน้ำลงไป ใส่ในถาดลึกแล้วปิดฟอยล์ให้สนิท
4. **จัดชั้นวาง:** ถาดข้าวและมันฝรั่ง หอมใหญ่ และมะเขือเทศไว้ชั้น**ล่าง** เนื้อไว้ชั้น**บนสุด** เพื่อให้น้ำจากเนื้อหยดลงมา
5. **ฝัง:** หย่อนชั้นวางลงในหลุมเหนือถ่าน ปิดด้วยฝาหรือแผ่นโลหะ ตามด้วยผ้าห่มหรือกระสอบ แล้วกลบด้วย**ทราย** ปิดทุกช่องโหว่ไม่ให้ไอน้ำเล็ดลอด
6. **ปรุง:** ทิ้งไว้ **2.5–3.5 ชั่วโมง** โดยไม่รบกวน
7. **เปิดและเสิร์ฟ:** ขุดชั้นวางขึ้นมาต่อหน้าแขก คว่ำข้าวลงบนถาดใหญ่ วางผักและเนื้อไว้ด้านบน เสิร์ฟกับขนมปัง โยเกิร์ต และสลัด
