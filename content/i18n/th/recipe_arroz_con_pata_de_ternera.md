# Arroz con Pata de Ternera / Arròs amb Pota de Vedella

> ⬅ [หน้าหลัก](README.md) · [จังหวัด Alacant](provincial_alicante.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** L'Alacantí (เมือง Alicante, Sant Vicent del Raspeig, Mutxamel) และพบรูปแบบคล้ายกันใน L'Alcoià และ El Vinalopó
*   **Liquid & Texture Profile:** **Meloso** (ข้าวข้นเยิ้ม) เจลาตินจากขาวัวทำให้เม็ดข้าวเหนียวหนึบและเป็นเงา บางบ้านหุงให้แห้งกว่านี้ในกระทะ paella
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** กระทะ paella ทรงลึก หรือหม้อดิน *cassola* (กาโซลา) ตั้งบนเตาแก๊สหรือไฟฟืน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
นี่คือข้าวคลาสสิกของชนชั้นแรงงานในเมือง Alicante และเป็นข้าว**ฤดูหนาว** ใช้ชิ้นส่วนที่ถูกที่สุดและมีเจลาตินมากที่สุด คือ**ขาลูกวัว** ร่วมกับ**ถั่วลูกไก่** **botifarra de ceba** (โบติฟาร์รา เด เซบา ไส้กรอกเลือดผสมหอมใหญ่) และ **chorizo** (ไส้กรอกหมูรมควันปาปริกา) แคมเปญ "Ciudad del Arroz" (เมืองแห่งข้าว) ของการท่องเที่ยวเมือง Alicante จัดให้ข้าวนี้อยู่ในรายชื่อข้าวสัญลักษณ์ของเมือง โครงสร้างของมันคือ cocido (โกซีโด สตูว์หม้อใหญ่สเปน) ที่กลายมาเป็นข้าว โดยต้มขาวัวล่วงหน้าจนนุ่ม แล้ว**ใช้น้ำต้มเป็นน้ำสต๊อกสำหรับหุงข้าว**

**วิทยาศาสตร์การทำอาหาร:** ขาลูกวัวแทบจะเป็นคอลลาเจนและเนื้อเยื่อเกี่ยวพันล้วนๆ เมื่อเคี่ยว 2–3 ชม. (หรือ 45 นาทีในหม้ออัดแรงดัน) จะปล่อยเจลาตินออกมาจำนวนมาก ซึ่งเคลือบเม็ดข้าว ทำให้ข้าวเป็นเงา และช่วยให้ได้เนื้อสัมผัสแบบ meloso เร็วขึ้น ถั่วลูกไก่ยังเป็นแหล่งแป้งอีกทางหนึ่งด้วย

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)

*   **สไตล์เมือง Alicante:** ขาวัว (pata) + ถั่วลูกไก่ + **botifarra de ceba** + chorizo + มะเขือเทศ มักใช้ฐาน **salmorreta** (ซัลโมร์เรตา ซอสเครื่องปรุงจาก ñora มะเขือเทศ และกระเทียม) หรือ ñora (โญรา พริกแดงแห้งทรงกลม) เนื้อสัมผัสแบบ meloso
*   **สไตล์ Sant Vicent / Mutxamel (Horta d'Alacant):** ช่วงฤดูหนาวใส่ **cardo** (คาร์ดูน ผักตระกูลอาร์ติโชก กินก้าน) และ **penca** (เปนกา ก้านชาร์ด) หุงให้ออกไปทาง caldoso (มีน้ำซุป) มากขึ้นเล็กน้อย
*   **สไตล์ Alcoi / พื้นที่ด้านใน:** ใช้ขาวัวร่วมกับ**ขาหมู** และพริกแห้งแบบ *pericana* (เปริกานา) หุงในกระทะ paella ให้แห้งกว่า

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **เมือง Alicante** (สัดส่วนจาก Turismo de Alicante: ข้าว 400 g, ขาวัว 1 ขา, ถั่วลูกไก่ 250 g, botifarra 2 ลูก, chorizo 50 g)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| ขาลูกวัว (*pota de vedella*) ให้คนขายผ่าให้ | 1 ขา (≈ 1 kg) |
| น้ำ (สำหรับต้มขาวัว) | 3 L |
| ใบกระวาน หอมใหญ่ เกลือ | 1 ใบ / ½ หัว / ตามชอบ |
| ถั่วลูกไก่ต้มสุก | 250 g |
| Botifarra de ceba | 2 ลูก |
| Chorizo | 50 g |
| น้ำมันมะกอก | 60 ml |
| มะเขือเทศสุก ขูด | 150 g |
| กระเทียม | 2 กลีบ |
| Pimentón dulce (ปาปริกาหวาน) (หรือ salmorreta 40 g) | 3 g |
| หญ้าฝรั่น | 0.2 g |

**การสกัดรส:**
1. ลวกขาวัว 5 นาที แล้วเททิ้งน้ำ เติมน้ำใหม่ 3 L ใส่ใบกระวานและหอมใหญ่ เคี่ยว **2.5 ชม.** (หรือ 45 นาทีในหม้ออัดแรงดัน) จนเนื้อหลุดจากกระดูก
2. แกะกระดูกออก หั่นเนื้อและหนังเป็นชิ้นพอดีคำ กรองน้ำต้มเก็บไว้ **1.4 L**
3. ในกระทะ paella ผัด chorizo และ botifarra ที่หั่นแว่น 2 นาที ใส่กระเทียม ตามด้วย pimentón (5 วินาที) แล้วตามด้วยมะเขือเทศ (5 นาที)
4. ใส่ชิ้นขาวัวและถั่วลูกไก่**ก่อน**เติมน้ำสต๊อก คนให้เคลือบทั่ว

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น | 400 g |
| น้ำสต๊อกขาวัว (ร้อนจัด กำลังเดือด) | 1.3–1.4 L |
| เนื้อขาวัว (แกะกระดูกแล้ว) | ≈ 400 g |
| ถั่วลูกไก่ | 250 g |

### ขั้นตอนการทำทีละขั้น
1. **การเตรียม:** ต้มขาวัวไว้ตั้งแต่วันก่อน น้ำสต๊อกจะแข็งตัวเป็นวุ้นในตู้เย็น ซึ่งแสดงว่าทำได้ถูกต้อง
2. **Fondo:** ทำตามข้างต้น
3. **น้ำซุปและข้าว:** เทน้ำสต๊อกขาวัวที่เดือดลงไป เมื่อกลับมาเดือดอีกครั้ง โรยข้าวและหญ้าฝรั่นให้ทั่วเท่าๆ กัน
4. **การคุมไฟ:** ไฟแรง 8 นาที → ไฟกลาง 9–10 นาที คนเบาๆ หนึ่งหรือสองครั้งเพื่อให้ได้เนื้อแบบ meloso
5. **จบงาน/การพัก:** พัก **3 นาที** เสิร์ฟร้อนๆ เพราะข้าวจะแข็งตัวเมื่อเย็นลง
