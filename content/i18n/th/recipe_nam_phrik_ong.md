# Nam Phrik Ong / น้ำพริกอ่อง

> ⬅ [หน้าหลัก](README.md) · [ภาคเหนือ (ล้านนา)](provincial_lanna.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ล้านนา (เชียงใหม่ ลำพูน ลำปาง เชียงราย)
*   **Dish Type & Texture:** กับข้าวกินกับข้าว: น้ำพริกสีส้มแดง ข้น รสเปรี้ยวหวาน ทำจากหมูสับและมะเขือเทศ ผัดกับพริกแกงพริกแห้งและถั่วเน่า (*ถั่วเน่า*) ตักกินกับข้าวเหนียว ผักสดหรือผักนึ่ง และแคบหมู
*   **Traditional Cooking Vessel & Fuel:** ครกหินสำหรับตำพริกแกง และกระทะบนเตาถ่าน ข้าวเหนียวนึ่งใน *หวด* เสิร์ฟใน *กระติ๊บ* / *ก่องข้าว*

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
น้ำพริกอ่องเป็นอาหารภาคเหนือของไทยที่ทำจากหมูสับและมะเขือเทศ กินกับข้าวเหนียว หมู และผักสดอย่างแตงกวาและกะหล่ำปลี บางครั้งกินกับแคบหมู ([Wikipedia – Nam phrik ong](https://en.wikipedia.org/wiki/Nam_phrik_ong)) พริกแกงประกอบด้วยพริกแห้ง เกลือ กระเทียม หอมแดง และกะปิ โดยมี *ถั่วเน่า* (ถั่วเหลืองหมักแผ่น) ให้เอกลักษณ์แบบเหนือ สูตรต่าง ๆ ระบุว่าถ้าหาถั่วเน่าไม่ได้ ใช้กะปิเล็กน้อยแทนได้ ([Food Network Solution – นํ้าพริกอ่อง](https://www.foodnetworksolution.com/cookbook/item/0002/น้ำพริกอ่อง); [กรุงเทพธุรกิจ](https://www.bangkokbiznews.com/lifestyle/951905)) ระดับความเผ็ดแตกต่างกันมากในแต่ละบ้าน ([Wikibooks – Nam Phrik Ong](https://en.wikibooks.org/wiki/Cookbook:Nam_Phrik_Ong_(Thai_Pork_and_Tomato_Dip)))

**วิทยาศาสตร์การครัว:** การผัดพริกแกงก่อนช่วยปลุกกลิ่นพริกและถั่วเหลืองหมักในไขมัน การเคี่ยวมะเขือเทศจนงวดช่วยระเหยน้ำออกและทำให้ความเปรี้ยวและความหวานเข้มข้นขึ้นจนเป็นซอสข้นที่ตักได้

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: น้ำพริกอ่องหมูแบบเชียงใหม่*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| พริกแห้ง แช่น้ำ | 8 เม็ด |
| หอมแดง / กระเทียม | 5 หัว / 6 กลีบ |
| ถั่วเน่าแผ่น (ถั่วเหลืองหมัก) ปิ้ง | 1 แผ่น |
| กะปิ / เกลือ | 1 ช้อนชา / ½ ช้อนชา |
| หมูสับ | 250 ก. |
| มะเขือเทศลูกเล็ก หั่น | 300 ก. |
| น้ำมัน | 2 ช้อนโต๊ะ |
| ข้าวเหนียว แช่น้ำ 6–8 ชม. | 300 ก. |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเหนียว | ข้าวสาร 300 ก. |
| พริกแกง : หมู : มะเขือเทศ | ≈ 3 ช้อนโต๊ะ : 250 ก. : 300 ก. |

### ขั้นตอนการทำทีละขั้น
1. **ข้าว:** แช่ข้าวเหนียว 6–8 ชม. สะเด็ดน้ำ แล้วนึ่งใน *หวด* ไม้ไผ่สานบนหม้อน้ำเดือด 20–25 นาที กลับก้อนข้าวหนึ่งครั้งตอนครึ่งทาง เก็บให้อุ่นใน *กระติ๊บ* ที่มีฝาปิด
2. **พริกแกง:** ตำพริกกับเกลือ แล้วใส่หอมแดง กระเทียม ถั่วเน่า และกะปิ ตำต่อ
3. **ผัด:** ผัดพริกแกงในน้ำมันจนหอม ใส่หมูสับผัดจนสุก ใส่มะเขือเทศแล้วเคี่ยวจนข้น (10–15 นาที)
4. **เสิร์ฟ:** กับข้าวเหนียว แตงกวา กะหล่ำปลี ถั่วฝักยาว และแคบหมู
