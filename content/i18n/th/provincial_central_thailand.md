# Central Thailand / ภาคกลาง

> ⬅ [หน้าหลัก](README.md)

## 1. ภาพรวม
ที่ราบภาคกลาง ซึ่งเป็นที่ราบน้ำท่วมถึงของแม่น้ำ **เจ้าพระยา** และลำน้ำสาขา ตั้งแต่ชัยนาทลงไปถึงอ่าวไทย คืออู่ข้าวอู่น้ำทางประวัติศาสตร์ของไทยและเป็นที่ตั้งของราชธานีทุกแห่งนับตั้งแต่อยุธยา (1351) ที่นี่ ข้าวหมายถึง **ข้าวสวย** คือข้าวเจ้าที่นึ่งหรือหุงจนเมล็ดร่วนฟู กินกับสำรับแกง น้ำพริก และต้มต่าง ๆ สิ่งนี้ทำให้ภาคกลางแตกต่างจากวัฒนธรรมข้าวเหนียวของภาคเหนือ (ล้านนา) และภาคอีสาน ข้าวหอม **ขาวดอกมะลิ 105** ("ข้าวหอมมะลิ") คัดเลือกมาจากรวงข้าว 1 ใน 199 รวงที่สุนทร สีหะเนิน เจ้าหน้าที่กรมการข้าว เก็บรวบรวมจาก **ฉะเชิงเทรา** (อำเภอบางคล้า) ในปี 1950–51 ทดสอบที่สถานีโคกสำโรง (ลพบุรี) และรับรองพันธุ์เมื่อวันที่ 25 พฤษภาคม 1959 ต่อมาได้พบบ้านที่แท้จริงในทุ่งนาแห้งแล้งของทุ่งกุลาร้องไห้ในภาคอีสาน ([Matichon](https://www.matichon.co.th/education/news_342342); [Silpa-mag](https://www.silpa-mag.com/?p=51247)) ⚠️ ชาวบ้านอำเภอบ้านโพธิ์อ้างว่าพันธุ์นี้มาจากอำเภอของตน ไม่ใช่บางคล้า ([Matichon](https://www.matichon.co.th/local/news_163253))

ชุมชนสี่กลุ่มหล่อหลอมอาหารข้าวของภูมิภาคนี้:
*   **ราชสำนักไทย** ห้องเครื่องในวังสมัยอยุธยาและต่อมาในสมัยรัตนโกสินทร์ได้ขัดเกลาอาหารอย่าง [ข้าวแช่](recipe_khao_chae.md) และ [ข้าวตังหน้าตั้ง](recipe_khao_tang_na_tang.md)
*   **ผู้อพยพชาวจีน-ไทย** ชาวจีนแต้จิ๋ว ไหหลำ และกวางตุ้ง ได้มอบอาหารจานเดียวให้กรุงเทพฯ ได้แก่ [ข้าวมันไก่](recipe_khao_man_kai.md) [ข้าวขาหมู](recipe_khao_kha_mu.md) [ข้าวหมูแดง](recipe_khao_mu_daeng.md) [ข้าวต้ม](recipe_khao_tom.md) [โจ๊ก](recipe_jok.md) และ [ข้าวผัด](recipe_khao_phat.md)
*   **ชาวไทยมุสลิม** ชุมชนไทยมุสลิมในกรุงเทพฯ นำ [ข้าวหมกไก่](recipe_khao_mok_kai.md) ซึ่งคล้ายบิรยานีเข้ามา
*   **ชาวมอญ** ชาวมอญในปทุมธานี ปากเกร็ด (เกาะเกร็ด) พระประแดง และราชบุรี เป็นต้นกำเนิดของข้าวสงกรานต์ที่กลายมาเป็นข้าวแช่

**ส่วนอื่น ๆ ในหมวดไทย:** อาหารข้าวเหนียวของภาคเหนือและอีสาน อาหารข้าวของภาคใต้ (เช่น ข้าวยำ) ขนมจากข้าวและข้าวในพิธีกรรม รวมถึงการสร้างสูตรขึ้นใหม่จากหลักฐานทางประวัติศาสตร์สมัยสุโขทัย/อยุธยา ล้วนมีหน้าของตนเอง

## 2. อนุภูมิภาคทางวัฒนธรรม
| อนุภูมิภาค | บุคลิกของข้าว | สถานที่สำคัญ |
|---|---|---|
| **กรุงเทพฯ / รัตนโกสินทร์** | อาหารชาววัง ข้าวจานเดียวแบบจีน-ไทย ร้านข้าวราดแกง ข้าวหมกแบบไทยมุสลิม | เกาะรัตนโกสินทร์ เยาวราช/ตลาดน้อย บางรัก นางเลิ้ง บางลำพู |
| **อยุธยา** | ราชสำนักนานาชาติและย่านมุสลิมของราชธานีเก่า | อยุธยา บางปะอิน |
| **สุพรรณบุรี / ชัยนาท / อ่างทอง** | ใจกลางที่ราบลุ่มนาข้าว ข้าวสวยประจำวันกับแกงและน้ำพริก | สุพรรณบุรี ชัยนาท |
| **เพชรบุรี** | ขนมหวานที่เชื่อมโยงกับวังและข้าวแช่ (พระนครคีรี ท่ายาง) | ตัวเมืองเพชรบุรี ท่ายาง |
| **ราชบุรี / ปทุมธานี / นนทบุรี (มอญ)** | ข้าวสงกรานต์ของชาวมอญ (ข้าวแช่) | เกาะเกร็ด ปทุมธานี พระประแดง |
| **ฉะเชิงเทรา** | บ้านเกิดของขาวดอกมะลิ 105 | บางคล้า บ้านโพธิ์ |
| **ชลบุรี / ชายฝั่งตะวันออก / จันทบุรี** | อาหารทะเลและข้าวแบบจีน-ไทยชายฝั่ง | ชลบุรี จันทบุรี |
