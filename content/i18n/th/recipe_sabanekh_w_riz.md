# Sabanekh w Riz / سبانخ ورز

> ⬅ [หน้าหลัก](README.md) · [เลบานอน](provincial_lebanon.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ทั่วทั้งเลบานอนในฤดูหนาวและฤดูใบไม้ผลิ ซึ่งเป็นฤดูของผักโขม
*   **Dish Type & Texture:** สตูว์ราดข้าว (*yakhnet sabanekh* ยัคเนต ซะบาเนิค) ผักโขมสลดกับเนื้อสับหรือเนื้อแกะ หอมใหญ่ กระเทียม และผักชี ปิดท้ายด้วยน้ำมะนาวและเมล็ดสนคั่ว เป็นสตูว์ผักสีเขียวรสเปรี้ยวสดชื่น เสิร์ฟราดบนข้าวเส้นหมี่
*   **Traditional Cooking Vessel & Fuel:** หม้อปากกว้างบนเตา และกระทะเล็กสำหรับคั่วเมล็ดสน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Sabanekh w riz* (ซะบาเนิค วะ ริซ "ผักโขมกับข้าว") เป็นหนึ่งในสตูว์บ้านๆ ของเลบานอนที่ทำได้เร็วที่สุด หลายสูตรใช้เวลาราว 30 นาที เอกลักษณ์ของจานนี้คือรส**เปรี้ยวมะนาว**ตอนท้ายและ**เมล็ดสนคั่ว** กินราดบนข้าวเส้นหมี่เช่นเดียวกับ [bazella](recipe_bazella_w_ruz.md) (บะเซลลา สตูว์ถั่วลันเตา) และ [bamieh](recipe_bamyeh_ma_ruz.md) (บัมยะห์ สตูว์กระเจี๊ยบเขียว) และยังมีแบบไม่ใส่เนื้อที่ใช้ถั่วลูกไก่หรือถั่วชนิดอื่นสำหรับวันถือศีลอด

**วิทยาศาสตร์การทำอาหาร:** ผักโขมยุบตัวเหลือราวหนึ่งในสิบของปริมาตรตอนดิบ การใส่ทีละชุดช่วยไม่ให้หม้อมีน้ำท่วม และการปรุงในเวลาสั้นช่วยให้ยังเขียวสด ใส่น้ำมะนาวตอนท้าย เพราะการปรุงนานๆ กับกรดจะทำให้คลอโรฟิลล์กลายเป็นสีเขียวมะกอกอมน้ำตาลหม่นๆ

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบเนื้อวัวสับ:** แบบเร็วสำหรับวันธรรมดา
*   **แบบเนื้อแกะสับกับเมล็ดสน:** แบบที่เข้มข้นกว่า
*   **แบบวีแกน / วันถือศีลอด:** ใช้ถั่วลูกไก่หรือถั่วชนิดอื่นแทนเนื้อ
*   ⚠️ ไม่มีบันทึกความแตกต่างในระดับเมือง

## 4. สูตรหลัก (สำหรับ 4 คน)
*ฉบับที่นำเสนอ: เนื้อแกะสับกับเมล็ดสน*

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| ผักโขมสด ล้างและหั่นแล้ว | 1 kg |
| เนื้อแกะหรือเนื้อวัวสับ | 350 g |
| น้ำมันมะกอก | 3 ช้อนโต๊ะ |
| หอมใหญ่ สับ | 1 หัว |
| กระเทียม บุบ | 4 กลีบ |
| ผักชีสด สับ | ½ กำ |
| เมล็ดสน คั่ว | 40 g |
| น้ำมะนาว | 60 ml |
| เครื่องเทศเจ็ดชนิด เกลือ พริกไทย | 1 ช้อนชา, ตามชอบ |
| น้ำ | ≈ 250 ml |

### อัตราส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเส้นหมี่ | ข้าว 300 g + เส้นหมี่ 50 g |
| ผักโขม (ดิบ) : เนื้อ | ≈ 3 : 1 |

### ขั้นตอนการปรุงทีละขั้น
1. **ฐาน:** ผัดหอมใหญ่ในน้ำมัน ใส่เนื้อแล้วผัดจนเป็นสีน้ำตาลพร้อมยีให้แตก จากนั้นใส่เครื่องเทศ
2. **กระเทียม-ผักชี:** ใส่กระเทียมและผักชี ผัด 1 นาที
3. **ผักโขม:** ใส่ผักโขมทีละชุดพร้อมน้ำ รอให้แต่ละชุดสลดก่อน เคี่ยว **10–15 นาที**
4. **ขั้นตอนสุดท้าย:** ใส่น้ำมะนาวและเมล็ดสนครึ่งหนึ่ง คนให้เข้ากัน แล้วปรับเกลือ
5. **เสิร์ฟ:** เสิร์ฟราดบนข้าวเส้นหมี่ โรยหน้าด้วยเมล็ดสนที่เหลือ
