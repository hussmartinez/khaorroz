# Arroz Marinero Andaluz / Arroz Caldoso Marinero (Málaga y Cádiz)

> ⬅ [หน้าหลัก](README.md) · [Andalucía (แคว้นอันดาลูเซีย)](provincial_andalucia.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** คู่มืออาหารของ Málaga บันทึก "ข้าวน้ำอาหารทะเล" ไว้ในฐานะข้าวประจำเมือง แต่ผู้เขียนไม่พบสูตรมาตรฐานที่ระบุเฉพาะเมือง ความแตกต่างในแต่ละเมืองด้านล่างจึงสร้างขึ้นใหม่จากแนวปฏิบัติทั่วไปของชายฝั่ง โปรดตรวจสอบกับท้องถิ่น

## 1. ข้อมูลภูมิศาสตร์และเนื้อสัมผัส
*   **Primary Geographic Zone:** ชายฝั่งเมดิเตอร์เรเนียนและแอตแลนติกของอันดาลูเซีย ได้แก่ Málaga (El Palo, Pedregalejo), Costa del Sol, Bahía de Cádiz และ Sanlúcar
*   **Liquid & Texture Profile:** **Caldoso** (ข้าวน้ำ)
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** *perol* (หม้อทรงกระทะลึก), *cazuela* (หม้อดินเผา) หรือ *caldero* (หม้อเหล็ก) ทรงลึก บนเตาแก๊สหรือบนกองไฟริมหาด

## 2. ประวัติและบริบททางวัฒนธรรม
ในอันดาลูเซีย ข้าวริมทะเลส่วนใหญ่กินแบบ**มีน้ำซุป** คือหม้อข้าว ปลา และหอยของชาวประมงที่สร้างขึ้นจากน้ำซุป ที่ Málaga "arroz caldoso marinero" นี้ถือกำเนิดจากเรือ *jábega* (เรือประมงพื้นบ้าน) และ *merenderos* (ร้านอาหารริมหาด) ของ El Palo และ Pedregalejo ซึ่งเป็นโลกเดียวกับ *espetos* (ปลาซาร์ดีนเสียบไม้ย่าง) คู่มืออาหารของ Málaga บรรยายว่าเป็นข้าวแบบมีน้ำของ Málaga ที่หล่อหลอมโดยเมืองเดินเรือที่มีปลาจับได้หลากหลาย ไกลออกไปทางตะวันตกที่ Cádiz และ Sanlúcar ตรรกะเดียวกันนี้ทำให้เกิดข้าวที่ใส่ *galeras* (กั้ง) *chirlas* (หอยลายตัวเล็ก) *langostinos* (กุ้ง) และปลาหมึกกระดอง มักเติม manzanilla หรือ fino (เชอร์รี่แห้ง) ลงในฐานเล็กน้อย

**วิทยาศาสตร์การทำอาหาร:** ด้วยอัตราส่วนน้ำซุปประมาณ 5–6:1 เมล็ดข้าวจะสุกขณะจมอยู่ในน้ำ จึงพองตัวสม่ำเสมอโดยไม่เกิดเป็นตัง แป้งที่ปล่อยออกมาทำให้น้ำซุปข้นขึ้นเพียงเล็กน้อย หอยอย่างหอยลายและหอยแมลงภู่จะเปิดฝาในช่วงไม่กี่นาทีสุดท้ายและปล่อยน้ำเค็มรสทะเลลงในน้ำซุปโดยตรง

## 3. ความแตกต่างในแต่ละเมือง (สำคัญมาก — สร้างขึ้นใหม่ โปรดตรวจสอบกับท้องถิ่น)
*   **Málaga (El Palo / Pedregalejo):** Rape (ปลาอังโกะ) *almejas* (หอยลาย) *mejillones* (หอยแมลงภู่) ปลาหมึกกล้วย *sofrito* (เครื่องผัดฐาน) จากหอมใหญ่ + พริกหวานเขียว + มะเขือเทศ มักใส่ *guindilla* (พริกแห้ง) เล็กน้อย
*   **Cádiz (Bahía):** *Chocos* (ปลาหมึกกระดอง) *galeras* กุ้ง langostinos เติม **fino** เล็กน้อย ใส่ผักชีฝรั่งเยอะ
*   **Sanlúcar de Barrameda:** **Langostino de Sanlúcar** (กุ้งแห่ง Sanlúcar) + *manzanilla* ในฐาน น้ำซุปใสและเหลวมาก
*   **หมู่บ้านด้านในของ Costa del Sol:** ผสมอาหารทะเลกับหมูแบบ "arroz campero" (ข้าวชนบท) ไม่ใช่ข้าวแบบ marinero โดยแท้

## 4. สูตรหลัก (สำหรับ 4 ที่)
*สูตรที่นำเสนอ: **Málaga แบบ caldoso***

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| Fumet ปลา (น้ำซุปจากปลาหินและหัวปลา) | 2 L |
| น้ำมันมะกอก | 70 ml |
| หอมใหญ่ สับละเอียด | 1 หัว (150 g) |
| พริกหวานเขียว | 1 ลูก |
| กระเทียม | 3 กลีบ |
| มะเขือเทศสุก ขูด | 200 g |
| Pimentón dulce (ปาปริก้าหวาน) | 3 g |
| Guindilla (ใส่หรือไม่ก็ได้) | 1 เม็ด |
| หญ้าฝรั่น | 0.2 g |

**การสกัดรส:** ผัดหอมใหญ่และพริกหวานด้วยไฟอ่อนให้นิ่ม **10 นาที** ใส่กระเทียมและ pimentón (5 วินาที) ตามด้วยมะเขือเทศ (6 นาที)

### อัตราส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น/เมล็ดกลม | 320 g |
| Fumet | 1.8–2 L (≈ 6:1) |
| ปลาอังโกะ หั่นเต๋า | 300 g |
| ปลาหมึกกล้วย หั่นวง | 200 g |
| หอยลาย + หอยแมลงภู่ | 500 g |
| กุ้งแกะเปลือก | 12 ตัว |

### ขั้นตอนการทำทีละขั้น
1. **เตรียมการ:** แช่หอยลายในน้ำเกลือ 1 ชั่วโมงให้คายทราย ขัดทำความสะอาดหอยแมลงภู่
2. **ผัดไฟแรง:** ผัดปลาหมึกกล้วยในหม้อ 3 นาที แล้วทำ sofrito ต่อในหม้อเดียวกัน
3. **คั่วข้าว:** ใส่ข้าวแล้วคน 1 นาที
4. **น้ำซุป:** เท fumet ที่เดือดและหญ้าฝรั่นลงไป เคี่ยว **12 นาที**
5. **อาหารทะเล:** ใส่ปลาอังโกะ หอยลาย และหอยแมลงภู่ ต้ม **4 นาที** ใส่กุ้งในช่วง **2 นาที**สุดท้าย
6. **ขั้นสุดท้าย:** เสิร์ฟ**ทันที**โดยไม่ต้องพัก โรยผักชีฝรั่งสับ
