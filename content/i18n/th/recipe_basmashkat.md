# Basmashkat (Damascene Meat Rolls Stuffed with Rice) / بسماشكات

> ⬅ [หน้าหลัก](README.md) · [ซีเรีย](provincial_syria.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** มีคำบรรยายในบทสรุปการค้นหาภาษาอาหรับของงานเขียนด้านอาหารดามัสกัส และในเว็บไซต์สูตรอาหารแห่งหนึ่งที่โยงอาหารนี้เข้ากับครัวในวังออตโตมันและงานแต่งงานของดามัสกัส ที่มาของชื่อว่า "ผูก/เย็บ" จากภาษาตุรกีออตโตมันเป็นเพียงการรายงาน ยังไม่ได้รับการยืนยัน และไม่พบแหล่งข้อมูลทางประวัติศาสตร์ชั้นต้น ปริมาณเป็นไปตามเว็บไซต์สูตรอาหาร

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ดามัสกัส
*   **Dish Type & Texture:** อาหารงานเลี้ยงที่มีข้าวอยู่ในเนื้อ: เนื้อลูกวัวหรือเนื้อแกะสไลซ์บางทุบแบน ม้วนรอบไส้ข้าวหญ้าฝรั่นกับเนื้อแกะสับ เย็บปิด จี่ แล้วเคี่ยวในน้ำซุปเนยกับแป้งแบบบางๆ จนนุ่ม ข้าวข้างในนุ่มและหอม ม้วนเนื้อหั่นเป็นชิ้นแล้วเสิร์ฟพร้อมซอส
*   **Traditional Cooking Vessel & Fuel:** หม้อก้นหนา (*tanjara*) บนเตา ด้ายและเข็มสำหรับเย็บม้วนเนื้อ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Basmashkat* (บัสมัชกัต) เป็นหนึ่งในอาหารอวดฝีมือที่ "สูญหาย" ของโต๊ะอาหารดามัสกัสเก่า งานเขียนด้านอาหารของดามัสกัสโยงอาหารนี้กับ**ครัวออตโตมัน**อันยิ่งใหญ่ ที่ซึ่งการจัดแสดงเป็นส่วนหนึ่งของวัฒนธรรมอาหาร และอธิบายว่าชื่อนี้มาจากคำภาษาตุรกีออตโตมันเก่าที่แปลว่า "ผูก" หรือ "เย็บขอบ" ตามด้ายที่ใช้ปิดม้วนแต่ละม้วน อาหารนี้ไม่ใช่อาหารประจำวัน แต่ทำใน**งานแต่งงานและงานฉลองของครอบครัว** เพื่อแสดงความใจกว้างและฝีมือของเจ้าภาพ เนื้อสไลซ์บางทุบจนนุ่ม ยัดไส้ด้วยเนื้อสับ ข้าว ถั่ว และหญ้าฝรั่น ม้วน เย็บ แล้วต้มในน้ำซุปเข้มข้น ([Clove Kitchen – Basmashkat](https://clove.kitchen/recipes/-basmashkat-veal-rolls--RCBc9rE5pHI)) หน้าอาหารซีเรียของ Wikipedia ระบุว่าเป็นม้วนเนื้อยัดไส้ข้าว ([Wikipedia – Syrian cuisine](https://en.wikipedia.org/wiki/Syrian_cuisine)) ⚠️ (เป็นเพียงรายการ)

อาหารนี้เป็นญาติฝั่งดามัสกัสของแกะยัดไส้ทั้งตัวของอเลปโปสมัยออตโตมัน ([kharuf mahshi](recipe_kharuf_mahshi_halabi.md)) และของผักยัดไส้ข้าว (*mahashi*): ใช้ *hashweh* (ไส้ข้าวกับเนื้อ) แบบเดียวกัน แต่ห่อด้วยเนื้อแทนผัก

**วิทยาศาสตร์การทำอาหาร:** ข้าว**หุงสุกครึ่งเดียว**ก่อนยัดไส้ เพื่อให้สุกต่อในม้วนโดยดูดซึมน้ำจากเนื้อโดยไม่ทำให้ม้วนแตก การคลุกแป้งบางๆ และจี่เร็วๆ ช่วยผนึกผิว จากนั้นน้ำซุปที่ทำให้ข้นด้วยรูซ์ตุ๋นม้วนเนื้ออย่างอ่อนโยน 45 นาทีจนเนื้อที่ทุบแล้วนุ่ม

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบงานแต่งงานของดามัสกัส:** เนื้อแกะหรือเนื้อลูกวัวสไลซ์ ไส้ข้าว-เนื้อ-หญ้าฝรั่นใส่เม็ดสน เย็บด้วยด้ายแล้วต้มในน้ำซุป
*   **แบบร้านอาหารสมัยใหม่:** สกาลอปปินีเนื้อลูกวัว ใช้ไม้จิ้มฟันแทนด้าย ซอสเนยกับแป้ง เสิร์ฟกับข้าว มันฝรั่งทอด หรือมันฝรั่งบด
*   ⚠️ ไม่มีบันทึกแบบของเมืองอื่น อาหารดามัสกัส *al-basha wa ʿasakru* ([ดู](recipe_al_basha_w_asakru.md)) ไม่เกี่ยวข้องกัน แม้จะมีเรื่องเล่าแบบออตโตมันคล้ายกัน

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: **ม้วนเนื้องานฉลองแบบดามัสกัส** (สัดส่วนตามเว็บไซต์สูตรอาหาร ปรับเป็น 4 คน)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เนื้อลูกวัวหรือเนื้อแกะส่วนขา สไลซ์บางทุบแบน | 700 g (≈ 12 ชิ้น) |
| เนย (สำหรับไส้) | 1½ ช้อนโต๊ะ |
| หอมใหญ่สับละเอียด | 1 หัว |
| เนื้อแกะสับ | 300 g |
| ออลสไปซ์ | ¾ ช้อนชา |
| พริกไทยดำ | ½ ช้อนชา |
| เกลือ | 1½ ช้อนชา |
| เกสรหญ้าฝรั่น แช่ในน้ำอุ่น 2 ช้อนโต๊ะ | 1 หยิบมือ |
| ขมิ้น | ½ ช้อนชา |
| เม็ดสนคั่ว | 3 ช้อนโต๊ะ |
| แป้งสาลี (สำหรับคลุกและทำรูซ์) | 4 ช้อนโต๊ะ |
| เนย (สำหรับจี่และทำซอส) | 3 ช้อนโต๊ะ |
| น้ำซุปเนื้อวัวหรือเนื้อแกะ เดือด | ≈ 1 L |
| ใบกระวาน (bay leaf) | 1 ใบ |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดกลาง ล้างและสะเด็ดน้ำ (สำหรับไส้) | 250 g |
| น้ำซุปสำหรับหุงข้าวไส้ให้สุกครึ่งเดียว | ≈ 300 ml |
| ข้าวเปล่าสำหรับเสิร์ฟ (ไม่ใส่ก็ได้) | 200 g |
| ไส้ต่อเนื้อหนึ่งชิ้น | ≈ 2 ช้อนโต๊ะ |

### ขั้นตอนการทำทีละขั้น
1. **ไส้:** ผัดหอมใหญ่ในเนยจนนุ่ม ใส่เนื้อแกะสับ ออลสไปซ์ พริกไทย และเกลือ ผัดจนเป็นสีน้ำตาล
2. **หุงข้าวครึ่งสุก:** ใส่ข้าว ขมิ้น และน้ำหญ้าฝรั่น คนให้เข้ากัน เติมน้ำซุปเดือด ≈ 300 ml ปิดฝาหุงบนไฟอ่อนมากราว 15 นาทีจนสุกบางส่วน เทลงถาดให้เย็นแล้วคลุกเม็ดสน
3. **ม้วนและเย็บ:** ตักไส้หนึ่งช้อนวางบนเนื้อแต่ละชิ้น ม้วนให้แน่นแล้วเย็บปิดด้วยด้าย (หรือกลัดด้วยไม้จิ้มฟัน) คลุกแป้งบางๆ
4. **จี่:** จี่ม้วนเนื้อในเนย 2 ช้อนโต๊ะจนเป็นสีน้ำตาล ตักขึ้น
5. **ซอส:** ละลายเนย 1 ช้อนโต๊ะ ใส่แป้ง 1 ช้อนโต๊ะ คนให้เข้ากัน แล้วค่อยๆ ตีน้ำซุปเดือดลงไปจนเนียน ใส่ใบกระวานและเกลือ
6. **ตุ๋น:** ใส่ม้วนเนื้อกลับลงไป เคี่ยวเบาๆ ราว 45 นาทีจนนุ่ม ดึงด้ายออก หั่นเป็นชิ้น เสิร์ฟกับซอส (และข้าวเปล่าตามชอบ)
