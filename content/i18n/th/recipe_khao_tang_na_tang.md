# Khao Tang Na Tang / ข้าวตังหน้าตั้ง

> ⬅ [หน้าหลัก](README.md) · [ภาคกลางของประเทศไทย](provincial_central_thailand.md)

> ⚠️ **หมายเหตุระดับความเชื่อมั่นของแหล่งข้อมูล:** การบินไทยและแหล่งอื่นบรรยายว่าเคยเป็นสูตรเฉพาะของราชสำนัก แต่ไม่พบแหล่งข้อมูลจากราชสำนักที่ระบุปี อาหารจานนี้ยังถูกกัมพูชาอ้างเป็นของตนในชื่อ *nataing* (นาเตียง) และที่มายังเป็นที่ถกเถียง ในที่นี้จึงนำเสนอว่าเป็นขนบร่วมกัน ส่วนที่มาของชื่อที่ว่า "วิ่งหน้าตั้ง" เป็นเรื่องเล่าพื้นบ้าน ปริมาณเป็นการสร้างขึ้นใหม่

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** กรุงเทพฯ และห้องเครื่องในวังของภาคกลาง ปัจจุบันเป็นของว่างประจำวันทั่วประเทศไทย
*   **Historical Source:** ขนบของว่างชาววังสมัยรัตนโกสินทร์ (ถ่ายทอดปากเปล่า; อ้างถึงใน *Thai Food* ของ David Thompson (เดวิด ทอมป์สัน)) ไม่พบตำราฉบับใดที่ระบุปี
*   **Dish Type & Texture:** ของว่างชาววัง: **ข้าวตังกรอบ** (*ข้าวตัง* ข้าวที่ตากแห้งแล้วทอดจนพองและกรอบแตก) กับน้ำจิ้มรสหวานเค็มเข้มข้นจากหัวกะทิ หมูสับ กุ้ง และถั่วลิสง
*   **Traditional Cooking Vessel & Fuel:** กระทะทองเหลืองหรือกระทะ (*กระทะ*) สำหรับน้ำจิ้ม กระทะกว้างที่ก้นไหม้ให้ข้าวตัง และเตาถ่านปิ้งหรือน้ำมันท่วมสำหรับทำให้กรอบ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*ข้าวตัง*คือ**ข้าวที่ไหม้ติดก้นหม้อแล้วขูดออกมา** ทั้งในครัวเรือนที่ประหยัดและในห้องเครื่องของวัง ข้าวตังจะนำไปตากแดด แล้วปิ้งหรือทอดจนกรอบ เมื่อจับคู่กับน้ำจิ้มหัวกะทิใส่หมูและกุ้ง (*หน้าตั้ง*) ก็กลายเป็นของว่างชั้นดีที่ตามคู่มือขนมจากข้าวของการบินไทย เริ่มต้นจากสูตรเฉพาะของราชสำนักก่อนจะแพร่ไปทั่วประเทศ ([การบินไทย – ขนมไทยจากข้าว](https://sawasdee.thaiairways.com/thai-rice-snacks/)) กัมพูชามีอาหารที่แทบเหมือนกันชื่อ **nataing** และทั้งสองประเทศต่างอ้างว่าเป็นมรดกของราชสำนัก ([Wikipedia – Nataing](https://en.wikipedia.org/wiki/Nataing); [Grantourismo](https://grantourismotravels.com/natang-recipe-pork-coconut-peanut-dip/))

**วิทยาศาสตร์การทำอาหาร:** ข้าวสุกที่ตากแห้งยังมีความชื้นกักอยู่ในแป้งที่สุกเป็นเจล ในน้ำมันร้อน น้ำนั้นจะกลายเป็นไอทันทีและทำให้เมล็ดข้าวพองเป็นแผ่นกรอบใสมีรูพรุน น้ำจิ้มเคี่ยวจนหัวกะทิ "แตกมัน" และปล่อยน้ำมันออกมา ทำให้เงางามและเก็บไว้ที่อุณหภูมิห้องได้โดยไม่เสียง่าย

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบชาววัง (กรุงเทพฯ):** หมูและกุ้งกับหัวกะทิ หอมแดง รากผักชี ถั่วลิสง น้ำตาลปี๊บ และน้ำปลา ข้าวตังจากข้าวไหม้ก้นหม้อ
*   **แบบสตรีทฟู้ดและแบบบรรจุซองสมัยใหม่:** ข้าวตังกลมผลิตในเชิงพาณิชย์ น้ำจิ้มหวานกว่า บางครั้งใช้ไก่
*   ***Nataing* ของกัมพูชา (ญาติข้ามพรมแดน):** น้ำจิ้มหมู-กะทิ-ถั่วลิสงคล้ายกัน มักมีสีแดงกว่าจากพริกแห้ง ([Grantourismo](https://grantourismotravels.com/natang-recipe-pork-coconut-peanut-dip/))
*   **ฉบับมังสวิรัติ/ขนุน:** การดัดแปลงสมัยใหม่ใช้ขนุนแทนหมู ([Wholesomm](https://www.wholesomm.com/vegetarian-jackfruit-na-tang/))

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่ใช้เป็นตัวแทน: **น้ำจิ้มหมูและกุ้งแบบชาววัง** กับข้าวตังทำเอง*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| หัวกะทิ | 300 ml |
| หมูสับ | 200 g |
| กุ้งปอกเปลือก สับ | 100 g |
| หอมแดงซอย | 3 หัว |
| กระเทียม + รากผักชี + พริกไทยขาวเม็ด ตำรวมกัน | 1 ช้อนโต๊ะ (เครื่องตำ) |
| ถั่วลิสงคั่ว บุบ | 60 g |
| น้ำตาลปี๊บ | 2 ช้อนโต๊ะ |
| น้ำปลา | 2 ช้อนโต๊ะ |
| ใบผักชีและพริกชี้ฟ้าแดงสำหรับแต่งหน้า | ตามชอบ |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวหอมมะลิสุกสำหรับทำข้าวตัง | 400 g (หรือข้าวตังสำเร็จรูป 200 g) |
| น้ำมันสำหรับทอด | 750 ml |
| น้ำจิ้มต่อคน | ≈ 150 g |

### ขั้นตอนการทำทีละขั้น
1. **ข้าวตัง:** กดข้าวสุกเป็นชั้นบางบนถาด (หรือใช้ข้าวไหม้ก้นหม้อ) ตัดเป็นแผ่นกลม แล้วตากแดดหรืออบในเตาที่ 90 °C 3–4 ชั่วโมงจนแข็ง
2. **ทอด:** ทอดแผ่นที่แห้งแล้วในน้ำมันท่วมที่ 180 °C ไม่กี่วินาทีจนพองและเหลืองอ่อน สะเด็ดน้ำมัน
3. **เคี่ยวหัวกะทิให้แตกมัน:** เคี่ยวหัวกะทิครึ่งหนึ่งจนน้ำมันแยกตัว ผัดเครื่องตำกระเทียมและหอมแดงจนหอม
4. **ปรุงน้ำจิ้ม:** ใส่หมูและกุ้ง ผัดจนสุก ใส่หัวกะทิที่เหลือ น้ำตาลปี๊บ น้ำปลา และถั่วลิสง เคี่ยวจนเป็นน้ำจิ้มข้นและเงา (8–10 นาที)
5. **เสิร์ฟ:** ใส่น้ำจิ้มในถ้วยวางไว้กลางจานข้าวตัง แต่งหน้าด้วยผักชีและพริก
