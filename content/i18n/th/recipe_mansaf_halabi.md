# Mansaf Halabi (Aleppo Rice and Freekeh Feast) / المنسف الحلبي

> ⬅ [หน้าหลัก](README.md) · [ซีเรีย](provincial_syria.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** มีบันทึกในบทความสูตรอาหารว่าด้วยอาหารอเลปโปของ Arabic Post ไม่มีแหล่งข้อมูลทางประวัติศาสตร์หรือของเทศบาลใดระบุอายุของจานนี้ และไม่มีบันทึกความแตกต่างระหว่างครัวเรือนในอเลปโป นอกเหนือจากเครื่องเทศทางเลือกที่แหล่งข้อมูลนั้นระบุไว้ อย่าสับสนกับ [mansaf](recipe_mansaf.md) (มันซัฟ) ของจอร์แดน ซึ่งมีเอกลักษณ์อยู่ที่ซอส jameed (จะมีด โยเกิร์ตแห้ง)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** อเลปโป (Halab ฮะลับ) และชนบทโดยรอบ
*   **Dish Type & Texture:** ถาดงานเลี้ยงที่มีธัญพืชสองชนิดอยู่ใต้เนื้อ ชั้นล่างเป็น **freekeh** (ฟรีเกห์ ข้าวสาลีอ่อนรมควัน) สีเขียวหอมควันกดให้แน่น ตามด้วยชั้น**ข้าว**เมล็ดสั้นร่วนฟู โปะหน้าด้วยเนื้อแกะต้มและถั่วคั่ว ธัญพืชทั้งสองหุงในน้ำซุปแกะเดียวกัน จึงแยกชั้นกันแต่มีรสชาติร่วมกัน
*   **Traditional Cooking Vessel & Fuel:** หม้อลึก (*tanjara* ฏันญะเราะห์) สำหรับต้มเนื้อแกะและน้ำซุป หม้อมีฝาใบเล็กสองใบสำหรับธัญพืช และถาดเสิร์ฟกลมใบใหญ่ (*sedr* ศิดร์) ปรุงบนเตา

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
อเลปโปเรียกตัวเองว่า "มารดาแห่ง mahashi และ kibbeh" (*حلب أمّ المحاشي والكبب*) และข้าวงานเลี้ยงของเมืองนี้สะท้อนธัญพืชสำคัญอีกชนิดของเมือง คือ **freekeh** ข้าวสาลีอ่อนสีเขียวที่คั่วกลางทุ่ง บทความเรื่องจานนี้ของ Arabic Post เรียก mansaf ที่ทำจากเนื้อแกะ ข้าว และ freekeh ว่า "หนึ่งในอาหารที่มีชื่อเสียงที่สุดของครัวอเลปโป" และเล่าว่าหนังสือ *Risalat al-Ghufran* (ริซาละตุล-ฆุฟรอน) ของ al-Maʿarri (อัล-มะอัรรี) จินตนาการถึงการเรียกพ่อครัวแห่งอเลปโปมาทำอาหารในงานเลี้ยงบนสวรรค์ ([Arabic Post – المنسف الحلبي](https://arabicpost.net/%d9%84%d8%a7%d9%8a%d9%81-%d8%b3%d8%aa%d8%a7%d9%8a%d9%84/2019/04/10/%d8%a7%d9%84%d9%85%d9%86%d8%b3%d9%81-%d8%a7%d9%84%d8%ad%d9%84%d8%a8%d9%8a/)) ต่างจาก [mansaf](recipe_mansaf.md) ของชาวเบดูอิน-จอร์แดน จานนี้ไม่มีซอสโยเกิร์ต หัวใจของจานคือการพบกันของธัญพืชสองชนิดกับน้ำซุปปรุงเครื่องเทศ

ถาดธัญพืชสองชั้นนี้สะท้อนแบบแผนเก่าของเลแวนต์ ที่ข้าวสาลี (บัลเกอร์ freekeh) เป็นธัญพืชประจำวัน ส่วนข้าวเป็นธัญพืชสำหรับงานเทศกาล การวางข้าว*ไว้บน* freekeh เป็นการอวดธัญพืชที่มีเกียรติ ขณะที่ข้าวสาลีซึ่งราคาถูกกว่าและอิ่มท้องกว่าอยู่ด้านล่าง อเลปโปในศตวรรษที่ 18 ที่ Russell บันทึกไว้ก็ปิดท้ายงานเลี้ยงด้วย "pilaw ถาดใหญ่" อยู่แล้ว ([ข้าวปิลาฟออตโตมัน](recipe_pilav_ottoman_aleppo.md))

**วิทยาศาสตร์การทำอาหาร:** freekeh ดูดซับของเหลวประมาณ 1½ เท่าของปริมาตร และยังคงเนื้อสัมผัสหนึบเคี้ยว ส่วนข้าวเมล็ดสั้นต้องการของเหลวมากกว่าเล็กน้อยและนุ่มเร็วกว่า การหุงแยกกันใน*น้ำซุปเดียวกัน*ทำให้แต่ละอย่างได้เนื้อสัมผัสที่เหมาะสมของตัวเอง และการกดแต่ละชั้นลงบนถาดทำให้ตัดแบ่งได้เรียบร้อยเมื่อเสิร์ฟ

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **ฉบับครัวเรือนอเลปโป (มีบันทึก):** ต้มเนื้อแกะกับหัวหอม อบเชย ใบกระวาน และยี่หร่าเล็กน้อย บางคนใส่**กานพลู**หรือ**ไทม์ป่า** (*zaʿtar barri* ซะอ์ตัร บัรรี) ในน้ำซุป ข้าวใส่อบเชยแท่งและลูกกระวานเทศ ส่วน freekeh นำไปผัดในเนยใสก่อน โรยหน้าด้วยอัลมอนด์ เม็ดสน วอลนัท และเม็ดมะม่วงหิมพานต์
*   **ฉบับเบาลง:** แหล่งข้อมูลแนะนำให้ลดเนยใสหรือเปลี่ยนไปใช้ไขมันที่เบากว่า
*   **เมืองอื่นๆ ในซีเรีย:** ⚠️ ไม่มีบันทึก ดามัสกัสนิยมถาดงานเลี้ยงที่มีแต่ข้าว (แบบ [riz a djej](recipe_riz_a_djej.md) ริซ อะ ดจาจ) ส่วนถาด freekeh กับเนื้อนั้นเชื่อมโยงกับอเลปโปและอิดลิบ

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*ฉบับที่ใช้: **mansaf แบบครัวเรือนอเลปโป** (สัดส่วนจาก Arabic Post ลดลงครึ่งหนึ่งและปรับเป็น 4 คน)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เนื้อแกะ (ไหล่/คอติดกระดูก) หั่นชิ้นขนาดกลาง | 1 kg |
| หัวหอมใหญ่ ผ่าสี่ | 1 หัว |
| ใบกระวาน | 2 ใบ |
| อบเชยแท่ง | 1 แท่ง |
| ยี่หร่าป่น | หยิบมือ |
| กานพลูหรือไทม์ป่า (ไม่ใส่ก็ได้) | 2 ดอก / 1 ก้าน |
| เกลือและพริกไทยดำ | ตามชอบ |
| น้ำ | 2.5 L |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น (อียิปต์) ล้างแล้วแช่น้ำ 20 นาที | 400 g |
| น้ำซุปแกะสำหรับหุงข้าว | ≈ 600 ml |
| freekeh เก็บสิ่งเจือปนออกแล้วล้าง | 2 ถ้วย (≈ 320 g) |
| น้ำซุปแกะสำหรับ freekeh | 3 ถ้วย (≈ 1½ ถ้วยต่อ freekeh 1 ถ้วย) |
| เนยใส (samneh สัมเนห์) | 3 ช้อนโต๊ะ (1 สำหรับข้าว 2 สำหรับ freekeh) |
| อบเชยแท่ง + ลูกกระวานเทศ | 2 + 2 |
| อัลมอนด์ เม็ดสน วอลนัท เม็ดมะม่วงหิมพานต์ (คั่ว) | อย่างละ 30 g |

### ขั้นตอนการทำทีละขั้น
1. **น้ำซุป:** ใส่น้ำให้ท่วมเนื้อแกะแล้วต้มให้เดือด ช้อนฟองออก ใส่หัวหอม ใบกระวาน อบเชย ยี่หร่า (และกานพลูหรือไทม์) เกลือ และพริกไทย เคี่ยวจนเนื้อนุ่ม ประมาณ 1½ ชั่วโมง ยกเนื้อขึ้นแล้วกรองน้ำซุป
2. **Freekeh:** ละลายเนยใส 2 ช้อนโต๊ะ ผัด freekeh 2–3 นาที คนไปเรื่อยๆ ใส่เกลือ พริกไทย อบเชยแท่งหนึ่งแท่ง ลูกกระวานเทศหนึ่งลูก และน้ำซุป 3 ถ้วย ต้มให้เดือด 5 นาที แล้วปิดฝาหุงด้วยไฟอ่อนจนนุ่ม (ประมาณ 25–30 นาที)
3. **ข้าว:** ละลายเนยใส 1 ช้อนโต๊ะในน้ำซุปประมาณ 600 ml ใส่อบเชยแท่งและลูกกระวานเทศ เติมเกลืออย่างระมัดระวัง (น้ำซุปปรุงรสแล้ว) ใส่ข้าวที่สะเด็ดน้ำแล้ว ต้มเดือด 3–5 นาที แล้วปิดฝาหุงบนไฟอ่อนมาก 20–25 นาที
4. **ทำให้เนื้อเป็นสีน้ำตาล (ไม่ทำก็ได้):** นำเนื้อแกะต้มไปจี่เร็วๆ ในเนยใสเล็กน้อยเพื่อให้มีสี
5. **ประกอบ:** เกลี่ย freekeh บนถาดใบใหญ่แล้วใช้ช้อนกดให้เรียบ เกลี่ยข้าวทับแล้วกดอีกครั้ง วางเนื้อแกะด้านบนและโรยถั่วคั่ว
6. **เสิร์ฟ:** เสิร์ฟร้อนๆ พร้อมน้ำซุปที่เหลือหนึ่งชาม และโยเกิร์ตรสธรรมชาติหรือสลัดแตงกวาโยเกิร์ต
