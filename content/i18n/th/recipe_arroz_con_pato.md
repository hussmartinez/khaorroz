# Arroz con Pato / Arròs amb Ànec (Arròs d'Ànec de l'Albufera)

> ⬅ [หน้าหลัก](README.md) · [จังหวัด València](provincial_valencia.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** L'Albufera และ La Ribera Baixa ได้แก่ Sueca, El Palmar, El Perellonet, Silla, Catarroja, Cullera
*   **Liquid & Texture Profile:** **Seco** (ข้าวแห้ง) ในฉบับกระทะ paella ซึ่งเป็นธรรมเนียมการล่าสัตว์ของ Albufera ที่บันทึกไว้ในหน้านี้ ส่วน *arròs amb ànec i naps* (ข้าวเป็ดกับหัวผักกาดเทอร์นิป) ที่อบในหม้อดินเป็นอีกรูปแบบหนึ่งของอาหารบ้าน (ดู §3)
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** กระทะ paella เหล็กบนไฟฟืนไม้ส้มหรือฟางข้าว หรือหม้อดิน *cassola* (กาโซลา) อบในเตาสำหรับฉบับใส่หัวผักกาด

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
L'Albufera คือพื้นที่ชุ่มน้ำที่สำคัญที่สุดของยุโรปสำหรับเป็ดที่อพยพมาพักหนาว ตั้งแต่เดือนตุลาคมถึงมกราคม วันล่าสัตว์ที่มีการควบคุม (*tirades*) เคยส่ง**เป็ดป่า** (*collverd* เป็ดแมลลาร์ด, *sivert* เป็ดทีล, *bragat*) ให้หมู่บ้านรอบทะเลสาบมาแต่ดั้งเดิม Sueca ซึ่งเป็นเทศบาลที่ผลิตข้าวมากที่สุดในแคว้น Comunitat Valenciana เป็นเจ้าภาพจัดงาน **Festa de l'Arròs** (เทศกาลข้าว) และ **Concurs Internacional de Paella Valenciana** (การแข่งขันปาเอยาบาเลนเซียนานาชาติ) พ่อครัวแม่ครัวที่นี่ใส่เป็ดลงในกระทะควบคู่หรือแทนไก่มานานแล้ว เมื่อการล่าสัตว์ลดลง เป็ดเลี้ยง (มักเป็นเป็ด**มัสโควี** หรือเป็ด**บาร์บารี**) ก็เข้ามาแทนที่

**วิทยาศาสตร์การทำอาหาร:** เป็ดมีชั้นไขมันใต้ผิวหนังหนา และมีเนื้อสีเข้มที่อุดมด้วยไมโอโกลบิน การเจียวหนังช้าๆ จะปล่อยไขมันออกมา แล้วไขมันนั้นจะกลายเป็นน้ำมันสำหรับผัด sofrito (โซฟริโต ฐานผัดเครื่องปรุง) และข้าว ทำให้เม็ดข้าวมีรสเป็ด เนื้อเป็ดต้องปรุงนานกว่าไก่ (≈35–45 นาทีใน fondo) เพื่อให้คอลลาเจนนุ่ม หัวผักกาดเทอร์นิป คู่หูคลาสสิกของเป็ด จะดูดซับไขมันเป็ดและถ่วงสมดุลด้วยรสขมคล้ายมัสตาร์ด

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)

*   **สไตล์ Sueca:** **เป็ด + ไก่ + กระต่าย** ในโครงแบบ paella valenciana (*bajoqueta* บาโคเกตา ถั่วแขกฝักแบน, *garrofó* การ์โรโฟ ถั่วลิมาเมล็ดใหญ่, มะเขือเทศ, หญ้าฝรั่น) ในฤดูหนาวจะเพิ่ม**อาร์ติโชก**ลงในกระทะ ใส่ pimentón (ปาปริกา) น้อยหรือไม่ใส่เลย ใช้ไฟฟืนไม้ส้มแบบคลาสสิก
*   **สไตล์ El Palmar / เกาะใน Albufera:** **เป็ดล้วน** มักเป็นเป็ดป่า บางครั้งเพิ่ม**ปลาไหล** (*anguila*) ซึ่งเชื่อมโยงกับอาหาร *all i pebre* (อาย อี เปเบร สตูว์ปลาไหลกระเทียมพริก) ฐานรสเน้นกระเทียมหนัก บางคนใส่**เห็ดป่า**เล็กน้อยในฤดูใบไม้ร่วง
*   **สไตล์ Silla / Catarroja:** **Arròs amb ànec i naps** เป็ด + **หัวผักกาดเทอร์นิป** + ถั่วขาวหรือ *garrofó* ปรุงใน *cassola* แล้วอบให้เสร็จในเตา เทคนิคใกล้เคียงกับ [arròs al forn](recipe_arroz_al_horno.md) (ข้าวอบ)
*   **สไตล์ Cullera:** เป็ด + **ผักจากชายฝั่ง** (อาร์ติโชก, *ajos tiernos* กระเทียมอ่อน) บางครั้งใช้**ซี่โครงหมู**แทนกระต่าย

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **Sueca** (โครงเป็ด + ไก่ ใส่อาร์ติโชกฤดูหนาว)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เป็ด แยกชิ้น (สะโพก + อกติดหนัง โครงสับ) | 1 ตัว (≈ 1.6 kg รวมกระดูก) |
| สะโพกไก่ | 400 g |
| น้ำมันมะกอก | 40 ml (ที่เหลือได้จากไขมันเป็ด) |
| Bajoqueta (ถั่วแขกฝักแบน) | 150 g |
| Garrofó (สดหรือแช่น้ำแล้ว) | 100 g |
| อาร์ติโชก ผ่าสี่ (ฤดูหนาว) | 4 หัว |
| มะเขือเทศสุก ขูด | 150 g |
| หญ้าฝรั่น | 0.3 g |
| น้ำ | 1.8 L |
| เกลือ | ตามชอบ |

**การสกัดรส:**
1. วางชิ้นเป็ดลงในกระทะเย็นพร้อมน้ำมัน โดย**คว่ำด้านหนังลง** เจียวช้าๆ บนไฟกลาง **15 นาที** ตักไขมันส่วนเกินออก เหลือไว้ในกระทะ ≈ 80 ml
2. ใส่ไก่ แล้วผัดทุกอย่างให้เหลืองต่ออีก **15 นาที**
3. ดันเนื้อไปไว้ขอบกระทะ แล้วผัดถั่วแขก garrofó และอาร์ติโชก **5 นาที**
4. ใส่มะเขือเทศ ผัดจนข้นเหมือนแยม (5 นาที)
5. เติมน้ำและหญ้าฝรั่น เคี่ยว **35–40 นาที** จนงวดเหลือ ≈ 1.25 L

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น (Senia / Bomba) | 400 g |
| น้ำซุป | ≈ 1.2–1.3 L |
| เป็ด | ≈ 1.6 kg รวมกระดูก |

### ขั้นตอนการทำทีละขั้น
1. **การเตรียม:** แยกชิ้นเป็ดตั้งแต่วันก่อน แล้วโรยเกลือบางๆ (หมักเกลือแบบแห้ง)
2. **Fondo:** ทำตามข้างต้น
3. **ข้าว:** โรยข้าวแล้วเกลี่ยให้เรียบ หลังจากนี้ห้ามคน
4. **ไฟ:** ไฟแรง 8 นาที → ไฟกลางค่อนอ่อน 8–9 นาที → ไฟแรง 1 นาที (ทำ socarrat ข้าวตังก้นกระทะ)
5. **จบงาน/การพัก:** พัก **5 นาที** [**ฉบับหัวผักกาดของ Silla:** ใน cassola ใช้หัวผักกาดเทอร์นิปปอกเปลือก 3 หัว หั่นเป็นชิ้นลิ่ม แทนถั่วแขกและอาร์ติโชก ใช้อัตราส่วนน้ำซุปเท่าเดิมที่ 2:1 อบที่ 230 °C 20 นาที]
