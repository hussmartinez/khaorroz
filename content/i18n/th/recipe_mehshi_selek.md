# Mehshi Selek bi-Zeit / محشي سلق بالزيت

> ⬅ [หน้าหลัก](README.md) · [เลบานอน](provincial_lebanon.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** เลบานอน โดยเฉพาะครัวเรือนชาวคริสต์ในเขตภูเขาเลบานอน (Mount Lebanon) และเบรุตช่วง**เทศกาลมหาพรต (Lent)** ที่ใดปลูกผักชาร์ด (chard) ได้ ที่นั่นก็จะเป็นอาหารน้ำมันมะกอกประจำฤดูใบไม้ผลิและฤดูใบไม้ร่วง
*   **Dish Type & Texture:** ใบผักยัดไส้ปรุงในน้ำมันมะกอก (*mahashi bi-zeit*) ใบชาร์ดม้วนไส้ข้าว ถั่วลูกไก่ มะเขือเทศ และสมุนไพร ปรุงช้า ๆ ในน้ำมะนาวกับน้ำมันมะกอกจนข้าวนุ่มและอมเปรี้ยวเล็กน้อย กินที่อุณหภูมิห้อง
*   **Traditional Cooking Vessel & Fuel:** หม้อก้นหนาปากกว้างบนไฟอ่อน เรียงม้วนผักให้แน่นและกดทับด้วยจาน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Mehshi selek* (เมห์ชี เซเลก) คือญาติไร้เนื้อสัตว์ของ [warak enab](recipe_warak_enab.md) (วะรัก อินับ ใบองุ่นยัดไส้) และ [malfouf mehshi](recipe_malfouf_mehshi.md) (มัลฟูฟ เมห์ชี กะหล่ำปลีม้วน) จัดอยู่ในตระกูลอาหารเลบานอน **bi-zeit** ("ในน้ำมัน") คือปรุงด้วยน้ำมันมะกอกแทนเนื้อสัตว์หรือเนย กินเย็น และขาดไม่ได้ในวันถือศีลอดของชาวคริสต์ ซึ่งงดเนื้อสัตว์และผลิตภัณฑ์นม L'Orient-Le Jour ตีพิมพ์สูตรช่วงเทศกาลมหาพรตของ Liza Soughayar Asseily คือม้วนผักที่ทอดพอเหลืองแล้วนำไป "confit" (ตุ๋นช้า) ในน้ำมันมะกอก ไส้เป็นข้าวขาว ถั่วลูกไก่ ผักชีฝรั่ง และสะระแหน่ Anissa Helou เรียก *mehshi silq bil-zeyt* ว่า "หนึ่งในอาหารเลบานอนจานโปรดของฉัน" แม่ครัวเลบานอนใช้ใบชาร์ดและใบองุ่นสลับกันได้กับไส้แบบเดียวกัน

**วิทยาศาสตร์การครัว:** ใบชาร์ดบางและอ่อนกว่ากะหล่ำปลี เพียงจุ่มน้ำเดือดครู่เดียวก็อ่อนตัวพอจะม้วนได้ เมื่อไส้ไม่มีเนื้อสัตว์ ข้าวจะได้ความมันจากน้ำมันมะกอกและน้ำจากมะเขือเทศสับ และได้ความแน่นจากถั่วลูกไก่ การปรุงช้า ๆ ในน้ำมันกับมะนาวทำให้เกิดอิมัลชันบาง ๆ เคลือบม้วนผักแต่ละม้วน นี่คือเหตุผลที่อาหารจานนี้อร่อยที่สุดเมื่อเย็นลงแล้ว

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบ confit เทศกาลมหาพรตของ L'Orient-Le Jour (เบรุต):** ทอดม้วนผักก่อน แล้วปรุงช้า ๆ ในน้ำมันมะกอกปริมาณมาก ไส้มีถั่วลูกไก่ เตรียมใบผักไว้ตั้งแต่วันก่อน
*   ***mehshi silq bil-zeyt* ของ Anissa Helou:** แบบน้ำมันมะกอกคลาสสิกจากหนังสือ *Levant* ของเธอ
*   **แบบใส่เนื้อ:** นอกเทศกาลมหาพรต บางบ้านยัดไส้ชาร์ดด้วยเนื้อแกะบดกับข้าวแล้วปรุงในซอสมะเขือเทศ เหมือน malfouf ฉบับฤดูร้อน
*   ⚠️ ไม่มีแหล่งข้อมูลที่ตีพิมพ์ใดแยกแยะความแตกต่างระหว่างเมือง

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*แบบที่นำเสนอ: แบบน้ำมันมะกอกช่วงเทศกาลมหาพรตใส่ถั่วลูกไก่*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| ใบสวิสชาร์ดใบใหญ่ (เอาก้านออก) | 30–35 ใบ (≈ 800 ก.) |
| ข้าวเมล็ดสั้น ซาวแล้ว | 200 ก. |
| ถั่วลูกไก่ต้มสุก บี้พอแตก | 120 ก. |
| มะเขือเทศสุก หั่นลูกเต๋าเล็ก | 2 ลูก (≈ 250 ก.) |
| ผักชีฝรั่งใบแบน สับ | 50 ก. |
| สะระแหน่สด สับ | 15 ก. |
| หอมใหญ่ สับละเอียด | ลูกเล็ก 1 หัว |
| น้ำมันมะกอกเอ็กซ์ตร้าเวอร์จิน | 150 มล. |
| น้ำมะนาว | 120 มล. |
| เกลือ, พริกไทยดำ, ซูแมก (ไม่ใส่ก็ได้) | ตามชอบ |
| น้ำ | ≈ 600 มล. |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ไส้ต่อใบ | 1 ช้อนโต๊ะ |
| ข้าว : ถั่วลูกไก่ | ≈ 5 : 3 |
| ของเหลว (น้ำมัน + มะนาว + น้ำ) | พอท่วม |

### ขั้นตอนการทำทีละขั้น
1. **ใบผัก (ทำล่วงหน้าตั้งแต่วันก่อนได้):** จุ่มใบชาร์ดในน้ำเดือดไม่กี่วินาทีจนอ่อนตัว แล้วสะเด็ดน้ำ ใบใหญ่ให้ผ่าครึ่งตามแนวก้านใบ
2. **ไส้:** ผสมข้าว ถั่วลูกไก่ มะเขือเทศ ผักชีฝรั่ง สะระแหน่ และหอมใหญ่ กับน้ำมันครึ่งหนึ่ง เกลือ และพริกไทย
3. **ม้วน:** ม้วนใบผักแต่ละชิ้นรอบไส้หนึ่งช้อนโต๊ะให้แน่น พับขอบข้างเข้าด้านใน
4. **ทอด (ไม่ทำก็ได้ วิธีของ L'Orient-Le Jour):** ทอดม้วนผักกับน้ำมันเล็กน้อยในหม้อพอเหลือง แล้วเรียงเป็นชั้นให้แน่น
5. **ปรุง:** ราดน้ำมันที่เหลือ น้ำมะนาว และน้ำพอท่วม กดทับด้วยจานแล้วเคี่ยวไฟอ่อนมากโดยปิดฝา **50–60 นาที** จนข้าวนุ่ม
6. **พัก:** ปล่อยให้ม้วนผักเย็นลงในหม้อ เพื่อให้น้ำมันและมะนาวเซ็ตตัวรอบ ๆ เสิร์ฟที่อุณหภูมิห้อง
