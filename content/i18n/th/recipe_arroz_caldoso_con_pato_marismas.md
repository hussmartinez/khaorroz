# Arroz Caldoso con Pato de las Marismas / Arroz de Pato Cortijero

> ⬅ [หน้าหลัก](README.md) · [Andalucía](provincial_andalucia.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** พื้นที่บึง marismas del Guadalquivir (Sevilla) ได้แก่ Isla Mayor, La Puebla del Río, Villafranco และ cortijo (ฟาร์มใหญ่) ปลูกข้าวในเขต Bajo Guadalquivir
*   **Liquid & Texture Profile:** **Caldoso** (ข้าวน้ำซุป)
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** หม้อดิน *cazuela* หรือหม้อเหล็ก บนไฟฟืนในครัวของ cortijo

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
นาข้าวในบึงแม่น้ำ Guadalquivir คือพื้นที่ปลูกข้าวที่ใหญ่ที่สุดของสเปน และเช่นเดียวกับ L'Albufera ที่นี่เต็มไปด้วยนกน้ำ Directo al Paladar บันทึก **"arroz caldoso con pato" ไว้ว่าเป็นสูตรดั้งเดิมของ cortijo ในพื้นที่บึงเซบียา** คือสตูว์ของคนงานนาข้าวและคนงานฟาร์ม (*cortijeros*) ที่ทำจากเป็ดในบึง เช่นเดียวกับญาติฝั่งบาเลนเซีย [arròs amb ànec](recipe_arroz_con_pato.md) อาหารนี้สะท้อนความเชื่อมโยงระหว่างพื้นที่ชุ่มน้ำ ข้าว และนกป่า อย่างไรก็ตาม ฉบับอันดาลูเซียเป็นแบบ**มีน้ำซุป** และสร้างบนฐาน sofrito (โซฟริโต ฐานผัดเครื่องปรุง) จากหอมใหญ่และพริก ไม่ใช่ข้าวแห้งในกระทะแบบบาเลนเซีย

**วิทยาศาสตร์การทำอาหาร:** ไขมันเป็ดจะละลายลงใน sofrito และเคลือบเม็ดข้าว การตุ๋นนานทำให้คอลลาเจนของเป็ดแตกตัว และน้ำซุปที่ได้จะพาความเข้มข้นเข้าสู่ข้าว caldoso

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **Isla Mayor:** เป็ด บางครั้งใส่ **cangrejo rojo** (กุ้งเครย์ฟิชแดงหนองบึง ปัจจุบันเป็นผลผลิตท้องถิ่นที่สำคัญ)
*   **La Puebla del Río:** เป็ด + พริกหยวกเขียว + **fino** หรือ manzanilla (เชอร์รีแห้ง) ในการตุ๋น
*   **Cortijo (ดั้งเดิม):** เป็ด + มันฝรั่ง + ผักจากสวนเท่าที่มี เติมน้ำซุปมากขึ้นเพื่อให้พอเลี้ยงคนงานจำนวนมาก
*   *รูปแบบต่างๆ มีแหล่งอ้างอิงเพียงเล็กน้อย โปรดตรวจสอบในท้องถิ่น*

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **Caldoso แบบ cortijo***

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เป็ด แยกชิ้น | 1 ตัว (≈ 1.6 kg) |
| น้ำมันมะกอก | 40 ml |
| หอมใหญ่ | 1 หัวใหญ่ |
| พริกหยวกเขียว | 2 ลูก |
| กระเทียม | 4 กลีบ |
| มะเขือเทศสุก ขูด | 200 g |
| Pimentón dulce (ปาปริกาหวาน) | 4 g |
| ใบกระวาน | 2 ใบ |
| ไวน์ขาวหรือ fino | 150 ml |
| น้ำ | 2.5 L |
| หญ้าฝรั่น | 0.2 g |

**การสกัดรส:** เจียวเป็ดโดยคว่ำด้านหนังลง (**15 นาที**) เทไขมันส่วนเกินออก ใส่หอมใหญ่และพริก (12 นาที) กระเทียม pimentón และมะเขือเทศ (5 นาที) แล้วเติมไวน์ เติมน้ำและใบกระวาน ปิดฝาเคี่ยว **75 นาที** ควรได้น้ำซุป ≈ 2 L

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดกลม (พันธุ์จากพื้นที่บึง) | 320 g |
| น้ำซุปเป็ด | ≈ 1.9 L (≈ 6:1) |

### ขั้นตอนการทำทีละขั้น
1. **ข้าว:** ต้มน้ำซุปให้เดือด ใส่ข้าวและหญ้าฝรั่น
2. **ไฟ:** เคี่ยวไฟสม่ำเสมอ **17 นาที**
3. **จบงาน:** เสิร์ฟทันที ใส่เนื้อเป็ดจานละหนึ่งชิ้น
