# Arroz a la Sevillana / Arroz con Cosas

> ⬅ [หน้าหลัก](README.md) · [Andalucía](provincial_andalucia.md)

> ⚠️ **หมายเหตุระดับความน่าเชื่อถือของแหล่งข้อมูล:** "arroz a la sevillana" (ข้าวแบบเซบียา) เป็นชื่อที่อยู่บนเมนูร้านอาหารสเปนมายาวนาน แต่ผู้เขียน**ไม่พบสูตรมาตรฐานหรือประวัติที่มีการบันทึกไว้** แหล่งข้อมูลเดียวที่พบคือเรื่องเล่าส่วนตัวของผู้ที่กินข้าวนี้ในงาน Expo '92 (ใส่ chorizo อาหารทะเลเปลือกแข็ง และปลา) และสูตร *arroz con cosas* / *arroz campero* ของอันดาลูเซีย เนื้อหาต่อไปนี้จึงบรรยายถึงข้าวผสมแบบอันดาลูเซียที่ชื่อนี้มักหมายถึง โปรดถือว่าเป็นการสร้างขึ้นใหม่

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** จังหวัดเซบียา (Sevilla) พื้นที่บึง marismas del Guadalquivir (Isla Mayor, La Puebla del Río) และร้าน venta (ร้านอาหารริมทาง) ในเมืองเซบียา
*   **Liquid & Texture Profile:** **Meloso** (ข้าวข้นเยิ้ม) ข้าวผสมแบบอันดาลูเซียมักแฉะกว่าปาเอยาบาเลนเซีย
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** กระทะ *paellera* ปากกว้าง หรือหม้อ *perol* บนเตาแก๊สหรือไฟฟืน ตามร้าน venta และมื้ออาหารครอบครัววันอาทิตย์

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
จังหวัดเซบียาคือ**แหล่งผลิตข้าวอันดับหนึ่งของสเปน** พื้นที่บึง **marismas del Guadalquivir** รอบ Isla Mayor ถูกระบายน้ำและเปลี่ยนเป็นนาข้าวในศตวรรษที่ 20 โดยเฉพาะโดยชาวนาข้าวบาเลนเซียที่มาตั้งถิ่นฐานที่นั่นตั้งแต่ทศวรรษ 1920–1930 ข้าวผสมของภูมิภาคนี้ ซึ่งเรียกกันเป็นภาษาปากว่า **"arroz con cosas"** ("ข้าวกับของต่างๆ") ผสมไก่หรือหมูเข้ากับอาหารทะเลเปลือกแข็ง ถั่วลันเตา พริก piquillo (ปิกีโย พริกแดงย่างหวาน) หรือพริกหวานแดงย่าง และบางครั้งใส่ chorizo (ไส้กรอกหมูรมควันปาปริกา) อย่างอิสระ ซึ่งตรงข้ามกับความเคร่งครัดแบบบาเลนเซีย Diputación de Sevilla (องค์การบริหารจังหวัดเซบียา) จัดการแข่งขันสูตรข้าวทำเองที่บ้านทุกปีเพื่อส่งเสริมธรรมเนียมนี้ คำว่า "a la sevillana" บนเมนูช่วงกลางศตวรรษที่ 20 มักหมายถึงข้าวผสมที่ใส่ของเต็มที่และมีสีสันสดใส ตกแต่งด้วยพริกหวานแดงหั่นเส้นและถั่วลันเตา

**วิทยาศาสตร์การทำอาหาร:** การผสมน้ำสต๊อกเนื้อสัตว์กับอาหารทะเลเปลือกแข็งทำให้ได้น้ำซุปที่อุดมทั้งเจลาติน กลูตาเมต และอิโนซิเนต ซึ่งเป็นการเสริมรสอูมามิกันตามธรรมชาติ เนื่องจากข้าวเป็นแบบ meloso จึงคนเบาๆ ได้ วัตถุดิบหลายอย่างจึงใส่ในเวลาต่างกันได้

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ — สร้างขึ้นใหม่ โปรดตรวจสอบในท้องถิ่น)
*   **ร้าน venta ในเมืองเซบียา:** ไก่ + หมู + กุ้ง/*cigalas* (กุ้งมังกรนอร์เวย์) + ถั่วลันเตา + piquillo แบบ meloso
*   **Isla Mayor / พื้นที่บึง:** **เป็ด** หรือ **cangrejo de río** (กุ้งน้ำจืดเครย์ฟิช) ซึ่งเป็นผลผลิตท้องถิ่น ดู [arroz caldoso con pato](recipe_arroz_caldoso_con_pato_marismas.md)
*   **Sierra Norte de Sevilla:** **Arroz campero** (ข้าวแบบชนบท) ใส่หมู กระต่าย และผักจากสวน ไม่ใส่อาหารทะเล
*   **สไตล์ร้านอาหารยุค Expo '92:** ใส่ **chorizo** ปลา และอาหารทะเลเปลือกแข็ง เป็นข้าวผสมในเมนูสำหรับนักท่องเที่ยว

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **"arroz con cosas" แบบร้าน venta ในเซบียา***

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| สะโพกไก่ สับ | 500 g |
| สันนอก/ซี่โครงหมู | 250 g |
| น้ำมันมะกอก | 80 ml |
| หอมใหญ่ | 1 หัว |
| พริกหยวกเขียว + พริกหวานแดง | อย่างละ 1 ลูก |
| กระเทียม | 3 กลีบ |
| มะเขือเทศสุก ขูด | 200 g |
| Pimentón dulce (ปาปริกาหวาน) | 3 g |
| ไวน์ขาว (หรือ fino เชอร์รีแห้ง) | 100 ml |
| น้ำสต๊อกไก่หรือน้ำสต๊อกปลา | 1.6 L |
| หญ้าฝรั่น | 0.2 g |

**การสกัดรส:** ผัดเนื้อสัตว์จนเหลือง (**12 นาที**) ใส่หอมใหญ่และพริก (10 นาที) กระเทียมและ pimentón แล้วตามด้วยมะเขือเทศ (5 นาที) เติมไวน์แล้วเคี่ยวให้งวด

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดกลม | 350 g |
| น้ำสต๊อก | 1.4–1.5 L (≈ 4:1) |
| กุ้ง/cigalas | 8–12 ตัว |
| หอยแมลงภู่ | 300 g |
| ถั่วลันเตา | 100 g |
| พริกหวานแดงย่าง หั่นเส้น | 1 ลูก |

### ขั้นตอนการทำทีละขั้น
1. **การคั่วข้าว:** ใส่ข้าวลงใน fondo (ฐานผัด) 1 นาที
2. **การเติมน้ำ:** เทน้ำสต๊อกที่กำลังเดือดและหญ้าฝรั่น
3. **ไฟ:** ไฟแรง 8 นาที → ไฟกลาง 8 นาที ใส่หอยแมลงภู่และถั่วลันเตาที่นาทีที่ 10 และใส่กุ้งที่นาทีที่ 13
4. **จบงาน:** วางพริกหวานแดงเส้นไว้ด้านบน พัก **3 นาที**
