# Fatteh Ghazawiyya / الفتة الغزاوية

> ⬅ [หน้าหลัก](README.md) · [ปาเลสไตน์](provincial_palestine.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ฉนวนกาซา (เมืองกาซา Khan Yunis ราฟาห์)
*   **Dish Type & Texture:** ถาดงานเลี้ยงของขนมปัง ข้าว และเนื้อแกะเรียงเป็นชั้น ขนมปังปิ้งที่ชุ่มน้ำซุปจนนุ่ม ชั้นข้าวเมล็ดสั้นหอมเนย เนื้อแกะด้านบน ถั่ว และ *dugga* (ดุกกา) รสจัดจากกระเทียม พริก และมะนาววางไว้ข้างๆ
*   **Traditional Cooking Vessel & Fuel:** หม้อสต็อกสำหรับน้ำซุปเนื้อแกะ หม้อก้นหนาสำหรับข้าว และถาดกลมกว้าง (*sidr*) สำหรับเสิร์ฟ ขนมปังปิ้งในเตาอบหรือบนถ่านแดง

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*Fatteh* (ฟัตเตะห์ "ที่ถูกบิเป็นชิ้น") เป็นชื่อของตระกูลอาหารลิแวนต์ที่สร้างบนขนมปังปิ้งหรือขนมปังค้างคืนที่ชุ่มน้ำซุปหรือโยเกิร์ต *fatteh* ของเลบานอนและซีเรียมักเป็นอาหารเช้าของถั่วลูกไก่กับโยเกิร์ต **แบบของกาซาเป็นอาหารงานเลี้ยง:** ขนมปัง ข้าว และเนื้อแกะ ชูรสด้วยพริกอันเป็นเอกลักษณ์ของกาซา เชฟชาวเบธเลเฮม Fadi Kattan เขียนว่า "อาหารกาซาแตกต่างจากอาหารเบธเลเฮมมาก" หล่อหลอมด้วย "ลมทะเล พริก และมื้ออาหารยาวนานริมชายฝั่ง" เขาเรียนรู้ fatteh นี้จากแม่ครัวของป้าเขาในกาซา คือ Im Khader ผู้ล่วงลับ "ซึ่งอาจเป็นแม่ครัวที่เก่งที่สุดในกาซา"

**Dugga** (พริกแดงสด กระเทียม เกลือ และมะนาวโขลกรวมกัน) คือสิ่งที่ทำให้อาหารนี้เป็นของกาซา มันอยู่ในกลุ่มเดียวกับผักชีลาว พริกเขียว และมะนาว ที่ *The Gaza Kitchen* ระบุว่าเป็นรสนิยมของชายฝั่ง "ใส่สมุนไพรมากกว่า เผ็ดกว่า พริกไทยมากกว่า เปรี้ยวมะนาวมากกว่า" อาหารในแผ่นดิน อาหารนี้อยู่ระหว่าง [mansaf](recipe_mansaf.md) (ข้าวบนขนมปังกับเนื้อแกะ) และ [fate](recipe_fate_chilena.md) ในงานไว้ทุกข์ของชาวชิลี-ปาเลสไตน์

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **เมืองกาซา (Kattan / Im Khader):** ขนมปังบาง *shrak* หรือ *rkak* น้ำซุปเนื้อแกะใส่กระวานเทศ ออลสไปซ์ และอบเชย ข้าวเมล็ดสั้นในเนยใส อัลมอนด์และเม็ดสน dugga วางข้างจาน
*   **กาซาตอนใต้ (Khan Yunis, ราฟาห์) (⚠️):** ครอบครัวต่างๆ เล่าว่า dugga เผ็ดกว่าและใส่กระเทียมมากกว่า ไม่มีบันทึกเป็นลายลักษณ์อักษร
*   **fatteh แบบเลบานอน / ดามัสกัส (เปรียบเทียบ):** ถั่วลูกไก่ โยเกิร์ต และทาฮินี (ซอสงาขาว) บนขนมปัง ไม่มีข้าว เป็นอาหารคนละอย่างที่ใช้ชื่อเดียวกัน

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: เมืองกาซา (ตามแบบ Fadi Kattan ลดปริมาณลงครึ่งหนึ่ง)*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เนื้อแกะติดกระดูก หั่นเป็นชิ้น | 4 × 250 g |
| น้ำ | 2.5 L |
| น้ำมันมะกอก | 1 ช้อนโต๊ะ |
| หอมใหญ่ หั่นสี่ | ½ หัว |
| กระเทียม | 2 กลีบ |
| ใบกระวาน พริกไทยดำเม็ด กระวานเทศ อบเชยแท่ง ออลสไปซ์เม็ด | 1 / 1 ช้อนชา / 5 / 1 / ¾ ช้อนชา |
| เกลือ | 1½ ช้อนชา |
| **Dugga:** พริกแดงสด กระเทียม น้ำมะนาว เกลือ | 3 เม็ด / 1 กลีบ / 2½ ช้อนชา / 1 หยิบมือ |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น แช่ 30 นาที | 300 g (1¼ ถ้วย) |
| น้ำ + น้ำซุปเนื้อแกะกรองแล้วสำหรับหุงข้าว | 250 ml + 125 ml |
| เนยใส | 1 ช้อนโต๊ะ |
| Shrak/rkak หรือพิตาแผ่นบาง | 1½ แผ่นใหญ่ |
| อัลมอนด์ / เม็ดสน ทอด | ½ ถ้วย / 1 ช้อนโต๊ะ |

### ขั้นตอนการทำทีละขั้น
1. **น้ำซุป:** ผัดกระเทียม หอมใหญ่ และเนื้อแกะในน้ำมันจนเป็นสีน้ำตาล ใส่เครื่องเทศและน้ำ ต้มให้เดือดแล้วปิดฝาเคี่ยวราว 1.5 ชั่วโมง ใส่เกลือแล้วกรอง เก็บน้ำซุปไว้
2. **ข้าว:** ผัดข้าวที่สะเด็ดน้ำแล้วในเนยใสเร็วๆ เติมน้ำและน้ำซุป ปิดฝาเคี่ยวจนน้ำถูกดูดซึมหมด (≈ 18 นาที) เกลี่ยให้ร่วน
3. **ถั่วและ dugga:** ทอดอัลมอนด์และเม็ดสนแยกกัน โขลกพริกและกระเทียมกับเกลือ แล้วใส่มะนาว
4. **ขนมปัง:** ฉีกขนมปังแล้วอบที่ 180 °C จนกรอบ
5. **ประกอบ:** เกลี่ยขนมปังบนถาดแล้วพรมน้ำซุปให้ชุ่ม ปิดด้วยข้าว วางเนื้อแกะด้านบนแล้วโรยถั่ว เสิร์ฟ dugga ไว้ข้างๆ
