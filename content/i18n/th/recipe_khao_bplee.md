# Khao Plee (Fried Rice Baked in a Banana Blossom) / ข้าวปลี

> ⬅ [หน้าหลัก](README.md) · [ภาคกลาง](provincial_central_thailand.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** อาหารจานนี้มาจาก *ตำรับสายเยาวภา* (พ.ศ. 2478) ตำราอาหารชาววังที่พิมพ์เนื่องในงานพระราชทานเพลิงพระศพพระเจ้าลูกเธอ พระองค์เจ้าเยาวภาพงศ์สนิท ตัวอาหารและส่วนผสม (ข้าวหอมมะลิผัดกับน้ำพริกมะขาม ปลาเค็ม ผักโขม มะเขือ และแครอท ยัดไส้ในหัวปลีย่างไฟแล้วนำไปอบ โดยมีนมและผักปวยเล้งซึ่งไม่ค่อยพบในอาหารไทย) ยืนยันได้จากคำอธิบายสูตรในคลังของ Thaifoodmaster แต่ปริมาณและขั้นตอนฉบับเต็มในคลังต้องเสียค่าสมาชิก ปริมาณและบทบาทของนมด้านล่างจึงเป็นการสร้างขึ้นใหม่

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** วังเจ้านายในกรุงเทพฯ (แวดวงราชสำนักของพระราชธิดาในพระบาทสมเด็จพระจุลจอมเกล้าเจ้าอยู่หัว) ช่วงทศวรรษ 1900–1930
*   **Historical Source:** *ตำรับสายเยาวภา* รวบรวมเพื่อเป็นที่ระลึกถึงพระองค์เจ้าเยาวภาพงศ์สนิท บรรณาธิการโดยพระยาสีหศักดิ์ สนิทวงศ์ พ.ศ. 2478 (ค.ศ. 1935) กรุงเทพฯ
*   **Dish Type & Texture:** ข้าวผัดชาววังที่เสิร์ฟในภาชนะจากผัก ข้าวหอมมะลิผัดรสเปรี้ยว เค็ม หวาน อัดลงในแกนกลางของหัวปลีที่ย่างจนไหม้และหอมควัน แล้วนำไปอบ ข้าวจึงได้กลิ่นควันจากหัวปลี
*   **Traditional Cooking Vessel & Fuel:** กระทะบนเตาถ่านสำหรับผัดข้าว หัวปลีย่างบนถ่านโดยตรง และเตาถ่านหรือเตาอบแบบตะวันตกยุคแรกสำหรับอบ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
*ตำรับสายเยาวภา* อยู่ในประเภทหนังสือที่มีลักษณะเฉพาะของไทย คือตำราอาหารที่พิมพ์เป็นหนังสืออนุสรณ์งานศพ แจกเป็นที่ระลึกในงานพระศพหรืองานศพของเจ้านายและขุนนาง *ศิลปวัฒนธรรม* อธิบายว่าเป็นหนังสืออาหารชาววังที่รวบรวมขึ้นในงานพระราชทานเพลิงพระศพพระองค์เจ้าเยาวภาพงศ์สนิท พระราชธิดาในพระบาทสมเด็จพระจุลจอมเกล้าเจ้าอยู่หัว เมื่อ พ.ศ. 2478 โดยมีพระยาสีหศักดิ์ สนิทวงศ์ เป็นบรรณาธิการ หนังสือรวมสูตรอาหารคาวหวานของคนในวัง พระญาติ และข้าหลวงของพระองค์ และนับเป็นหนึ่งในชุดสูตรอาหารชาววังฉบับพิมพ์ที่เก่าที่สุด ([ศิลปวัฒนธรรม – ที่มาของ *สายเยาวภา*](https://www.silpa-mag.com/?p=42563)) ส่วนตำราอาหารเล่มแรกของไทย *แม่ครัวหัวป่าก์* ออกมาตั้งแต่ปี 1908 ([Wikipedia](https://en.wikipedia.org/wiki/Mae_Khrua_Hua_Pa))

*ข้าวปลี* (*ปลี* = หัวปลี) สะท้อนรสนิยมชอบของแปลกใหม่ของราชสำนักในสมัยรัชกาลที่ 5 คลังของ Thaifoodmaster บรรยายว่าเป็น "อาหารหัวปลียัดไส้ด้วยข้าวหอมมะลิผัดรสเปรี้ยว เค็ม หวาน และหอม" ผัดกับน้ำพริกมะขาม ปลาเค็ม ผักโขม มะเขือ และแครอท และระบุว่านมกับผักปวยเล้ง "ไม่ใช่สิ่งที่มักพบในอาหารสยาม" ขณะที่หัวปลีนำไปย่างไฟและอบทั้งลูก ([Thaifoodmaster – ข้าวผัดข้าวปลี ราว ค.ศ. 1935](https://thaifoodmaster.com/courses/c1935-khaao-bplee-fried-rice?lang=th)) แครอท ผักปวยเล้ง และผลิตภัณฑ์นมเป็นวัตถุดิบตะวันตกที่วังต่าง ๆ เริ่มรับเข้ามาใช้ในช่วงทศวรรษเหล่านั้น

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **วังพระองค์เจ้าเยาวภาฯ (1935):** หัวปลียัดไส้ข้าวผัดน้ำพริกมะขาม ปลาเค็ม และผัก แล้วนำไปอบ
*   **ข้าวผัดชาววังอื่น ๆ ในยุคเดียวกัน:** *ข้าวผัดสามสี* (จาก *สายเยาวภา* 1935 เช่นกัน) และข้าวผัดชาววังในทศวรรษ 1940 ดู[ข้าวผัดชาววัง](recipe_khao_phat_chao_wang.md)
*   **ทายาทสมัยใหม่:** เมนู "อาหารไทยชาววัง" ในร้านอาหารนำข้าวผัดที่เสิร์ฟในภาชนะจากผลไม้กลับมา (ในสับปะรด ในมะพร้าวอ่อน) ⚠️ (ไม่มีหลักฐานว่าสืบทอดโดยตรงจาก *ข้าวปลี*)

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่สร้างขึ้นใหม่แบบสมัยใหม่ สำหรับ "ถ้วย" หัวปลี 4 ถ้วย (หรือหัวปลีใหญ่ 2 หัวผ่าครึ่ง)*

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| เนื้อมะขามเปียก ละลายในน้ำอุ่น 60 ml แล้วกรอง | 40 g |
| น้ำตาลมะพร้าว (น้ำตาลปี๊บ) | 25 g |
| น้ำปลา | 25 ml |
| หอมแดง ซอย | 60 g |
| กระเทียม สับ | 20 g |
| พริกแห้ง แช่น้ำแล้วโขลก | 3 เม็ด |
| ปลาเค็ม (*ปลาเค็ม*) แช่น้ำ ฉีกเป็นชิ้น | 120 g |
| น้ำมันพืชกลิ่นอ่อน | 50 ml |
| นม (ตามคำอธิบายในคลัง ใส่ตอนท้าย) | 50 ml |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวหอมมะลิหุงค้างคืน | 700 g |
| หัวปลี | 2 หัวใหญ่ |
| ผักโขมหรือผักปวยเล้ง หั่น | 100 g |
| มะเขือเปราะ หั่นเต๋า | 120 g |
| แครอท หั่นเต๋าเล็ก | 80 g |
| มะนาว | 1 ลูก |

### ขั้นตอนการทำทีละขั้น
1. **ย่างหัวปลี:** ลอกกาบนอกที่แข็งออก แล้วย่างหัวปลีบนถ่านหรือเปลวไฟแก๊ส พลิกไปมาจนด้านนอกไหม้ดำและด้านในนุ่ม (10–12 นาที) พักให้เย็น ลอกชั้นที่ไหม้ออก ผ่าครึ่งตามยาว แล้วคว้านแต่ละซีกให้เป็นถ้วย ถูด้วยมะนาว
2. **ทำน้ำพริก:** เจียวหอมแดง กระเทียม และพริกที่โขลกไว้ในน้ำมันจนเหลือง ใส่น้ำมะขาม น้ำตาลมะพร้าว และน้ำปลา เคี่ยวจนเป็นน้ำพริกข้นเงา (3–4 นาที)
3. **ผัดปลาและผัก:** ใส่ปลาเค็มฉีก แครอท และมะเขือ ผัด 3 นาที แล้วใส่ผักโขมหรือผักปวยเล้งพอให้สลด
4. **ผัดข้าว:** ใส่ข้าวแล้วผัดคลุกบนไฟแรงจนร้อนและน้ำพริกเคลือบทั่ว พรมนมลงไปแล้วผัดจนนมซึมหมด ให้ข้าวเงาแต่ไม่แฉะ
5. **ยัดไส้และอบ:** อัดข้าวลงในถ้วยหัวปลี แล้วอบที่ 200 °C 10–12 นาที จนหน้าข้าวกรอบเล็กน้อยและหอมกลิ่นควัน เสิร์ฟในหัวปลี
