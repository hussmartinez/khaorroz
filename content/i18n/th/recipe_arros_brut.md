# Arroz Sucio Mallorquín / Arròs Brut

> ⬅ [หน้าหลัก](README.md) · [Illes Balears](provincial_baleares.md)

## 1. ภูมิศาสตร์และเนื้อสัมผัส
*   **Primary Geographic Zone:** Mallorca โดยเฉพาะพื้นที่ชนบทตอนใน (Es Pla) และหมู่บ้านในเทือกเขา Serra de Tramuntana ส่วน Eivissa มีอาหารพี่น้องคือ [arròs de matances](recipe_arros_de_matances_eivissa.md)
*   **Liquid & Texture Profile:** **Caldoso** (ข้าวน้ำ) เสิร์ฟร้อน ๆ จากหม้อ
*   **ภาชนะและเชื้อเพลิงแบบดั้งเดิม:** **greixonera** (หม้อดินเผาแบบ Mallorca) หรือ *olla* (หม้อ) บนเตาฟืน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ในภาษาคาตาลันสำเนียง Mallorca คำว่า *brut* แปลว่า **"สกปรก"** ชื่อนี้หมายถึง**น้ำซุปขุ่น**ที่ได้สีจากเครื่องเทศ ได้แก่ อบเชย pimentón (ปาปริกา) หญ้าฝรั่น พริกไทย และในบางสูตรมีกานพลูกับลูกจันทน์เทศ เดิมเป็น**อาหารของนักล่าและชาวนา** ทำจาก**กระต่ายป่าและกระต่าย** นกทรัชหรือนกพิราบ ผักอะไรก็ได้ที่ไร่นาให้มา และในสูตรเก่าแก่จะมี**เครื่องในและเลือด** ทำให้เป็นอาหารประจำฤดูหนาว สูตรสมัยใหม่ใช้ไก่ ซี่โครงหมู *sobrassada* (ไส้กรอกหมักแบบทาได้) หรือ *botifarró* (ไส้กรอกท้องถิ่น) เห็ดหรือหอยทาก และ **picada** (เครื่องโขลก) จากตับ พ่อครัวแม่ครัวบางคนยืนยันว่า arròs brut ที่**ไม่ใส่ตับสับ**ไม่สมควรได้ชื่อนี้

**วิทยาศาสตร์การทำอาหาร:** picada ที่ทำจาก**ตับทอด**โขลกกับกระเทียมและเครื่องเทศจะใส่ในตอนท้าย โปรตีนจากตับและเลือดทำให้น้ำซุปข้นขึ้นเล็กน้อยและสีเข้มขึ้น จึงดู "สกปรก" ซึ่งตรงข้ามกับแนวคิดของบาเลนเซียที่ว่าข้าวแบบ caldoso ต้องมีน้ำซุปใส เครื่องเทศรสอุ่นเหล่านี้ชวนให้นึกถึงชุดเครื่องเทศของคาตาลันยุคกลางที่ยังหลงเหลืออยู่บนหมู่เกาะ

## 3. ความแตกต่างแบบเมืองต่อเมือง (สำคัญ)
> ⚠️ ความแตกต่างระดับหมู่บ้านมีบันทึกออนไลน์เพียงคร่าว ๆ รูปแบบด้านล่างมาจากแหล่งข้อมูลที่อ้างถึง และชื่อเมืองเป็นเพียงข้อบ่งชี้ ไม่ได้รับการยืนยัน

*   **แบบดั้งเดิมพื้นที่ตอนใน (สัตว์ป่า):** กระต่ายป่าหรือกระต่าย + นกทรัชหรือนกพิราบ + หอยทาก + เห็ดป่า + picada ตับ
*   **แบบสมัยใหม่ / ในเมือง (Palma):** ไก่ + ซี่โครงหมู + sobrassada + ผัก (ถั่วแขก อาร์ติโชก ถั่วลันเตา) + picada ตับ
*   **Tramuntana:** ⚠️ ใส่**เห็ด**มากกว่า (*esclata-sangs* เห็ดน้ำนมสีส้ม) ในฤดูใบไม้ร่วง

## 4. สูตรหลัก (แบบแผนสำหรับ 4 คน)
*สูตรที่ใช้เป็นตัวแทน: **แบบ Mallorca สมัยใหม่** (ไก่, หมู, sobrassada, picada ตับ)*

### ฐานรส (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| น้ำมันมะกอก | 70 ml |
| ไก่ หั่นชิ้น | 500 g |
| ซี่โครงหมู ตัดสั้น | 300 g |
| ตับไก่ | 100 g |
| หัวหอม สับ | 1 หัว |
| มะเขือเทศสุก ขูด | 200 g |
| กระเทียม | 3 กลีบ |
| Sobrassada | 50 g |
| เห็ด (esclata-sangs หากอยู่ในฤดู) | 200 g |
| ถั่วแขก / อาร์ติโชก / ถั่วลันเตา | รวม 250 g |
| Pimentón dulce (ปาปริกาหวาน) | 3 g |
| น้ำ | 2 L |
| **Picada เครื่องเทศ:** อบเชย ⅓ ช้อนชา, พริกไทยดำ, กานพลู 2 ดอก, ลูกจันทน์เทศ 1 หยิบมือ, หญ้าฝรั่น 0.2 g, พาร์สลีย์, กระเทียม 2 กลีบ, ตับที่ทอดไว้ | — |

**การสกัดรส:** ทอดตับครู่หนึ่งแล้วตักพักไว้ ผัดไก่และซี่โครงจนเหลือง (**15 นาที**) ใส่หัวหอม (10 นาที) ตามด้วยกระเทียม มะเขือเทศ และปาปริกา (5 นาที) แล้วใส่ sobrassada (1 นาที) เติมน้ำแล้วเคี่ยว **30 นาที** ใส่ผักและเห็ด (**10 นาที**) โขลก picada ในครก

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดกลม | 280 g |
| น้ำซุป | ≈ 1.8–2 L (≈ 6:1, caldoso) |

### แบบแผนการปรุงทีละขั้นตอน
1. ต้มน้ำซุปให้เดือดแล้วใส่ข้าว
2. เคี่ยว **10 นาที** แล้วคน **picada เครื่องเทศและตับ** ลงไป
3. ต้มต่ออีก **6–8 นาที**
4. เสิร์ฟทันที ข้าวต้องยังมีน้ำซุปขลุกขลิก
