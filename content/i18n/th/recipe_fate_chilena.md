# Fate de Velorio (Chilean-Palestinian Funeral Rice) / فتّة العزاء

> ⬅ [หน้าหลัก](README.md) · [ปาเลสไตน์](provincial_palestine.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** มีบันทึกจากแหล่งข้อมูลทางชาติพันธุ์วรรณนาเพียงแหล่งเดียว ครอบครัวชิลี-ปาเลสไตน์จาก Beit Jala ใน La Calera บรรยาย *fate* ให้นักสังคมวิทยา Nicholas Bascuñan-Wiley ฟังว่าเป็น "อาหารที่มีข้าวเป็นฐาน กับโยเกิร์ต กะหล่ำดอก และเนื้อแพะ" ที่เสิร์ฟในงานไว้ทุกข์ ไม่พบสูตรที่เป็นลายลักษณ์อักษร พิมพ์เขียวด้านล่างเป็นการสร้างขึ้นใหม่โดยผสมคำบรรยายนั้นกับเทคนิค *fatteh* และข้าวโยเกิร์ตของปาเลสไตน์ โปรดตรวจสอบกับแม่ครัวชิลี-ปาเลสไตน์

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ชาวปาเลสไตน์พลัดถิ่นในแคว้นบัลปาราอิโซของชิลี (La Calera, Quillota) ในหมู่ครอบครัวจาก Beit Jala น่าจะมีร่วมกันในวงกว้างกว่านั้นในชุมชน ⚠️
*   **Dish Type & Texture:** สำรับงานไว้ทุกข์ของชาวพลัดถิ่น ข้าวปรุงเครื่องเทศเรียงชั้นกับกะหล่ำดอกทอดและเนื้อแพะนุ่มๆ ราดด้วยซอสโยเกิร์ตอุ่นใส่กระเทียม กินจากถาดร่วมกัน
*   **Traditional Cooking Vessel & Fuel:** หม้อสต็อกใบใหญ่และถาดบนเตาแก๊ส ทำในปริมาณมากที่บ้านของครอบครัวผู้เสียชีวิต

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ตามประเพณีปาเลสไตน์ ครอบครัวของผู้เสียชีวิตรับแขกที่มาแสดงความเสียใจเป็นเวลาหลายวัน มีการเสิร์ฟกาแฟขม (*qahwa sada*) และเพื่อนบ้านกับญาติจะทำถาดข้าวกับเนื้อให้ผู้มาไว้ทุกข์ ในชิลี ธรรมเนียมนี้อยู่รอดผ่านการอพยพสามหรือสี่ชั่วอายุคน เจ้าของร้านอาหารใน La Calera อธิบายว่าในงานไว้ทุกข์ของชาวชิลี-ปาเลสไตน์ ผู้คน "ดื่มกาแฟขมก่อนพิธี แล้วดื่มกาแฟหวานหลังพิธี" จากนั้น "ไปที่บ้านของครอบครัวเพื่อกิน *fate*" เธอเสริมว่า "ไม่ว่าผู้ตายจะเป็นที่รู้จักหรือไม่ หรือจะเป็นงานไว้ทุกข์ใหญ่หรือเล็ก พวกเขาก็ทำอาหารแบบเดียวกัน"

ชื่อนี้เป็นการสะกดแบบชิลีของ ***fatteh*** (ฟัตเตะห์ "ที่ถูกบิเป็นชิ้น") ในปาเลสไตน์และเลบานอน นี่คือตระกูลอาหารเรียงชั้นของขนมปัง ข้าว เนื้อ และโยเกิร์ต ดูแบบกาซา [fatteh ghazawiyya](recipe_fatteh_ghazawiyya.md) ในชิลี อาหารนี้ยังคงแก่นของโยเกิร์ต ข้าว และเนื้อไว้ ใช้**เนื้อแพะ** (ซึ่งในชิลีหาได้ง่ายกว่าเนื้อแกะในยุคแรกของผู้อพยพ นักชาติพันธุ์วรรณนาบันทึกการใช้เนื้อวัวแทนเนื้อแพะหรือเนื้อแกะในยุคแรก) และเพิ่ม**กะหล่ำดอก** ซึ่งเป็นผักที่สำคัญใน [maqluba](recipe_maqluba.md) ด้วย การทำอาหารนี้เป็นงานร่วมกันของกลุ่ม ส่วนใหญ่เป็นงานของผู้หญิง ครอบครัวจาก Beit Jala ที่ให้สัมภาษณ์บรรยายถึงงานใหญ่ที่มีแขกหลายร้อยคนและใช้เวลาเตรียมหลายชั่วโมง

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **La Calera / Quillota (ครอบครัวจาก Beit Jala):** ข้าว + โยเกิร์ต + กะหล่ำดอก + เนื้อแพะ เมนูเดียวกันในทุกงานไว้ทุกข์
*   **เปรียบเทียบกับบ้านเกิด ปาเลสไตน์ (⚠️):** อาหารในงานไว้ทุกข์โดยทั่วไปเป็นถาดข้าวกับเนื้อแบบ [mansaf](recipe_mansaf.md) หรือ [qidreh](recipe_qidreh.md) ในแถบเนินเขาเฮบรอน ส่วน *fatteh* ที่นั่นเป็นอาหารงานฉลองหรืออาหารเช้ามากกว่า *fate* ในงานไว้ทุกข์ของชิลีจึงเป็นความเฉพาะตัวของชาวพลัดถิ่น
*   **ครอบครัวชิลีอื่นๆ:** ⚠️ ไม่มีบันทึก อาจใช้เนื้อแกะหรือเนื้อวัวแทนเนื้อแพะ

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: fate งานไว้ทุกข์แบบ La Calera ที่สร้างขึ้นใหม่*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เนื้อแพะ (หรือเนื้อแกะ) ติดกระดูก หั่นเป็นชิ้น | 1.2 kg |
| น้ำ | 2 L |
| หอมใหญ่ผ่าครึ่ง | 1 หัว |
| ใบกระวาน กระวานเทศ อบเชยแท่ง | 2 / 4 / 1 |
| กะหล่ำดอก แยกเป็นดอก | 1 หัวขนาดกลาง (≈ 700 g) |
| น้ำมันสำหรับทอด | 300 ml |
| โยเกิร์ตรสธรรมชาติ (หรือ leben) | 750 g |
| แป้งข้าวโพด (ให้โยเกิร์ตคงตัว) | 1 ช้อนโต๊ะ |
| กระเทียมทุบ | 3 กลีบ |
| เกลือ ออลสไปซ์ | ตามชอบ |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดกลาง | 350 g |
| น้ำซุปแพะกรองแล้วสำหรับหุงข้าว | 650 ml |
| ซอสโยเกิร์ตต่อจาน | ≈ 180 ml |

### ขั้นตอนการทำทีละขั้น
1. **น้ำซุป:** ใส่น้ำให้ท่วมเนื้อแพะ ช้อนฟองออก แล้วใส่หอมใหญ่ ใบกระวาน กระวานเทศ และอบเชย ปิดฝาเคี่ยว 1.5–2 ชั่วโมงจนนุ่ม กรองและเก็บน้ำซุปไว้
2. **กะหล่ำดอก:** ทอดกะหล่ำดอกในน้ำมันร้อนจนเป็นสีทองเข้ม แล้วสะเด็ดน้ำมัน
3. **ข้าว:** ล้างข้าว แล้วหุงในน้ำซุปร้อน 650 ml กับเกลือและออลสไปซ์หนึ่งหยิบมือ ปิดฝาบนไฟอ่อน 18 นาที
4. **ซอสโยเกิร์ต:** ตีโยเกิร์ตกับแป้งข้าวโพด กระเทียม และเกลือ อุ่นเบาๆ โดยคนไปทางเดียวจนเริ่มเดือดเบาๆ
5. **ประกอบ:** เกลี่ยข้าวบนถาด วางกะหล่ำดอกและเนื้อแพะด้านบน แล้วราดโยเกิร์ตอุ่นก่อนเสิร์ฟ
