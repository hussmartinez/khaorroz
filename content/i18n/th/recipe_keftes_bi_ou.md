# Keftes (Syrian-Jewish Meatballs in Tamarind Sauce, over Rice) / كفتة بالتمر الهندي

> ⬅ [หน้าหลัก](README.md) · [ซีเรีย](provincial_syria.md)

> ⚠️ **หมายเหตุเรื่องความน่าเชื่อถือของแหล่งข้อมูล:** มีบันทึกในสื่ออาหารของชาวยิว (My Jewish Learning, Forward, Kosher.com) เกี่ยวกับชุมชนชาวยิวอเลปโปในบรุกลิน ซึ่งจานนี้เป็นอาหารวันหยุดทางศาสนาที่เสิร์ฟกับข้าว แต่ละครอบครัวใช้สัดส่วนมะขาม มะนาว และมะเขือเทศต่างกันไป ไม่มีบันทึกว่าฉบับใดมาจากเมืองไหนในแถบอเลปโป ชื่อภาษาฮีบรู: קפטס

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ชุมชนชาวยิวแห่งอเลปโปและชุมชนผู้พลัดถิ่น (บรุกลิน, Deal รัฐนิวเจอร์ซีย์, เม็กซิโกซิตี, อิสราเอล)
*   **Dish Type & Texture:** กินกับข้าว: ลูกชิ้นเนื้อวัวใส่สมุนไพรและเม็ดสน ทอดให้เป็นสีน้ำตาลแล้วเคี่ยวในซอสเปรี้ยวหวานจากมะขาม (*ou* อู) มะเขือเทศ และพริก Aleppo จนซอสเงาวาว ตักราดบนข้าวสวยขาว
*   **Traditional Cooking Vessel & Fuel:** กระทะทอดสำหรับทอดลูกชิ้น หม้อหนาสำหรับซอส และหม้อมีฝาสำหรับหุงข้าว

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ในครัวของชาวยิวอเลปโป **น้ำมะขามเข้มข้น** (*ou*, *temerhindi* เตเมรฮินดี) ทำหน้าที่เดียวกับที่กากน้ำตาลทับทิมทำในส่วนอื่นๆ ของซีเรีย Poopa Dweck (พูปา ดเวค) เรียกมันว่า "ความลับรสเปรี้ยวของอาหารซีเรีย" ([Tablet – Taking on Tamarind](https://www.tabletmag.com/podcasts/vox-tablet/taking-on-tamarind)) *Keftes* (เคฟเตส) คือลูกชิ้นประจำครัวนี้ สูตรของ My Jewish Learning ซึ่งเรียนมาจากครอบครัวเชื้อสายซีเรีย-อิตาลีในบรุกลินและบรรยายว่าเป็น "จานโปรดในวันหยุดทางศาสนา" เคี่ยวลูกชิ้นในมะขาม มะเขือเทศเข้มข้น และมะนาว แล้วปิดท้ายว่า "เสิร์ฟกับข้าว" ([My Jewish Learning – Syrian meatballs with tamarind sauce](https://www.myjewishlearning.com/the-nosher/syrian-meatballs-with-tamarind-sauce-recipe/)) ฉบับที่รู้จักกันมากที่สุดคือ ***keftes garaz*** (เคฟเตส การัซ) ซึ่งใส่**เชอร์รีเปรี้ยว** เป็นเสียงสะท้อนแบบชาวยิวของ *kebab bil-karaz* (เคบับเชอร์รี) อันโด่งดังของอเลปโป ([Forward – Keftes garaz](https://forward.com/food/recipes/382890/syrian-meatballs-keftes-garaz-with-cherries-and-tamarind)) ในเทศกาลปัสกา (Passover) จะใช้ผงขนมปังมัตซาห์ (matzah meal) แทนเกล็ดขนมปัง

**วิทยาศาสตร์การทำอาหาร:** มะขามให้กรดทาร์ทาริก ส่วนน้ำตาลช่วยถ่วงสมดุล เมื่อซอสงวดลง ลูกชิ้นจะดูดซับซอสและพองขึ้นเล็กน้อย การทอดให้เป็นสีน้ำตาลก่อน (ปฏิกิริยาเมลลาร์ด) ทำให้ซอสมีมิติรสชาติลึกขึ้น และช่วยให้ลูกชิ้นที่ยึดเกาะด้วยไข่ไม่แตก

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **ชาวยิวอเลปโปในบรุกลิน (มีบันทึก):** เนื้อวัว ไข่ เม็ดสน ผงมัตซาห์ สมุนไพร บาฮารัต (baharat เครื่องเทศผสม) พริก Aleppo ซอสมะขาม-มะเขือเทศ-มะนาว
*   **Keftes garaz:** ใส่เชอร์รีเปรี้ยว (สด แช่แข็ง หรืออบแห้ง) ลงในซอสมะขาม
*   **สัดส่วนประจำครอบครัว:** ปริมาณมะขาม มะนาว และมะเขือเทศแตกต่างกันไปในแต่ละครอบครัว แม่ครัวจะได้รับคำแนะนำให้ชิมไปปรุงไป

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*ฉบับที่ใช้: **keftes ของชาวยิวอเลปโปในบรุกลิน** (My Jewish Learning ประมาณหนึ่งในสามของสูตร) **กับข้าวสวย***

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| เนื้อวัวบด | 1 kg |
| ไข่ไก่ | 2 ฟอง |
| เม็ดสน คั่ว | ½ ถ้วย |
| ผงมัตซาห์หรือเกล็ดขนมปัง (+ เผื่อสำหรับคลุก) | ¼ ถ้วย |
| สมุนไพรสด (พาร์สลีย์ ผักชี มินต์) สับ | ⅓ ถ้วย |
| บาฮารัตหรือออลสไปซ์ / พริก Aleppo / เกลือ | 1 ช้อนชา / 1 ช้อนชา / 1½ ช้อนชา |
| น้ำมันมะกอก + พริก Aleppo + ออลสไปซ์ (สำหรับซอส) | 2 ช้อนโต๊ะ + ½ ช้อนชา + ½ ช้อนชา |
| น้ำ | 1.3 L |
| น้ำมะขามเข้มข้น | 3 ช้อนโต๊ะ |
| มะเขือเทศเข้มข้น | 3 ช้อนโต๊ะ |
| น้ำมะนาว; น้ำตาล (ไม่ใส่ก็ได้) | 1 ช้อนโต๊ะ; ตามชอบ |

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวขาวเมล็ดสั้นหรือกลาง ซาวแล้ว | 320 g |
| น้ำสำหรับหุงข้าว | ≈ 480 ml |
| น้ำมันหรือเนยสำหรับข้าว | 1 ช้อนโต๊ะ |
| ลูกชิ้นต่อคน | 6–8 ลูก |

### ขั้นตอนการทำทีละขั้น
1. **ลูกชิ้น:** ผสมเนื้อวัว ไข่ เม็ดสน ผงมัตซาห์ สมุนไพร และเครื่องเทศ ปั้นเป็นลูกขนาดเท่าลูกวอลนัท แล้วคลุกผงมัตซาห์บางๆ
2. **ทอด:** ทอดทีละชุดในน้ำมันเล็กน้อยจนเป็นสีน้ำตาลทุกด้าน
3. **ซอส:** อุ่นน้ำมันมะกอกกับพริก Aleppo จนน้ำมันเป็นสีแดง ใส่ออลสไปซ์ ตามด้วยน้ำ น้ำมะขาม มะเขือเทศเข้มข้น มะนาว และเกลือ เคี่ยวสักครู่
4. **เคี่ยว:** ใส่ลูกชิ้นลงไป ปรุงประมาณ 30 นาทีจนซอสข้น ชิมแล้วปรับสมดุลเปรี้ยวหวาน
5. **ข้าว:** ผัดข้าวในน้ำมัน 1 นาที ใส่น้ำเดือดและเกลือ ปิดฝาหุงบนไฟอ่อนมาก 15–18 นาที แล้วพักไว้ 5 นาที
6. **เสิร์ฟ:** ตักลูกชิ้นและซอสราดบนข้าว
