# Arroz Negro / Arròs Negre

> ⬅ [หน้าหลัก](README.md) · [จังหวัด València](provincial_valencia.md) · [จังหวัด Alacant](provincial_alicante.md) · [จังหวัด Castelló](provincial_castellon.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ตลอดแนวชายฝั่งบาเลนเซีย โดดเด่นที่สุดในย่านชาวประมงของเมืองบาเลนเซีย (El Cabanyal, El Grau), La Safor (Gandia), La Marina Alta (Dénia) และท่าเรือของ Castellón (El Grau de Castelló, Vinaròs)
*   **Liquid & Texture Profile:** **Seco** (ข้าวแห้ง) มี socarrat (ข้าวตังก้นกระทะ)
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** กระทะ paella เหล็กบนไฟฟืนหรือเตาแก๊ส ฉบับสมัยใหม่จะอบจบในเตาอบ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
Arròs negre (อาร็อส เนเกร ข้าวดำ) มีบันทึกในบาเลนเซียมาตั้งแต่อย่างน้อยศตวรรษที่ 17 เป็นคำตอบของชาวประมงต่อ**ปลาหมึกกระดอง** (*sepia*) และ**ปลาหมึกกล้วย** (*calamar*) ซึ่งถุงหมึกมีค่าเกินกว่าจะทิ้งไปในแง่รสชาติ น้ำหมึก (*tinta*) ทำให้ข้าวดำสนิท และเพิ่มความลึกของรสเค็มทะเล กลิ่นไอโอดีน และอูมามิเข้มข้น จากสารประกอบเมลานิน-โปรตีนและกลูตาเมตอิสระ เสิร์ฟคู่กับ **allioli** (อาลิโอลี ซอสกระเทียมน้ำมันมะกอก) เสมอ อาหารจานนี้พบได้ทั้งในคาตาลันและหมู่เกาะแบลีแอริกด้วย แต่ในบาเลนเซียยังคงรูปแบบที่กระชับและเรียบง่าย ได้แก่ ปลาหมึกกระดอง น้ำหมึก กระเทียม มะเขือเทศ และน้ำสต๊อกปลา

**วิทยาศาสตร์การทำอาหาร:** น้ำหมึกของสัตว์ตระกูลหมึกส่วนใหญ่คือเมลานินที่จับกับโปรตีน ทนความร้อนได้ดี สีจึงคงอยู่แม้ปรุงนาน แต่ถ้าไหม้ น้ำหมึกจะมีรสคล้ายโลหะ นี่คือเหตุผลที่ใส่น้ำหมึกพร้อมน้ำสต๊อก ไม่ใช่ใส่ลงในน้ำมันร้อน ปลาหมึกกระดองมีเนื้อแน่นอุดมด้วยคอลลาเจน จึงต้องจี่ไฟแรงก่อนเพื่อไล่น้ำและให้ผิวเป็นคาราเมล น้ำที่ปล่อยออกมาก็เป็นส่วนหนึ่งของ *fondo* (ฟอนโด ฐานน้ำซุป)

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)

*   **สไตล์เมืองบาเลนเซีย / El Cabanyal:** ใช้ **sepia** (ปลาหมึกกระดอง) อย่างเดียว หั่นเต๋าเล็ก กระเทียม + มะเขือเทศ + *pebre roig* (ปาปริกา) fumet (ฟูเมต์ น้ำสต๊อกปลา) จากปลาหิน ใช้น้ำหมึกจากถุงหมึกของ sepia เอง บางครั้งเสริมด้วยน้ำหมึกแบบซอง เสิร์ฟ allioli ข้างจาน
*   **สไตล์ Alicante / Dénia:** ใช้ **salmorreta** (ซัลโมร์เรตา: ñora พริกแดงแห้ง กระเทียม มะเขือเทศ พาร์สลีย์) เป็นฐาน และมักเพิ่ม **chipirones** (ปลาหมึกกล้วยตัวเล็ก) หรือ **calamar** หั่นเต๋า พร้อม **gamba roja** (กุ้งแดง) แกะเปลือก สีจะเข้มกว่าและออกไปทางดำอมแดง
*   **สไตล์ Castellón / Grau:** บางครั้งจับคู่ข้าวหมึกดำกับ **alcachofa de Benicarló** (อาร์ติโชกจาก Benicarló) ในฤดูหนาว (*arròs negre amb carxofa*) หรือกับ *galeres* (กาเลเรส กั้งตั๊กแตน) ใช้ fumet ที่เบากว่า
*   **สไตล์ La Safor / Gandia:** บางครั้งยอมให้ใส่หอมใหญ่ในฐาน (ซึ่งไม่ค่อยพบที่อื่นในบาเลนเซีย) และพริกหยวกเขียวเล็กน้อย มักจบด้วย **ajos tiernos** (กระเทียมอ่อน)

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*รูปแบบที่ใช้: **เมืองบาเลนเซีย** (sepia + น้ำหมึกของตัวเอง + fumet ปลาหิน) พร้อมระบุการใช้ salmorreta แทนแบบ Alicante*

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| Fumet de roca (ดู fumet ใน [arroz a banda](recipe_arroz_a_banda.md)) | 1.3 L |
| ปลาหมึกกระดองทั้งตัวพร้อมถุงหมึก | 600 g รวม (≈ 400 g หลังทำความสะอาด) |
| น้ำหมึก (จากถุงหมึกของตัวเอง + แบบซองถ้าจำเป็น) | รวม 8–12 g |
| น้ำมันมะกอก | 80 ml |
| กระเทียม | 3 กลีบ สับ |
| มะเขือเทศสุก ขูด | 150 g |
| Pebre roig (ปาปริกาหวาน) | 3 g |
| [Alicante: ใช้ salmorreta แทนมะเขือเทศ + ปาปริกา] | 60 g |

**การสกัดรส:** ทำความสะอาดปลาหมึกกระดองอย่างระมัดระวัง แกะถุงหมึกออกมาให้**ไม่แตก** แล้วพักไว้ใน fumet เล็กน้อย หั่นตัวหมึกเป็นชิ้นเต๋าขนาด 1 cm จี่ในน้ำมันร้อนจนน้ำระเหยหมดและขอบเป็นสีน้ำตาล (**8–10 นาที**) ใส่กระเทียม (30 วินาที) ตามด้วย pebre roig (5 วินาที) แล้วตามด้วยมะเขือเทศ ผัดจนมะเขือเทศข้นเหมือนแยม (**5 นาที**)

### สัดส่วนการประกอบ
| ส่วนประกอบ | ปริมาณ |
|---|---|
| ข้าวเมล็ดสั้น | 400 g |
| Fumet | 1.2–1.3 L |
| น้ำหมึก | ละลายใน fumet ร้อน 100 ml |
| Allioli | 150 g |

### ขั้นตอนการทำทีละขั้น
1. **การเตรียม:** ละลายน้ำหมึกใน fumet ร้อน แล้วกรองผ่านกระชอนตาถี่ (ไม่ให้มีก้อน)
2. **การคั่วข้าว:** ใส่ข้าวลงใน fondo แล้วคั่ว **2 นาที**
3. **การเติมน้ำ:** เท fumet ที่กำลังเดือดและน้ำหมึกลงไป คนหนึ่งครั้งเพื่อเกลี่ยให้เรียบ ปรับรสเค็ม
4. **การคุมไฟ:** ไฟแรง **8 นาที** → ไฟกลางค่อนอ่อน **8 นาที** → ไฟแรง **1–2 นาที** เพื่อทำ socarrat (ทางเลือกแบบสมัยใหม่: อบที่ 185 °C ใน 6–8 นาทีสุดท้าย)
5. **จบงาน/การพัก:** พัก **3–5 นาที** เสิร์ฟกับ allioli การบีบมะนาวไม่ใช่ธรรมเนียมดั้งเดิม
