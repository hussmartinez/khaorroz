# Arroz con Conejo y Caracoles Murciano / Arroz con Conejo y Serranas

> ⬅ [หน้าหลัก](README.md) · [Región de Murcia (แคว้นมูร์เซีย)](provincial_murcia.md)

## 1. ข้อมูลภูมิศาสตร์และเนื้อสัมผัส
*   **Primary Geographic Zone:** แผ่นดินด้านในและ huerta (สวนผักชลประทาน) ของ Murcia ได้แก่ Noroeste (Calasparra, Caravaca, Moratalla, Cehegín), Altiplano (Jumilla, Yecla) และ Huerta de Murcia
*   **Liquid & Texture Profile:** **Seco** (แห้ง) ข้าวชั้นบาง หุงบนไฟฟืน ("a la lumbre")
*   **ภาชนะและเชื้อเพลิงดั้งเดิม:** paella (กระทะปาเอยา) เหล็กกล้าบนไฟจากกิ่งองุ่นแห้ง (*sarmiento*) หรือไม้สน บางครัวเรือนในแผ่นดินด้านในใช้ cazuela (หม้อดินเผา)

## 2. ประวัติและบริบททางวัฒนธรรม
แหล่งข้อมูลของ Murcia บรรยายว่าข้าวที่หุง "a la lumbre" (บนกองไฟฟืนแบบเปิด) เป็นเสาหลักหนึ่งของอาหารในแคว้นนี้ และข้าวกระต่ายกับหอยทากคือแบบคลาสสิก นี่คือฝั่ง Murcia ของประเพณีข้าวภูเขาเดียวกันกับของแผ่นดินด้านในของ Alicante ([recipe_arroz_conejo_y_caracoles.md](recipe_arroz_conejo_y_caracoles.md) สำนัก Pinoso และ Vega Baja) ข้อแตกต่างหลักคือข้าว แม่ครัวชาว Murcia ยืนกรานว่าต้องใช้ **D.O. Arroz de Calasparra** ที่ปลูกบนขั้นบันไดริมแม่น้ำ Segura และ Mundo ตามเอกสารของ D.O. อาหารคลาสสิกที่สุดของพื้นที่นี้คือข้าวกระต่ายกับหอยทากที่ทำด้วยข้าวท้องถิ่นและ**หุงบนไฟฟืน** หอยทากที่ใช้คือ **serranas** หอยทากภูเขาตัวเล็ก ซึ่งแม่ครัวจะล้างให้สะอาดแล้วทำให้ "asustan" ("ตกใจ") โดยเริ่มต้มในน้ำเย็นก่อนจะค่อย ๆ ให้เดือด

**วิทยาศาสตร์การทำอาหาร:** Calasparra ปลูกข้าวบนที่สูงด้วยน้ำแม่น้ำที่เย็น เมล็ดข้าวจึงสุกช้า ทำให้แข็งกว่าและมีความชื้นต่ำกว่า สามารถดูดซับน้ำได้ประมาณ 3 เท่าของปริมาตรโดยไม่แตก เมนูนี้จึงรับน้ำซุปได้มากขึ้นเล็กน้อยโดยที่ข้าวยังร่วน พริกหวานแดงหั่นเส้นที่ทอดในน้ำมันจะถ่ายทอดความหวานลงสู่ไขมัน

## 3. ความแตกต่างในแต่ละเมือง (สำคัญมาก)
*   **Calasparra / Noroeste:** กระต่าย + serranas + มะเขือเทศสุก + **พริกหวานแดง** + กระเทียม + หญ้าฝรั่น + น้ำมันมะกอก ใช้**ข้าว Calasparra** หุงบนไฟฟืน
*   **Huerta de Murcia:** เพิ่มผักตามฤดูกาลจาก huerta (อาร์ติโชก *bajocas* หรือถั่วแขก) และบางครั้งใส่ไก่ การเสิร์ฟมะนาวเหลืองไว้ข้าง ๆ เป็นเรื่องปกติทั่ว Murcia
*   **Altiplano (Jumilla / Yecla):** ใช้ไฟจากกิ่งองุ่นของไร่ Monastrell คล้ายกับ Pinoso ที่อยู่อีกฝั่งของเขตแดน ⚠️ ไม่พบแหล่งข้อมูลท้องถิ่นโดยเฉพาะ ส่วนนี้สร้างขึ้นใหม่จากแนวปฏิบัติร่วมของแดนองุ่น Monastrell
*   **ข้อแตกต่างจากสำนัก Alicante:** สูตรของ Murcia นิยม**พริกหวานแดงหั่นเส้น**และข้าว Calasparra ส่วน Pinoso นิยมไธม์และ ñora (พริกแดงแห้งทรงกลม) และ Vega Baja เสิร์ฟกับมะนาวเหลืองและ *picada* (เครื่องโขลก) จาก ñora

## 4. สูตรหลัก (สำหรับ 4 ที่)
*สูตรที่นำเสนอ: **Calasparra / Noroeste** (ผสมสัดส่วนจาก Directo al Paladar และ Spain.info)*

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| น้ำมันมะกอก | 120 ml |
| กระต่าย หั่นชิ้นเล็ก | 1 ตัว (≈ 1.2–1.5 kg) |
| พริกหวานแดง หั่นเส้นกว้าง | ½ ลูก |
| กระเทียม | 4 กลีบ |
| มะเขือเทศสุก ขูด | 200 g |
| Serranas (หอยทากภูเขา) ล้างพิษและทำให้ "ตกใจ" แล้ว | 20–24 ตัว |
| Pimentón dulce (ปาปริก้าหวาน) | 3 g |
| หญ้าฝรั่น | 0.3 g |
| โรสแมรี่ | 1 กิ่ง |
| น้ำ | 1.4 L |

**การสกัดรส:** ทอดพริกหวานหั่นเส้นแล้วพักไว้ ผัดกระต่ายกับเกลือจนเป็นสีน้ำตาล (**20 นาที**) ใส่กระเทียม pimentón (5 วินาที) และมะเขือเทศ (5 นาที) เติมน้ำ หอยทาก และหญ้าฝรั่น เคี่ยวไฟอ่อน **25 นาที** จนเหลือประมาณ 1.1 L ใส่พริกหวานหั่นเส้นกลับลงไป ใส่โรสแมรี่ในช่วง 3 นาทีสุดท้ายแล้วหยิบออก

### อัตราส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าว Calasparra (bomba หรือ balilla × sollana) | 320–350 g |
| น้ำซุป | ≈ 1.05–1.1 L |
| มะนาวเหลือง | 1 ลูก |

### ขั้นตอนการทำทีละขั้น
1. **หอยทาก:** ใส่ลงในน้ำเย็นแล้วค่อย ๆ ต้มให้เดือด เพื่อให้หอยยื่นตัวออกจากเปลือก แล้วสะเด็ดน้ำ
2. **Fondo (ฐานรสชาติ):** ทำตามขั้นตอนด้านบน
3. **ข้าว:** โรยข้าวให้เป็นชั้นเรียบเสมอกัน หลังจากนี้ห้ามคน
4. **ไฟ:** ไฟแรง 8 นาที → ไฟถ่านแดง 8–9 นาที (ข้าว Calasparra ใช้เวลาประมาณ 18 นาที) → เร่งไฟสั้น ๆ ตอนท้ายเพื่อทำ socarrat (ข้าวตังก้นกระทะ)
5. **ขั้นสุดท้าย:** พัก 5 นาที เสิร์ฟพร้อมมะนาวเหลืองหั่นซีก
