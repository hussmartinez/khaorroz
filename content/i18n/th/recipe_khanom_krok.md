# Khanom Krok / ขนมครก

> ⬅ [หน้าหลัก](README.md) · [ภาคกลาง](provincial_central_thailand.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** ขนมริมทางที่พบได้ทั่วประเทศ มีศูนย์กลางดั้งเดิมอยู่ที่อยุธยาและที่ราบภาคกลาง
*   **Dish Type & Texture:** ขนมถ้วยเล็กจากแป้งข้าวเจ้าและกะทิ อบในกระทะเหล็กหล่อที่มีหลุม ตัวขนมมีเปลือกกรอบ หน้ากะทิเยิ้ม รสหวานเค็ม และกินกันเป็นคู่
*   **Traditional Cooking Vessel & Fuel:** ***เตาขนมครก*** ถาดเหล็กหล่อ (หรือดินเผา) ที่มีหลุมกลมเรียงเป็นแถว ตั้งบนเตาถ่าน

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ขนมครกได้รับการกล่าวถึงว่าเป็นขนมที่ผู้คนนิยมมากในสมัย**อยุธยา** ซึ่งมีการขาย *เตาขนมครก* กันแล้วในเวลานั้น ตามแบบดั้งเดิม แป้งทำจาก**ข้าวสารแช่น้ำแล้วโม่ด้วยโม่หิน** ผสมกับหางกะทิ ข้าวสวย และมะพร้าวทึนทึกขูด แล้วหยอดหน้าด้วยหัวกะทิ แม่ครัวในวัง (*ชาววัง*) คิดหน้าขนมให้หลากหลายขึ้น ได้แก่ กุ้ง ไข่ หมู เผือก และข้าวโพด (ข่าวสด) ในปี 2024 TasteAtlas จัดอันดับให้ขนมครกเป็น**แพนเค้กที่ดีที่สุดในโลกอันดับที่สี่** (กรมประชาสัมพันธ์)

## 3. ความแตกต่างของแต่ละเมือง (สำคัญ)
*   **แบบริมทางคลาสสิก:** หน้าเปล่า หรือโรยต้นหอมหรือข้าวโพด
*   **แบบชาววัง (*ชาววัง*):** หน้ากุ้ง ไข่ หมู เผือก หรือข้าวโพด
*   **ขนมครกใบเตย:** แป้งสีเขียวจากใบเตย
*   **แป้งแบบโบราณ:** ใช้ข้าวสารแช่น้ำโม่หินแทนแป้งข้าวเจ้าสำเร็จรูป

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: **ขนมครกแบบคลาสสิก** (ประมาณ 28 หลุม)*

### ฐานรสชาติ (El Fondo)
| ส่วนผสม | ปริมาณ |
|---|---|
| แป้งข้าวเจ้า | 150 g |
| ข้าวหอมมะลิหุงสุก | 50 g |
| หางกะทิ | 300 ml |
| มะพร้าวอ่อน (ทึนทึก) ขูด | 40 g |
| เกลือ | ½ ช้อนชา |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| หน้าขนม: หัวกะทิ + น้ำตาล + เกลือ + แป้งข้าวเจ้า | 250 ml + 60 g + ½ ช้อนชา + 1 ช้อนโต๊ะ |
| โรยหน้า: ต้นหอมซอยหรือข้าวโพดหวาน | 3 ช้อนโต๊ะ |
| น้ำมันสำหรับทาหลุม | ตามต้องการ |

### ขั้นตอนการทำทีละขั้น
1. **แป้งตัวขนม:** ปั่นแป้งข้าวเจ้า ข้าวสวย หางกะทิ มะพร้าวขูด และเกลือจนเนียน พักไว้ **30 นาที**
2. **แป้งหน้าขนม:** ผสมหัวกะทิ น้ำตาล เกลือ และแป้งข้าวเจ้าจนเนียน
3. **ตั้งเตา:** ตั้งเตาขนมครกบนเตาถ่านให้ร้อน แล้วทาน้ำมันทุกหลุม
4. **หยอดขนม:** หยอดแป้งตัวขนมลงในหลุมประมาณสองในสาม เมื่อขอบเริ่มเซ็ตตัว (**1–2 นาที**) จึงหยอดแป้งหน้ากะทิและโรยหน้า ปิดฝาแล้วอบต่อ **3–4 นาที** จนก้นกรอบและหน้าเพิ่งเซ็ตตัว
5. **เสิร์ฟ:** แคะขนมด้วยช้อนโค้ง แล้วประกบสองฝั่งหน้าชนกัน
