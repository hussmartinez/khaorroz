# Yam Naem Khao Thot / ยำแหนมข้าวทอด

> ⬅ [หน้าหลัก](README.md) · [ภาคกลาง](provincial_central_thailand.md)

## 1. ข้อมูลพื้นที่และเนื้อสัมผัส
*   **Primary Geographic Zone:** กรุงเทพฯ และอีสาน (ต้นกำเนิดจากลาว ที่ท่าเดื่อ เวียงจันทน์)
*   **Dish Type & Texture:** สลัดข้าว: ข้าวคลุกพริกแกงปั้นเป็นก้อนทอดกรอบ หักเป็นชิ้นกรุบกรอบ คลุกกับหมูหมักเปรี้ยว (*แหนม*) มะนาว พริก หอมแดง ถั่วลิสง และผักสมุนไพร กินห่อด้วยผักกาดหอม
*   **Traditional Cooking Vessel & Fuel:** กระทะน้ำมันสำหรับทอดข้าว ชามผสม และใบผักกาดหอมสำหรับห่อ

## 2. บริบททางประวัติศาสตร์และวัฒนธรรม
ในลาวรู้จักกันในชื่อ *แหนมข้าว* (nam khao) ได้รับการบรรยายว่าเป็นอาหารเรียกน้ำย่อยยอดนิยมของลาวจากท่าเดื่อใกล้เวียงจันทน์ อาหารจานนี้เข้ามาถึงอีสานและต่อมาถึงกรุงเทพฯ พร้อมกับแรงงานชาวลาวและชาวอีสานที่มาทำงาน ซึ่งที่นี่เรียกว่า *ยำแหนมข้าวทอด* ([Wikipedia – Nam khao](https://en.wikipedia.org/wiki/Nam_khao)) ⚠️ แหล่งข้อมูลส่วนใหญ่มาจากบทความ Wikipedia บทความเดียวและสำเนาของบทความนั้น ไม่พบการระบุช่วงเวลาจากแหล่งอิสระ

**วิทยาศาสตร์การครัว:** ข้าวสุกที่เกาะตัวด้วยพริกแกงแดงและไข่ ปั้นเป็นก้อนแล้วทอด จะได้เปลือกกรอบและแกนในหนึบ การหักก้อนข้าวทำให้ทั้งสองเนื้อสัมผัสได้สัมผัสกับน้ำยำมะนาวและความเปรี้ยวจากกรดแลคติกของ *แหนม*

## 3. ความแตกต่างของแต่ละท้องถิ่น (สำคัญ)
*   ***แหนมข้าว* ลาว (ท่าเดื่อ):** ต้นฉบับ ใช้แหนมแบบลาว ([Wikipedia](https://en.wikipedia.org/wiki/Nam_khao))
*   ***ยำแหนมข้าวทอด* แบบกรุงเทพฯ:** น้ำยำหวานกว่า เสิร์ฟกับกะหล่ำปลีและผักสมุนไพร ([Pholfoodmafia](https://www.pholfoodmafia.com/?p=20191))
*   **ใช้หมูสด (*แหนมหมูสด*):** ในที่ที่หา *แหนม* ไม่ได้ ([ImportFood](https://importfood.com/recipes/recipe/1271-crispy-rice-larb-pork-yum-khao-tod-naem-moo-sod))

## 4. สูตรหลัก (พิมพ์เขียวสำหรับ 4 คน)
*สูตรที่นำเสนอ: **ยำแหนมข้าวทอดแบบกรุงเทพฯ***

### ฐานรสชาติ (El Fondo)
| วัตถุดิบ | ปริมาณ |
|---|---|
| ข้าวหอมมะลิหุงสุก | 600 ก. |
| พริกแกงแดง | 2 ช้อนโต๊ะ |
| ไข่ | 1 ฟอง |
| มะพร้าวขูด (ไม่ใส่ก็ได้) | 2 ช้อนโต๊ะ |
| แหนม (*แหนม*) ยีให้ร่วน | 200 ก. |
| หอมแดง ต้นหอม ผักชี สะระแหน่ | ตามชอบ |
| ถั่วลิสงคั่ว พริกแห้ง | 50 ก., 4 เม็ด |
| น้ำมะนาว / น้ำปลา / น้ำตาล | 3 ช้อนโต๊ะ / 1½ ช้อนโต๊ะ / 1 ช้อนชา |
| น้ำมันสำหรับทอด ใบผักกาดหอม | ตามต้องการ |

### สัดส่วนการประกอบ
| องค์ประกอบ | ปริมาณ |
|---|---|
| ข้าวหอมมะลิ | ข้าวสาร ≈ 220 ก. (ข้าวสุก 600 ก.) |
| แหนม : ข้าวทอด | ≈ 1 : 3 |

### ขั้นตอนการทำทีละขั้น
1. **ข้าว:** หุงข้าวหอมมะลิ 220 ก. กับน้ำ 300 มล. พักให้เย็น
2. **ปั้นก้อน:** ผสมข้าวกับพริกแกง ไข่ และมะพร้าว ปั้นเป็นก้อนให้แน่น
3. **ทอด:** ทอดในน้ำมันท่วมที่ 180 °C จนเหลืองเข้มและกรอบ (6–8 นาที) สะเด็ดน้ำมันแล้วพักให้เย็น
4. **คลุก:** หักก้อนข้าวเป็นชิ้น คลุกกับแหนม หอมแดง ผักสมุนไพร ถั่วลิสง พริกทอด มะนาว น้ำปลา และน้ำตาล
5. **เสิร์ฟ:** พร้อมใบผักกาดหอมสำหรับห่อ
